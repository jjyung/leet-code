# Leet Code Interview Prep

這個 repo 用來整理「準備開發人員面試」所需的程式題目與學習資源。

## 專案目標

- 彙整常見面試題型（例如 Top 150）
- 分門別類收錄題目、解法與模板
- 累積面試前可快速複習的筆記與 cheat sheets

## 目前現況

- 已建立 `top-150-interview` 題型目錄結構
- 各分類資料夾已加入 `.gitkeep`，避免空目錄在 Git 中遺失
- 根目錄提供模板與速查文件：
  - `cheatsheets.md`
  - `code-templates.md`
  - `code-templates-java.md`
  - `code-templates-cpp.md`

## 使用方式

- 依題型進入 `top-150-interview` 對應資料夾練習
- 將解題思路、時間空間複雜度與程式碼持續補充
- 搭配 templates 與 cheatsheets 做面試前複習

- 不同準備時長（1 年、6 個月、3 個月、1 個月、1 週、3 天、24 小時）可參考：`study-plan.md`
