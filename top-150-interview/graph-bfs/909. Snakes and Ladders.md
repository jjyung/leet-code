# 909. Snakes and Ladders

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

給定一個 `n x n` 棋盤 `board`，編號從左下角的 `1` 開始，以蛇形方式一路排到 `n^2`。你每次可以從當前格子往前走 `1` 到 `6` 步；若落點有蛇或梯子，必須立刻傳送到指定位置。

請回傳到達 `n^2` 所需的最少擲骰次數；若無法到達，回傳 `-1`。

https://leetcode.com/problems/snakes-and-ladders/

## Answer

這題也是標準 BFS 最短步數：

1. 每次擲骰的成本都相同，都是一步。
2. 從當前格子展開 `+1` 到 `+6` 的所有可能落點。
3. 第一次到達終點 `n * n` 時，當前層數就是最少擲骰次數。

難點不在 BFS，而在於如何把格子編號轉回 `board[row][col]`。由於棋盤採蛇形編號，必須先算出該編號位於自底向上的第幾列，再依列的奇偶決定欄位方向。

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    public int snakesAndLadders(int[][] board) {
        int n = board.length;
        int target = n * n;

        Queue<Integer> queue = new ArrayDeque<>();
        boolean[] visited = new boolean[target + 1];

        queue.offer(1);
        visited[1] = true;

        int moves = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();

            for (int i = 0; i < size; i++) {
                int current = queue.poll();
                if (current == target) {
                    return moves;
                }

                for (int dice = 1; dice <= 6; dice++) {
                    int next = current + dice;
                    if (next > target) {
                        break;
                    }

                    int[] pos = getPosition(next, n);
                    int row = pos[0];
                    int col = pos[1];

                    if (board[row][col] != -1) {
                        next = board[row][col];
                    }

                    if (visited[next]) {
                        continue;
                    }

                    visited[next] = true;
                    queue.offer(next);
                }
            }

            moves++;
        }

        return -1;
    }

    private int[] getPosition(int label, int n) {
        int index = label - 1;
        int rowFromBottom = index / n;
        int col = index % n;

        int row = n - 1 - rowFromBottom;
        if (rowFromBottom % 2 == 1) {
            col = n - 1 - col;
        }

        return new int[] {row, col};
    }
}
```

### 說明

1. 時間複雜度為 `O(n^2)`，每個格子最多處理一次，每次最多展開 6 個結果。
2. 空間複雜度為 `O(n^2)`，來自佇列與 `visited`。
3. 蛇或梯子每次擲骰只會觸發一次，不能連續跳轉。
