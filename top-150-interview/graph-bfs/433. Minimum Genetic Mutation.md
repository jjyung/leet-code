# 433. Minimum Genetic Mutation

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

給定起點基因 `startGene`、終點基因 `endGene`，以及合法基因庫 `bank`，每次只能改動一個字元，且改完後的基因必須存在於 `bank` 中。

請回傳從 `startGene` 變到 `endGene` 所需的最少 mutation 次數；如果無法到達，回傳 `-1`。

https://leetcode.com/problems/minimum-genetic-mutation/

## Answer

這題本質是最短路徑問題，適合用 BFS：

1. 每一次 mutation 都算一步。
2. BFS 會按步數一層一層展開所有可能基因。
3. 第一次碰到 `endGene` 時，就是最少步數。

實作上先把 `bank` 放進 `HashSet`，這樣可以快速判斷某個新基因是否合法；當基因被加入佇列後，就立刻從集合移除，避免重複拜訪。

```java
import java.util.ArrayDeque;
import java.util.Arrays;
import java.util.HashSet;
import java.util.Queue;
import java.util.Set;

class Solution {
    public int minMutation(String startGene, String endGene, String[] bank) {
        Set<String> validGenes = new HashSet<>(Arrays.asList(bank));
        if (!validGenes.contains(endGene)) {
            return -1;
        }

        Queue<String> queue = new ArrayDeque<>();
        queue.offer(startGene);

        char[] choices = {'A', 'C', 'G', 'T'};
        int steps = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();

            for (int i = 0; i < size; i++) {
                String current = queue.poll();
                if (current.equals(endGene)) {
                    return steps;
                }

                char[] chars = current.toCharArray();
                for (int pos = 0; pos < chars.length; pos++) {
                    char original = chars[pos];

                    for (char choice : choices) {
                        if (choice == original) {
                            continue;
                        }

                        chars[pos] = choice;
                        String next = new String(chars);

                        if (!validGenes.contains(next)) {
                            continue;
                        }

                        validGenes.remove(next);
                        queue.offer(next);
                    }

                    chars[pos] = original;
                }
            }

            steps++;
        }

        return -1;
    }
}
```

### 說明

1. 時間複雜度為 `O(N * L * 4)`，其中 `N` 是 `bank` 長度、`L` 是基因長度 8。
2. 空間複雜度為 `O(N)`，主要來自集合與 BFS 佇列。
3. `startGene` 不一定在 `bank` 內，但 `endGene` 若不在 `bank`，答案一定是 `-1`。
