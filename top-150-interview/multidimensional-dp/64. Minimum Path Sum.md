# 64. Minimum Path Sum

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given a m x n grid filled with non-negative numbers, find a path from top left to bottom right, which minimizes the sum of all numbers along its path.

Note: You can only move either down or right at any point in time.

[LeetCode problem link](https://leetcode.com/problems/minimum-path-sum/description/?envType=study-plan-v2&envId=top-interview-150)

### Example 1

```text
Input: grid = [[1,3,1],[1,5,1],[4,2,1]]
Output: 7
Explanation: Because the path 1 → 3 → 1 → 1 → 1 minimizes the sum.
```

### Example 2

```text
Input: grid = [[1,2,3],[4,5,6]]
Output: 12
```

### Constraints

- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 200`

## Answer

### 解題思路

令 `dp[j]` 表示走到目前這一列的第 `j` 欄時，從左上角到該位置的最小路徑總和。

走到 `grid[i][j]` 時，只能從上方或左方到達：

```text
dp[j] = min(上方的 dp[j], 左方的 dp[j - 1]) + grid[i][j]
```

使用一維陣列時，必須由左至右更新：

- `dp[j]` 在更新前仍是上方位置的最小路徑總和。
- `dp[j - 1]` 已經更新成目前這一列左方位置的最小路徑總和。

第一欄只能從上方到達，因此直接累加；其餘欄位則取上方與左方的較小值。

### Java 實作

```java
class Solution {
    public int minPathSum(int[][] grid) {
        int rows = grid.length;
        int columns = grid[0].length;
        int[] dp = new int[columns];

        // 初始化第一列：每個位置只能從左方走過來。
        dp[0] = grid[0][0];
        for (int column = 1; column < columns; column++) {
            dp[column] = dp[column - 1] + grid[0][column];
        }

        for (int row = 1; row < rows; row++) {
            // 第一欄只能從上方走過來。
            dp[0] += grid[row][0];

            // 由左至右更新，保留 dp[column] 的上方值，並使用 dp[column - 1] 的左方值。
            for (int column = 1; column < columns; column++) {
                dp[column] = Math.min(dp[column], dp[column - 1])
                        + grid[row][column];
            }
        }

        return dp[columns - 1];
    }
}
```

### 複雜度分析

- 時間複雜度：`O(m * n)`，每個網格位置只處理一次。
- 空間複雜度：`O(n)`，使用一維陣列儲存目前列的最小路徑總和。
