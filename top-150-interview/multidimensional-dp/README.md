## 解題思路提示

看到「從左上走到右下」、「第 `i` 列第 `j` 個位置」或「兩個維度共同決定狀態」時，先定義 `dp[row][column]` 的意義：

1. 決定狀態代表到達某格的最佳值、方法數或可行性。
2. 列出能抵達目前狀態的前驅，通常是上方、左方或上一列相鄰位置。
3. 先處理第一列、第一欄或三角形邊界，再依拓撲順序填表。
4. 確認每個狀態只依賴已完成的狀態，必要時壓縮成一維。

## 必要資料結構與演算法

- **二維陣列**：直觀保存每個座標的狀態，時間通常為 $O(mn)$，`m`、`n` 是網格尺寸。
- **一維滾動陣列**：若只依賴上一列與目前列，可將空間降為 $O(n)$。
- **邊界初始化**：第一列/第一欄常只有一種來源，是最容易出錯的地方。
- **拓撲式填表**：從左上到右下、由底向上等固定順序，確保轉移來源已計算。

## 複習提醒

- 清楚區分「目前格子的值」與「走到目前格子的最佳總和」。
- 使用一維 DP 時，確認由左到右或由右到左的更新方向不會重複使用同一輪狀態。
- 三角形的每一列長度不同，索引邊界不能直接套用矩形網格公式。
- 測試單格、單列、單欄、負數/零成本與只有邊界路徑的案例。
