# 120. Triangle

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given a triangle array, return the minimum path sum from top to bottom.

For each step, you may move to an adjacent number of the row below. More formally, if you are on index `i` on the current row, you may move to either index `i` or index `i + 1` on the next row.

### Example 1

```text
Input: triangle = [[2],[3,4],[6,5,7],[4,1,8,3]]
Output: 11
Explanation: The minimum path sum from top to bottom is 2 + 3 + 5 + 1 = 11.
```

### Example 2

```text
Input: triangle = [[-10]]
Output: -10
```

### Constraints

- `1 <= triangle.length <= 200`
- `triangle[0].length == 1`
- `triangle[i].length == triangle[i - 1].length + 1`
- `-10^4 <= triangle[i][j] <= 10^4`

Follow-up: Could you do this using only `O(n)` extra space, where `n` is the total number of rows in the triangle?

[LeetCode problem link](https://leetcode.com/problems/triangle/description/?envType=study-plan-v2&envId=top-interview-150)

## Answer

### 解題思路

使用自底向上的動態規劃，將每個位置的狀態定義為：從該位置走到最底層的最小路徑總和。

這題不能直接找出每一列的最小值再加總，因為路徑必須符合相鄰限制：若目前位於索引 `i`，下一列只能走到索引 `i` 或 `i + 1`。某一列的最小值可能無法從前一列抵達，或選擇目前較小的數字後，反而錯過後續更好的路徑。

因此必須分別記錄到達每個位置的最佳結果，而不是只保留整列的最小值。這也是需要使用動態規劃的原因。

從最後一列開始建立基礎狀態，再由倒數第二列逐列往上計算。對於位置 `(row, column)`，下一步只能走到下一列的 `column` 或 `column + 1`，因此轉移公式為：

`dp[column] = triangle[row][column] + min(dp[column], dp[column + 1])`

其中 `dp[column]` 與 `dp[column + 1]` 在更新前分別代表下一列的兩個相鄰狀態。從最後一列開始計算，再逐列往上更新，就能將空間複雜度壓縮為 `O(n)`。

### Java 實作

```java
import java.util.List;

class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        int rows = triangle.size();
        int[] dp = new int[rows + 1];

        // 從最後一列往上走，逐步計算每個位置到底部的最小路徑總和。
        for (int row = rows - 1; row >= 0; row--) {
            List<Integer> currentRow = triangle.get(row);

            for (int column = 0; column <= row; column++) {
                // dp[column] 與 dp[column + 1] 是下一列的兩個相鄰選擇。
                dp[column] = currentRow.get(column)
                        + Math.min(dp[column], dp[column + 1]);
            }
        }

        return dp[0];
    }
}
```

### 說明

1. `dp[column]` 儲存目前處理位置往下走的最小路徑總和。
2. 自底向上更新時，`dp[column]` 和 `dp[column + 1]` 正好對應下一列可走的兩個位置。
3. 最後 `dp[0]` 即為從三角形頂端到底端的最小路徑總和。

時間複雜度為 `O(n^2)`，其中 `n` 是三角形的列數；空間複雜度為 `O(n)`。

### 解法二：由上往下的動態規劃

也可以從頂端開始計算，將每個位置的狀態定義為：從頂端走到該位置的最小路徑總和。

對於目前位置 `(row, column)`，它只能從上一列的 `column - 1` 或 `column` 抵達。因此轉移時要比較上左方與上右方的最佳結果：

`dp[column] = triangle[row][column] + min(dp[column - 1], dp[column])`

使用一維陣列時，必須由右往左更新。如此一來，`dp[column]` 和 `dp[column - 1]` 都還保留上一列的結果；若由左往右更新，`dp[column - 1]` 會先被改成目前列的結果，導致轉移錯誤。

### Java 實作

```java
import java.util.List;

class Solution {
    public int minimumTotal(List<List<Integer>> triangle) {
        int rows = triangle.size();
        int[] dp = new int[rows];
        dp[0] = triangle.get(0).get(0);

        for (int row = 1; row < rows; row++) {
            List<Integer> currentRow = triangle.get(row);

            // 由右往左更新，保留上一列尚未被覆蓋的狀態。
            for (int column = row; column >= 0; column--) {
                int value = currentRow.get(column);

                if (column == 0) {
                    // 最左側只能從上一列的最左側走下來。
                    dp[column] += value;
                } else if (column == row) {
                    // 最右側只能從上一列的左上方走下來。
                    dp[column] = dp[column - 1] + value;
                } else {
                    // 中間位置可由左上方或正上方抵達，選擇較小的路徑。
                    dp[column] = Math.min(dp[column - 1], dp[column]) + value;
                }
            }
        }

        int answer = dp[0];
        for (int column = 1; column < rows; column++) {
            answer = Math.min(answer, dp[column]);
        }

        return answer;
    }
}
```

此解法同樣會保留每個位置的最佳結果，不會只選擇當前列的最小值，因此能正確處理相鄰位置限制。時間複雜度為 `O(n^2)`，空間複雜度為 `O(n)`。
