# 072. Edit Distance

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given two strings word1 and word2, return the minimum number of operations required to convert word1 to word2.

You have the following three operations permitted on a word:

- Insert a character
- Delete a character
- Replace a character

### Example 1

```text
Input: word1 = "horse", word2 = "ros"
Output: 3
Explanation:
horse -> rorse (replace 'h' with 'r')
rorse -> rose (remove 'r')
rose -> ros (remove 'e')
```

### Example 2

```text
Input: word1 = "intention", word2 = "execution"
Output: 5
Explanation:
intention -> inention (remove 't')
inention -> enention (replace 'i' with 'e')
enention -> exention (replace 'n' with 'x')
exention -> exection (replace 'n' with 'c')
exection -> execution (insert 'u')
```

Constraints:

- `0 <= word1.length, word2.length <= 500`
- word1 and word2 consist of lowercase English letters.

## Answer

### 解題思路

使用二維動態規劃。令 `dp[i][j]` 表示將 `word1` 的前 `i` 個字元轉成 `word2` 的前 `j` 個字元所需的最少操作次數。

- 若其中一個前綴為空，必須將另一個前綴的字元全部插入或刪除，因此 `dp[0][j] = j`、`dp[i][0] = i`。
- 若兩個前綴的最後一個字元相同，不需對這兩個字元操作，取 `dp[i - 1][j - 1]`。
- 若最後一個字元不同，考慮刪除、插入或替換一個字元，分別從 `dp[i - 1][j]`、`dp[i][j - 1]`、`dp[i - 1][j - 1]` 轉移，取最小值再加一。

每個狀態所依賴的較短前綴都已先算出，而最後一步涵蓋所有可能的編輯操作，所以取得的值是最少操作次數。

```java
class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        // i、j 是前綴長度，不是字元索引；0 代表空字串。
        // dp[i][j] 是 word1 前 i 個字元轉成 word2 前 j 個字元的最少操作次數。
        // 多一列、一欄存放空字串的狀態，因此大小為 (m + 1) × (n + 1)。
        int[][] dp = new int[m + 1][n + 1];

        // 空字串與非空前綴之間，只能逐一刪除或插入字元。
        for (int i = 0; i <= m; i++) {
            dp[i][0] = i;
        }
        for (int j = 0; j <= n; j++) {
            dp[0][j] = j;
        }

        // 0 的狀態已初始化；從長度 1 算到完整長度 m、n。
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                // 字元索引從 0 開始，因此長度 i、j 的前綴末字元位於 i - 1、j - 1。
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    // 末字元相同，不需額外操作；前面前綴的操作次數已記在 dp[i - 1][j - 1]。
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    // 取刪除、插入、替換三種操作的最小成本。
                    int delete = dp[i - 1][j];
                    int insert = dp[i][j - 1];
                    // 先轉換去掉兩個末字元的前綴，再替換末字元；操作次數稍後加一。
                    int replace = dp[i - 1][j - 1];
                    dp[i][j] = Math.min(delete, Math.min(insert, replace)) + 1;
                }
            }
        }

        return dp[m][n];
    }
}
```

### 複雜度分析

令 `m`、`n` 分別為 `word1`、`word2` 的長度。空字串的情況由第一列與第一欄的初始化處理。

- 時間複雜度：`O((m + 1) × (n + 1))`，每個狀態計算一次。
- 空間複雜度：`O((m + 1) × (n + 1))`，用於儲存動態規劃表。
