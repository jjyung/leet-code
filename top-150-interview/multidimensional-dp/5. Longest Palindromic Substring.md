# 5. Longest Palindromic Substring

<span style="color: #f59e0b;"><strong>Medium</strong></span>

## Problem

Given a string s, return the longest palindromic substring in s.

### Example 1

```text
Input: s = "babad"
Output: "bab"
Explanation: "aba" is also a valid answer.
```

### Example 2

```text
Input: s = "cbbd"
Output: "bb"
```

### Constraints

1 <= s.length <= 1000
s consist of only digits and English letters.

<https://leetcode.com/problems/longest-palindromic-substring/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

### 解題思路

使用區間 DP 判斷每個子字串是否為回文。定義 `isPalindrome[begin][end]` 表示 `s[begin..end]` 是否為回文。

對目前區間 `s[begin..end]` 而言，必須先滿足兩端字元相同，接著分成兩種情況：

1. 區間長度不超過 3。更精確地說，`shortInterval` 只判斷區間是否很短，並不負責判斷頭尾；頭尾是否相同由 `sameBoundary` 判斷。例如：`"a"` 沒有內部字元、`"aa"` 的內部沒有字元、`"aba"` 的內部只有 `"b"`，這些區間只要頭尾相同，就一定是回文。相反地，`"ab"` 雖然長度只有 2，但頭尾不同，所以不是回文。
2. 區間長度大於 3。內部區間 `s[begin + 1..end - 1]` 也必須是回文，才能判定目前區間為回文。

因此轉移條件為：

```text
isPalindrome[begin][end] =
    s.charAt(begin) == s.charAt(end)
    && (end - begin <= 2 || isPalindrome[begin + 1][end - 1])
```

按照右端點 `end` 遞增填表時，內部區間的右端點是 `end - 1`，因此一定已經計算完成。每次找到回文區間，就比較其長度與目前答案；只有更長時才更新起點與長度。

### 程式碼

```java
class Solution {
    public String longestPalindrome(String s) {
        if (s == null || s.isEmpty()) {
            return "";
        }

        int length = s.length();
        boolean[][] isPalindrome = new boolean[length][length];
        int longestStart = 0;
        int longestLength = 1;

        for (int end = 0; end < length; end++) {
            for (int begin = 0; begin <= end; begin++) {
                // 兩端相同且內部區間為回文時，整個區間才是回文。
                boolean sameBoundary = s.charAt(begin) == s.charAt(end);
                boolean shortInterval = end - begin <= 2;
                boolean innerIsPalindrome = shortInterval
                        || isPalindrome[begin + 1][end - 1];

                if (sameBoundary && innerIsPalindrome) {
                    isPalindrome[begin][end] = true;

                    int currentLength = end - begin + 1;
                    if (currentLength > longestLength) {
                        longestStart = begin;
                        longestLength = currentLength;
                    }
                }
            }
        }

        return s.substring(longestStart, longestStart + longestLength);
    }
}
```

### 複雜度分析

- `n` 是字串 `s` 的長度。
- 時間複雜度：$O(n^2)$。共有 $O(n^2)$ 個區間，每個區間只進行常數次判斷。
- 空間複雜度：$O(n^2)$。`isPalindrome` 儲存所有起點與終點組合的回文判斷結果。

### 邊界條件

- 題目限制保證 `s` 至少包含一個字元，因此最長回文至少是單一字元；程式也額外處理空字串或 `null`，避免建立零大小 DP 陣列後取用答案。
- 長度為 1、2 或 3 的區間透過 `end - begin <= 2` 處理，不會存取不存在的內部索引。
- 若有多個相同長度的最長回文，程式保留先找到的區間，符合題目允許任一有效答案的要求。
