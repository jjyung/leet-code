# 63. Unique Paths II

## Problem

<!-- markdownlint-disable MD033 -->
<span style="color: #f59e0b;"><strong>Medium</strong></span>
<!-- markdownlint-enable MD033 -->

You are given an m x n integer array `grid`. There is a robot initially located at the top-left corner (i.e., `grid[0][0]`). The robot tries to move to the bottom-right corner (i.e., `grid[m - 1][n - 1]`). The robot can only move either down or right at any point in time.

An obstacle and space are marked as 1 or 0 respectively in `grid`. A path that the robot takes cannot include any square that is an obstacle.

Return the number of possible unique paths that the robot can take to reach the bottom-right corner.

The testcases are generated so that the answer will be less than or equal to 2 * 109.

### Example 1

![alt text](image-1.png)

```text
Input: obstacleGrid = [[0,0,0],[0,1,0],[0,0,0]]
Output: 2
Explanation: There is one obstacle in the middle of the 3x3 grid above.
There are two ways to reach the bottom-right corner:

1. Right -> Right -> Down -> Down
2. Down -> Down -> Right -> Right
```

### Example 2

![alt text](image-2.png)

```text
Input: obstacleGrid = [[0,1],[0,0]]
Output: 1
Explanation: There is one path from the top-left corner to the bottom-right corner.
```

### Constraints

- `m == obstacleGrid.length`
- `n == obstacleGrid[i].length`
- `1 <= m, n <= 100`
- `obstacleGrid[i][j] is 0 or 1.`

## Answer

### 解題思路

令 `dp[column]` 表示處理目前這一列之前，走到目前儲存格上方位置的路徑數；當走訪目前儲存格時，`dp[column]` 會先保留上方的路徑數，而 `dp[column - 1]` 已經更新成左方的路徑數。因此，沒有障礙物時可以使用下列轉移：

```text
dp[column] = dp[column] + dp[column - 1]
```

其中：

- `dp[column]` 是上方儲存格的路徑數。
- `dp[column - 1]` 是左方儲存格的路徑數。

若目前儲存格是障礙物，任何路徑都不能經過它，必須將 `dp[column]` 設為 `0`。第一個儲存格初始化為 `1`（可通行）或 `0`（有障礙物），其餘狀態便能沿著每一列逐步計算。當障礙物出現在第一列或第一欄時，路徑數會自然維持為 `0`，因為後續位置無法繞過障礙物。

### Java 程式碼

```java
class Solution {
    public int uniquePathsWithObstacles(int[][] obstacleGrid) {
        int rowCount = obstacleGrid.length;
        int columnCount = obstacleGrid[0].length;

        // dp[column] 表示目前走到該欄儲存格時的路徑數
        int[] dp = new int[columnCount];
        dp[0] = obstacleGrid[0][0] == 1 ? 0 : 1;

        for (int row = 0; row < rowCount; row++) {
            for (int column = 0; column < columnCount; column++) {
                // 先判斷目前儲存格是否為障礙物，障礙物不能被任何路徑經過
                if (obstacleGrid[row][column] == 1) {
                    // 清除這個位置的所有路徑，避免障礙物的路徑繼續傳遞
                    dp[column] = 0;
                // 只有 column > 0 才有左方儲存格，才能套用上方加左方的轉移
                } else if (column > 0) {
                    // dp[column] 尚未更新前代表上方，dp[column - 1] 代表左方
                    dp[column] += dp[column - 1];
                }
            }
        }

        return dp[columnCount - 1];
    }
}
```

### 說明

- `dp[0]` 先根據左上角是否為障礙物設定。由於題目保證至少有一列一欄，這個初始化涵蓋單一儲存格的情況。
- 每個可通行位置只能從上方或左方抵達，所以將兩個方向的路徑數相加；障礙物則直接把對應狀態歸零。
- 若起點或終點是障礙物，起點的初始值或終點的狀態會是 `0`，最後便會回傳 `0`。
- 題目保證答案不超過 `2 * 10^9`，使用 `int` 足以儲存結果。
- 時間複雜度為 `O(mn)`，其中 `m` 是列數、`n` 是欄數；每個儲存格只處理一次。
- 空間複雜度為 `O(n)`，其中 `n` 是欄數；只使用一個長度為 `n` 的 DP 陣列。
