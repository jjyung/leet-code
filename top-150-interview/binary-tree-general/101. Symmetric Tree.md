# 101. Symmetric Tree

## Problem

<!-- markdownlint-disable MD033 -->
<span style="color: #16a34a;"><strong>Easy</strong></span>
<!-- markdownlint-enable MD033 -->

Given the `root` of a binary tree, check whether it is a mirror of itself (i.e., symmetric around its center).

### Example 1

![alt text](image-3.png)

```text
Input: root = [1,2,2,3,4,4,3]
Output: true
Explanation: The left and right subtrees are mirror images of each other around the root.
```

### Example 2

![alt text](image-4.png)

```text
Input: root = [1,2,2,null,3,null,3]
Output: false
Explanation: The second node on the left is null while the second node on the right is 3, so the tree is not a mirror of itself.
```

### Constraints

- The number of nodes in the tree is in the range [1, 1000].
- -100 <= Node.val <= 100

Follow up: Could you solve it both recursively and iteratively?

[LeetCode 101. Symmetric Tree](https://leetcode.com/problems/symmetric-tree/)

## Answer

### 解題思路

對稱的定義不是「每個節點的左子樹等於右子樹」，而是「整棵樹的左半邊與右半邊互為鏡像」。因此需要同時比較兩個節點：`leftNode` 與 `rightNode`。

兩個節點互為鏡像的條件為：

1. 兩者同時為 `null`：視為對稱，回傳 `true`。
2. 其中只有一個為 `null`：結構不對稱，回傳 `false`。
3. 兩者的值不相同：回傳 `false`。
4. 都通過後，再遞迴比較外側與內側：
   - 外側：`leftNode.left` 對 `rightNode.right`。
   - 內側：`leftNode.right` 對 `rightNode.left`。

呼叫端以 `isMirror(root.left, root.right)` 作為起點，因為根節點只有一個，對稱性完全由左右子樹決定。若 `root` 為 `null`（空樹），依題意可視為對稱，回傳 `true`。

```java
class Solution {
    public boolean isSymmetric(TreeNode root) {
        // 空樹視為對稱；否則比較根的左右子樹是否互為鏡像。
        if (root == null) {
            return true;
        }
        return isMirror(root.left, root.right);
    }

    // 判斷 leftNode 與 rightNode 這兩棵子樹是否互為鏡像。
    private boolean isMirror(TreeNode leftNode, TreeNode rightNode) {
        // 兩邊都走到空節點，代表這一層結構對稱。
        if (leftNode == null && rightNode == null) {
            return true;
        }
        // 只有一邊為空，代表結構不對稱。
        if (leftNode == null || rightNode == null) {
            return false;
        }
        // 值不同就不可能互為鏡像。
        if (leftNode.val != rightNode.val) {
            return false;
        }
        // 外側（left.left 對 right.right）與內側（left.right 對 right.left）都必須對稱。
        return isMirror(leftNode.left, rightNode.right)
                && isMirror(leftNode.right, rightNode.left);
    }
}
```

### 迭代解法（跟進問題）

用佇列同時放入「應該互為鏡像」的節點配對，每次取出兩個節點比較，再把下一層的配對以鏡像順序放入。佇列中每個元素是一個 `TreeNode`，配對關係由入列順序保證。

因為 `null` 也是一種必須比較的結構資訊，佇列必須允許存入 `null`。`ArrayDeque` 不接受 `null`，`offer(null)` 會拋出 `NullPointerException`，所以這裡改用同樣實作 `Deque` 但允許 `null` 的 `LinkedList`。

```java
import java.util.Deque;
import java.util.LinkedList;

class Solution {
    public boolean isSymmetric(TreeNode root) {
        if (root == null) {
            return true;
        }

        // 佇列中連續取出的一對節點，必須互為鏡像；LinkedList 允許存入 null。
        Deque<TreeNode> queue = new LinkedList<>();
        queue.offer(root.left);
        queue.offer(root.right);

        while (!queue.isEmpty()) {
            TreeNode leftNode = queue.poll();
            TreeNode rightNode = queue.poll();

            // 兩邊同時為空，這對節點對稱，換下一對。
            if (leftNode == null && rightNode == null) {
                continue;
            }
            // 只有一邊為空或值不同，代表不對稱。
            if (leftNode == null || rightNode == null || leftNode.val != rightNode.val) {
                return false;
            }

            // 依鏡像順序放入下一層配對：外側一組、內側一組。
            queue.offer(leftNode.left);
            queue.offer(rightNode.right);
            queue.offer(leftNode.right);
            queue.offer(rightNode.left);
        }

        return true;
    }
}
```

### 邊界條件

- `root == null`：空樹視為對稱，回傳 `true`。
- 只有根節點：左右子樹皆為 `null`，`isMirror(null, null)` 回傳 `true`。
- 節點值可為負數，直接以 `!=` 比較值即可，不需特殊處理。
- 單邊子樹缺失（例如 `[1,2,2,null,3,null,3]`）會在「只有一邊為空」的判斷被攔下，回傳 `false`。

### 複雜度分析

令 `n` 為二元樹中的節點數，`h` 為樹高。

- 遞迴解法：
  - 時間複雜度：$O(n)$，每對節點只被比較一次。
  - 空間複雜度：$O(h)$，來自遞迴呼叫堆疊；最差（鏈狀）為 $O(n)$。
- 迭代解法：
  - 時間複雜度：$O(n)$，每個節點最多入列、出列各一次。
  - 空間複雜度：$O(n)$，佇列最多同時容納一層的節點配對。
