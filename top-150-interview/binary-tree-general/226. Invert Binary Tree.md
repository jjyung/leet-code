# 226. Invert Binary Tree

## Problem

<!-- markdownlint-disable MD033 -->
<span style="color: #16a34a;"><strong>Easy</strong></span>
<!-- markdownlint-enable MD033 -->

Given the root of a binary tree, invert the tree, and return its root.

### Example 1

![alt text](image.png)

```text
Input: root = [4,2,7,1,3,6,9]
Output: [4,7,2,9,6,3,1]
Explanation: Swapping the left and right subtrees at every node produces the inverted tree.
```

### Example 2

![alt text](image-1.png)

```text
Input: root = [2,1,3]
Output: [2,3,1]
Explanation: Swapping the children of the root changes the tree to [2,3,1].
```

### Example 3

```text
Input: root = []
Output: []
Explanation: The tree is empty, so there is nothing to invert.
```

### Constraints

- The number of nodes in the tree is in the range [0, 100].
- -100 <= Node.val <= 100

## Answer

### 解題思路

對每個節點而言，反轉二元樹只需要交換它的左、右子樹，接著對交換後的兩棵子樹遞迴執行相同操作。這是一種深度優先搜尋（DFS）：當目前節點為 `null` 時，代表已經走到空子樹，直接返回即可。

程式直接在原本的樹上交換子樹參考，不需要建立新的節點，因此最後回傳的仍是原本的 `root`。

```java
class Solution {
    public TreeNode invertTree(TreeNode root) {
        // 空樹沒有節點可交換，直接回傳 null。
        if (root == null) {
            return null;
        }

        // 先交換目前節點的左右子樹，暫存左子樹可避免遺失原本的參考。
        TreeNode temporary = root.left;
        root.left = root.right;
        root.right = temporary;

        // 交換後繼續反轉兩棵子樹，確保每個節點都完成左右互換。
        invertTree(root.left);
        invertTree(root.right);

        return root;
    }
}
```

### 邊界條件

- `root == null` 時直接回傳 `null`，對應空樹。
- 只有一個節點時，左右子樹都是 `null`，交換後樹的結構不變。
- 葉節點的左右子樹都為空，遞迴會在 `null` 判斷處停止。

### 複雜度分析

令 `n` 為二元樹中的節點數，`h` 為樹高。

- 時間複雜度：$O(n)$，每個節點只會被造訪一次。
- 空間複雜度：$O(h)$，來自遞迴呼叫堆疊；平衡樹為 $O(\log n)$，最差的傾斜樹為 $O(n)$。
