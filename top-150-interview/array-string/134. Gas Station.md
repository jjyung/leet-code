# 134. Gas Station

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

There are `n` gas stations along a circular route, where the amount of gas at the `ith` station is `gas[i]`.

You have a car with an unlimited gas tank and it costs `cost[i]` of gas to travel from the `ith` station to its next `(i + 1)th` station. You begin the journey with an empty tank at one of the gas stations.

Given two integer arrays `gas` and `cost`, return *the starting gas station's index if you can travel around the circuit once in the clockwise direction, otherwise return* `-1`. If there exists a solution, it is **guaranteed** to be **unique**

<https://leetcode.com/problems/gas-station/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

要解決這個問題，我們可以使用貪心演算法來確定是否存在一個起點，使得從該起點出發可以繞環路一圈，並且返回這個起點的索引。如果不能繞環路一圈，則返回 -1。

具體思路如下：

1. 如果總的 `gas` 小於總的 `cost`，說明不可能繞環路一圈，直接返回 -1。

2. 使用一個變數 `total_tank` 來記錄總的油量淨值（即 `gas[i] - cost[i]` 的總和）。

3. 使用另一個變數 `curr_tank` 來記錄當前油箱中的油量。

4. 初始化起點 `start` 為 0。

5. 遍歷所有加油站，如果 `curr_tank` 小於 0，說明當前起點不能使汽車繞環路一圈，將起點設為下一個加油站，並將 `curr_tank` 重新置為 0。

以下是詳細的 Java 實現：

```java
class Solution {
    public int canCompleteCircuit(int[] gas, int[] cost) {
        int n = gas.length;
        
        int total_tank = 0;
        int curr_tank = 0;
        int start = 0;
        
        for (int i = 0; i < n; i++) {
            total_tank += gas[i] - cost[i];
            curr_tank += gas[i] - cost[i];
            
            // 如果當前油箱中的油量小於 0，說明不能從當前起點出發
            if (curr_tank < 0) {
                // 更新起點為下一個加油站
                start = i + 1;
                // 重置當前油箱
                curr_tank = 0;
            }
        }
        
        // 如果總的油量淨值小於 0，說明不能繞環路一圈
        return total_tank >= 0 ? start : -1;
    }

    public static void main(String[] args) {
        Solution sol = new Solution();
        int[] gas = {1, 2, 3, 4, 5};
        int[] cost = {3, 4, 5, 1, 2};
        System.out.println(sol.canCompleteCircuit(gas, cost)); // 應輸出 3
    }
}
```

### 說明

1. **初始化變數**：

   - `total_tank` 用來記錄總的油量淨值（`gas[i] - cost[i]` 的總和）。

   - `curr_tank` 用來記錄當前油箱中的油量。

   - `start` 用來記錄可能的起點，初始化為 0。

2. **遍歷所有加油站**：

   - 更新 `total_tank` 和 `curr_tank`。

   - 如果 `curr_tank` 小於 0，說明從當前起點無法繞環路一圈，將起點更新為下一個加油站，並將 `curr_tank` 置為 0。

3. **返回結果**：

   - 如果 `total_tank` 大於等於 0，說明可以繞環路一圈，返回起點 `start`。

   - 否則，返回 -1。

這種方法的時間複雜度是 O(n)，空間複雜度是 O(1)。通過一次遍歷陣列，我們可以確定是否存在一個起點，使得汽車能夠繞環路一圈，並且返回這個起點的索引。
