# 121. Best Time to Buy and Sell Stock

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

You are given an array `prices` where `prices[i]` is the price of a given stock on the `ith` day.

You want to maximize your profit by choosing a **single day** to buy one stock and choosing a **different day in the future** to sell that stock.

Return *the maximum profit you can achieve from this transaction*. If you cannot achieve any profit, return `0`.

<https://leetcode.com/problems/best-time-to-buy-and-sell-stock/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

要解決這個問題，可以使用一次遍歷的演算法，記錄到目前為止的最小價格以及最大利潤。這樣的時間複雜度是 O(n)，空間複雜度是 O(1)。

以下是詳細的 Java 實現：

```java
class Solution {
    public int maxProfit(int[] prices) {
        if (prices == null || prices.length == 0) {
            return 0;
        }

        int minPrice = Integer.MAX_VALUE;
        int maxProfit = 0;

        for (int price : prices) {
            if (price < minPrice) {
                minPrice = price; // 更新最小價格
            } else if (price - minPrice > maxProfit) {
                maxProfit = price - minPrice; // 更新最大利潤
            }
        }

        return maxProfit;
    }
}
```

### 說明

1. **初始化變數**：

   - `minPrice` 用來記錄到目前為止的最小價格，初始化為最大值。

   - `maxProfit` 用來記錄到目前為止的最大利潤，初始化為 0。

2. **遍歷陣列**：

   - 對於每個價格 `price`：

      - 如果 `price` 小於 `minPrice`，則更新 `minPrice`。

      - 否則，計算 `price` 和 `minPrice` 的差值，如果差值大於 `maxProfit`，則更新 `maxProfit`。

3. **返回結果**：

   - 遍歷完成後，`maxProfit` 即為可以獲得的最大利潤。如果沒有利潤（即 `maxProfit` 仍然是 0），則返回 0。

這個方法通過一次遍歷就能找到最大利潤，同時只使用了常數級別的額外空間，非常高效。
