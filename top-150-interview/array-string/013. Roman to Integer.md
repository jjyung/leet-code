# 013. Roman to Integer

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

Roman numerals are represented by seven different symbols: `I`, `V`, `X`, `L`, `C`, `D` and `M`.

```plain
Symbol       Value
I             1
V             5
X             10
L             50
C             100
D             500
M             1000
```

For example, `2` is written as `II` in Roman numeral, just two ones added together. `12` is written as `XII`, which is simply `X + II`. The number `27` is written as `XXVII`, which is `XX + V + II`.

Roman numerals are usually written largest to smallest from left to right. However, the numeral for four is not `IIII`. Instead, the number four is written as `IV`. Because the one is before the five we subtract it making four. The same principle applies to the number nine, which is written as `IX`. There are six instances where subtraction is used:

- `I` can be placed before `V` (5) and `X` (10) to make 4 and 9. 

- `X` can be placed before `L` (50) and `C` (100) to make 40 and 90. 

- `C` can be placed before `D` (500) and `M` (1000) to make 400 and 900.

Given a roman numeral, convert it to an integer.

## Answer

要將羅馬數字轉換為整數，我們可以從左到右遍歷字串，並使用一個對映表將羅馬數字符號轉換為對應的整數值。在遍歷過程中，如果當前字元表示的值比下一個字元表示的值小，則減去當前字元的值；否則，加上當前字元的值。

下面是詳細的 Java 實現：

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int romanToInt(String s) {
        int total = 0;
        int prevValue = 0;

        // 從左到右遍歷字串
        for (int i = 0; i < s.length(); i++) {
            int currentValue = romanToInt(s.charAt(i));

            // 如果當前值大於前一個值，需要減去前一個值兩次（一次是之前加上的，另一次是為了扣掉）
            if (currentValue > prevValue) {
                total += currentValue - 2 * prevValue;
            } else {
                total += currentValue;
            }

            prevValue = currentValue;
        }

        return total;
    }

    private int romanToInt(char c) {
        switch (c) {
            case 'I' -> {
                return 1;
            }
            case 'V' -> {
                return 5;
            }
            case 'X' -> {
                return 10;
            }
            case 'L' -> {
                return 50;
            }
            case 'C' -> {
                return 100;
            }
            case 'D' -> {
                return 500;
            }
            case 'M' -> {
                return 1000;
            }
            default -> {
                throw new RuntimeException("invalid char");
            }
        }
    }

    public static void main(String[] args) {
        Solution sol = new Solution();
        System.out.println(sol.romanToInt("III"));     // 應輸出 3
        System.out.println(sol.romanToInt("IV"));      // 應輸出 4
        System.out.println(sol.romanToInt("IX"));      // 應輸出 9
        System.out.println(sol.romanToInt("LVIII"));   // 應輸出 58
        System.out.println(sol.romanToInt("MCMXCIV")); // 應輸出 1994
    }
}
```

### 說明

1. **建立對映**：建立一個雜湊表 `romanToInt`，將羅馬數字符號對映到對應的整數值。(改用 switch function)

2. **遍歷字串**：從左到右遍歷字串 `s`，並使用變數 `currentValue` 儲存當前字元對應的整數值。

3. **處理特殊情況**：如果 `currentValue` 大於 `prevValue`，說明當前字元與前一個字元構成了一個特殊情況（例如 IV 或 IX），需要減去前一個值兩次（一次是之前加上的，另一次是為了扣掉）。否則，直接加上當前值。

4. **更新前一個值**：將 `currentValue` 賦值給 `prevValue`，以便下一次迭代使用。

5. **返回結果**：返回計算得到的總值 `total`。

這樣的方法可以有效地將羅馬數字轉換為整數，並處理所有的特殊情況。
