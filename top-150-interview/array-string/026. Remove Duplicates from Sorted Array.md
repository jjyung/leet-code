# 026. Remove Duplicates from Sorted Array

## Question

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given an integer array `nums` sorted in **non-decreasing order**, remove the duplicates **[in-place](https://en.wikipedia.org/wiki/In-place_algorithm)** such that each unique element appears only **once**. The **relative order** of the elements should be kept the **same**. Then return *the number of unique elements in* `nums`.

Consider the number of unique elements of `nums` to be `k`, to get accepted, you need to do the following things:

- Change the array `nums` such that the first `k` elements of `nums` contain the unique elements in the order they were present in `nums` initially. The remaining elements of `nums` are not important as well as the size of `nums`.

- Return `k`.

<https://leetcode.com/problems/remove-duplicates-from-sorted-array/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

這個問題可以通過雙指標法來解決，一個指標用來遍歷整個陣列，另一個指標用來標記唯一元素的位置。以下是詳細的 Java 實現：

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        if (nums.length == 0) return 0;

        // 用於標記唯一元素的位置
        int k = 1;

        // 遍歷陣列
        for (int i = 1; i < nums.length; i++) {
            // 如果發現一個新的唯一元素
            if (nums[i] != nums[i - 1]) {
                nums[k] = nums[i];
                k++;
            }
        }

        // 返回唯一元素的數量
        return k;
    }
}
```

### 說明

1. **處理空陣列**：如果輸入陣列長度為0，直接返回0。

2. **初始化指標**：`k` 用於標記唯一元素的位置，從1開始因為第一個元素總是唯一的。

3. **遍歷陣列**：從第二個元素開始遍歷陣列。

4. **檢查重複**：如果當前元素 `nums[i]` 不等於前一個元素 `nums[i - 1]`，則將其放到 `nums[k]` 位置，並將 `k` 增加 1。

5. **返回結果**：遍歷完成後，`k` 即為唯一元素的數量。

這個方法確保了所有的唯一元素都被移到陣列的前部，並且保持了原來的相對順序。
