# 055. Jump Game

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

You are given an integer array `nums`. You are initially positioned at the array's **first index**, and each element in the array represents your maximum jump length at that position.

Return `true` *if you can reach the last index, or* `false` *otherwise*.

<https://leetcode.com/problems/jump-game/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

要解決這個問題，我們可以使用貪心演算法來確定是否能夠到達陣列的最後一個索引。我們維護一個變數 `farthest` 來記錄可以到達的最遠位置。如果在遍歷陣列的過程中，當前索引超過了 `farthest`，則返回 `false`。如果遍歷結束後 `farthest` 大於或等於最後一個索引，則返回 `true`。

以下是詳細的 Java 實現：

```java
class Solution {
    public boolean canJump(int[] nums) {
        int farthest = 0;

        for (int i = 0; i < nums.length; i++) {
            if (i > farthest) {
                return false; // 如果當前索引超過了最遠可達位置，返回 false
            }
            farthest = Math.max(farthest, i + nums[i]); // 更新最遠可達位置
            if (farthest >= nums.length - 1) {
                return true; // 如果最遠可達位置已經達到或超過最後一個索引，返回 true
            }
        }

        return false; // 遍歷結束後檢查是否能到達最後一個索引
    }
}
```

### 說明

1. **初始化變數**：

   - `farthest` 用來記錄可以到達的最遠位置，初始化為 0。

2. **遍歷陣列**：

   - 從第一個元素開始遍歷陣列。

   - 如果當前索引 `i` 超過了 `farthest`，說明不能到達當前位置，返回 `false`。

   - 更新 `farthest` 為 `i + nums[i]` 和當前 `farthest` 的最大值。

   - 如果 `farthest` 大於或等於陣列的最後一個索引，說明可以到達最後一個位置，返回 `true`。

3. **返回結果**：

   - 如果遍歷結束後 `farthest` 仍然不能到達最後一個索引，返回 `false`。

這個演算法的時間複雜度是 O(n)，空間複雜度是 O(1)，通過一次遍歷陣列就能確定是否可以到達最後一個索引。
