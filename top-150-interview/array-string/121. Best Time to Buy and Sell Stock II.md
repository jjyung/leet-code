# 121. Best Time to Buy and Sell Stock II

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

You are given an integer array `prices` where `prices[i]` is the price of a given stock on the `ith` day.

On each day, you may decide to buy and/or sell the stock. You can only hold **at most one** share of the stock at any time. However, you can buy it then immediately sell it on the **same day**.

Find and return *the **maximum** profit you can achieve*.

<https://leetcode.com/problems/best-time-to-buy-and-sell-stock-ii/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

這個問題要求我們找到可以獲得的最大利潤，當我們可以每天買賣股票時。這意味著我們需要找到所有的上升段並進行交易。可以通過一次遍歷來實現，當天的價格比前一天的價格高時，就賺取差價。

以下是詳細的 Java 實現：

```java
class Solution {
    public int maxProfit(int[] prices) {
        int maxProfit = 0;

        for (int i = 1; i < prices.length; i++) {
            if (prices[i] > prices[i - 1]) {
                maxProfit += prices[i] - prices[i - 1];
            }
        }

        return maxProfit;
    }
}
```

### 說明

1. **初始化變數**：

   - `maxProfit` 用來記錄總的最大利潤，初始化為 0。

2. **遍歷陣列**：

   - 從第二天（`i = 1`）開始遍歷陣列，比較當前價格 `prices[i]` 和前一天的價格 `prices[i - 1]`。

   - 如果 `prices[i]` 大於 `prices[i - 1]`，這意味著價格在上升，可以在前一天買入，今天賣出，賺取 `prices[i] - prices[i - 1]` 的差價。

   - 將差價累加到 `maxProfit` 中。

3. **返回結果**：

   - 遍歷完成後，`maxProfit` 即為可以獲得的最大利潤。

這個方法的時間複雜度是 O(n)，空間複雜度是 O(1)，通過一次遍歷陣列就能找到所有可能的利潤，從而得到最大利潤。
