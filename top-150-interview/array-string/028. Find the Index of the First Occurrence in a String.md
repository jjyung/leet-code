# 028. Find the Index of the First Occurrence in a String

## Question

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given two strings `needle` and `haystack`, return the index of the first occurrence of `needle` in `haystack`, or `-1` if `needle` is not part of `haystack`.

## Answer

要在一個字串中找到另一個字串的第一次出現位置，我們可以使用多種方法，例如子字串搜尋演算法。最簡單的方法是使用內建的字串匹配函式，但我們也可以實現更高效的演算法，如KMP（Knuth-Morris-Pratt）演算法。為了簡潔起見，這裡使用簡單的暴力匹配演算法來實現這個功能。

以下是詳細的 Java 實現：

```java
class Solution {
    public int strStr(String haystack, String needle) {
        if (needle.isEmpty()) {
            return 0;
        }

        int haystackLength = haystack.length();
        int needleLength = needle.length();

        for (int i = 0; i <= haystackLength - needleLength; i++) {
            int j = 0;
            while (j < needleLength && haystack.charAt(i + j) == needle.charAt(j)) {
                j++;
            }
            if (j == needleLength) {
                return i;
            }
        }

        return -1;
    }

    public static void main(String[] args) {
        Solution sol = new Solution();
        System.out.println(sol.strStr("hello", "ll")); // 應輸出 2
        System.out.println(sol.strStr("aaaaa", "bba")); // 應輸出 -1
        System.out.println(sol.strStr("", "")); // 應輸出 0
        System.out.println(sol.strStr("abc", "c")); // 應輸出 2
        System.out.println(sol.strStr("abc", "d")); // 應輸出 -1
    }
}
```

### 說明

1. **特殊情況處理**：

   - 如果 `needle` 是空字串，返回 0，因為空字串在任何字串中的起始位置都是 0。

2. **暴力匹配演算法**：

   - 遍歷 `haystack` 字串，從位置 0 到 `haystackLength - needleLength`。

   - 對於每個位置，檢查從當前位置開始的子字串是否與 `needle` 相匹配。

   - 如果找到匹配的子字串，返回其起始位置。

   - 如果遍歷完成後沒有找到匹配的子字串，返回 -1。

這種方法的時間複雜度是 O((N - L) \* L)，其中 N 是 `haystack` 的長度，L 是 `needle` 的長度。對於較短的字串，這種方法是可行的。如果需要處理更長的字串，可以考慮使用更高效的字串匹配演算法，例如KMP演算法。
