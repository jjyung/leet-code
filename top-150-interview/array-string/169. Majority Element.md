# 169. Majority Element

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given an array `nums` of size `n`, return *the majority element*.

The majority element is the element that appears more than `⌊n / 2⌋` times. You may assume that the majority element always exists in the array.

<https://leetcode.com/problems/majority-element/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

要找出陣列中的多數元素（出現次數超過 ⌊n / 2⌋ 的元素），可以使用 Boyer-Moore 投票演算法。這種演算法的時間複雜度是 O(n)，空間複雜度是 O(1)。

以下是詳細的 Java 實現：

```java
class Solution {
    public int majorityElement(int[] nums) {
        int count = 0;
        Integer candidate = null;

        for (int num : nums) {
            if (count == 0) {
                candidate = num;
            }
            count += (num == candidate) ? 1 : -1;
        }

        return candidate;
    }
}
```

### 說明

1. **初始化**：

   - `count` 用來記錄當前候選多數元素的計數。

   - `candidate` 用來記錄當前的候選多數元素。

2. **遍歷陣列**：

   - 如果 `count` 為 0，則將當前元素 `num` 設定為 `candidate`。

   - 如果當前元素 `num` 等於 `candidate`，則 `count` 加 1。

   - 否則，`count` 減 1。

3. **返回結果**：

   - 遍歷完成後，`candidate` 即為陣列中的多數元素。

這個演算法利用了多數元素的性質，即多數元素的出現次數超過陣列長度的一半，因此在進行元素的配對和計數時，最終剩下的元素就是多數元素。
