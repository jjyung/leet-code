# 088. Merge Sorted Array

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

You are given two integer arrays `nums1` and `nums2`, sorted in **non-decreasing order**, and two integers `m` and `n`, representing the number of elements in `nums1` and `nums2` respectively.

**Merge** `nums1` and `nums2` into a single array sorted in **non-decreasing order**.

The final sorted array should not be returned by the function, but instead be *stored inside the array* `nums1`. To accommodate this, `nums1` has a length of `m + n`, where the first `m` elements denote the elements that should be merged, and the last `n` elements are set to `0` and should be ignored. `nums2` has a length of `n`.

<https://leetcode.com/problems/merge-sorted-array/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

要解決這個問題，我們可以利用從後往前合併的方法，這樣可以避免覆蓋 `nums1` 中的有效元素。下面是詳細的 Java 實現：

```java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        // 定義三個指標
        int p1 = m - 1; // nums1 中最後一個有效元素的索引
        int p2 = n - 1; // nums2 中最後一個元素的索引
        int p = m + n - 1; // nums1 中最後一個位置的索引

        // 從後向前遍歷陣列
        while (p1 >= 0 && p2 >= 0) {
            if (nums1[p1] > nums2[p2]) {
                nums1[p] = nums1[p1];
                p1--;
            } else {
                nums1[p] = nums2[p2];
                p2--;
            }
            p--;
        }

        // 如果 nums2 還有剩餘元素
        while (p2 >= 0) {
            nums1[p] = nums2[p2];
            p2--;
            p--;
        }
    }
}
```

### 說明

1. **指標初始化**：`p1` 指向 `nums1` 中最後一個有效元素，`p2` 指向 `nums2` 中最後一個元素，`p` 指向 `nums1` 中最後一個位置。

2. **從後向前遍歷**：比較 `nums1[p1]` 和 `nums2[p2]`，把較大的值放到 `nums1[p]` 中，然後相應地移動指標。

3. **處理剩餘元素**：如果 `nums2` 中還有剩餘元素（`p2` 沒有遍歷完），繼續把 `nums2` 中的元素複製到 `nums1` 中。

這樣可以避免覆蓋 `nums1` 中的有效元素，並且確保合併後的陣列是有序的。
