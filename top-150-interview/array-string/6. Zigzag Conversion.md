# 6. Zigzag Conversion

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

The string `"PAYPALISHIRING"` is written in a zigzag pattern on a given number of rows like this: (you may want to display this pattern in a fixed font for better legibility)

```plain
P   A   H   N
A P L S I I G
Y   I   R
```

And then read line by line: `"PAHNAPLSIIGYIR"`

Write the code that will take a string and make this conversion given a number of rows:

```java
string convert(string s, int numRows);
```

<https://leetcode.com/problems/zigzag-conversion/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

我們可以直接計算每個字元在Z字形圖案中的行號：

```java
class Solution {
    public String convert(String s, int numRows) {
        if (numRows == 1 || numRows >= s.length()) {
            return s;
        }

        // 建立一個字串陣列來儲存每一行的字元
        StringBuilder[] rows = new StringBuilder[numRows];
        for (int i = 0; i < numRows; i++) {
            rows[i] = new StringBuilder();
        }

        int len = s.length();
        int cycleLen = 2 * numRows - 2; // 一個週期的長度

        // 遍歷字串，將每個字元新增到對應的行中
        for (int i = 0; i < len; i++) {
            int rowIndex = i % cycleLen;
            if (rowIndex >= numRows) {
                rowIndex = cycleLen - rowIndex;
            }
            rows[rowIndex].append(s.charAt(i));
        }

        // 將所有行的字串連線起來
        StringBuilder result = new StringBuilder();
        for (StringBuilder row : rows) {
            result.append(row);
        }

        return result.toString();
    }

    public static void main(String[] args) {
        Solution sol = new Solution();
        System.out.println(sol.convert("PAYPALISHIRING", 3)); // 應輸出 "PAHNAPLSIIGYIR"
        System.out.println(sol.convert("PAYPALISHIRING", 4)); // 應輸出 "PINALSIGYAHRPI"
        System.out.println(sol.convert("A", 1)); // 應輸出 "A"
    }
}
```

### 說明

1. **特殊情況處理**：

   - 如果 `numRows` 為 1，直接返回原字串，因為不需要進行轉換。

2. **建立行的儲存結構**：

   - 使用一個 `StringBuilder` 陣列 `rows` 來儲存每一行的字元。每個 `StringBuilder` 對應一個行。

3. **計算週期長度**：

   - `cycleLen` 等於 `2 * numRows - 2`，表示一個完整的上下波動週期的長度。

4. **遍歷字串**：

   - 對於每個字元，通過 `i % cycleLen` 計算其在週期中的位置。

   - 如果計算結果大於等於 `numRows`，需要計算其對應的行號 `rowIndex`，即 `cycleLen - rowIndex`。

5. **連線所有行**：

   - 遍歷 `rows` 陣列，將所有行的字串連線起來形成最終結果。

6. **返回結果**：

   - 將最終結果字串返回。

這種方法通過計算每個字元在週期中的位置，可以直接將字元分配到對應的行，從而實現更高效的Z字形轉換。
