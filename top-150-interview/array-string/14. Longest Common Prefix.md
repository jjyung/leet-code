# 14. Longest Common Prefix

## Question

<span style="color: #16a34a;"><strong>Easy</strong></span>

Write a function to find the longest common prefix string amongst an array of strings.

If there is no common prefix, return an empty string `""`.

<https://leetcode.com/problems/longest-common-prefix/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

要找到字串陣列中的最長公共字首，我們可以使用以下方法：

1. 選擇第一個字串作為基準字首。

2. 遍歷陣列中的其他字串，逐個比較並更新字首。

3. 如果在任何時刻字首變為空，立即返回空字串。

4. 最後返回最長公共字首。

以下是詳細的 Java 實現：

```java
class Solution {
    public String longestCommonPrefix(String[] strs) {
        if (strs == null || strs.length == 0) {
            return "";
        }

        // 初始化字首為第一個字串
        String prefix = strs[0];

        // 從第二個字串開始遍歷
        for (int i = 1; i < strs.length; i++) {
            // 當前字串與字首比較
            while (strs[i].indexOf(prefix) != 0) {
                // 減少字首長度
                prefix = prefix.substring(0, prefix.length() - 1);
                // 如果字首變為空，返回空字串
                if (prefix.isEmpty()) {
                    return "";
                }
            }
        }

        return prefix;
    }

    public static void main(String[] args) {
        Solution sol = new Solution();
        String[] strs1 = {"flower", "flow", "flight"};
        System.out.println(sol.longestCommonPrefix(strs1)); // 應輸出 "fl"

        String[] strs2 = {"dog", "racecar", "car"};
        System.out.println(sol.longestCommonPrefix(strs2)); // 應輸出 ""

        String[] strs3 = {"interview", "intermediate", "internal"};
        System.out.println(sol.longestCommonPrefix(strs3)); // 應輸出 "inte"

        String[] strs4 = {"a"};
        System.out.println(sol.longestCommonPrefix(strs4)); // 應輸出 "a"

        String[] strs5 = {};
        System.out.println(sol.longestCommonPrefix(strs5)); // 應輸出 ""
    }
}
```

### 說明

1. **初始化字首**：

   - 使用陣列的第一個字串作為初始字首。

2. **遍歷字串陣列**：

   - 從第二個字串開始遍歷，逐個與當前字首進行比較。

3. **更新字首**：

   - 使用 `indexOf` 方法檢查當前字串是否以當前字首開頭。

   - 如果不是，逐步減少字首的長度，直到找到匹配的字首或者字首變為空。

4. **返回結果**：

   - 遍歷完成後，返回最終的字首。如果在任何時候字首變為空，則返回空字串。

這種方法通過逐步縮短字首，確保找到最長公共字首。時間複雜度是 O(S)，其中 S 是所有字串中字元數量的總和。
