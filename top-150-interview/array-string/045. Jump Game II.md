# 045. Jump Game II

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

You are given a **0-indexed** array of integers `nums` of length `n`. You are initially positioned at `nums[0]`.

Each element `nums[i]` represents the maximum length of a forward jump from index `i`. In other words, if you are at `nums[i]`, you can jump to any `nums[i + j]` where:

- `0 <= j <= nums[i]` and

- `i + j < n`

Return *the minimum number of jumps to reach* `nums[n - 1]`. The test cases are generated such that you can reach `nums[n - 1]`.

<https://leetcode.com/problems/jump-game-ii/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

要解決這個問題，我們可以使用貪心演算法和BFS（廣度優先搜尋）的思想來找到最少的跳躍次數。我們維護一個變數 `end` 來記錄當前跳躍的範圍，另一個變數 `farthest` 來記錄在當前跳躍範圍內可以到達的最遠位置。每次跳躍後更新這兩個變數，同時增加跳躍次數。

以下是詳細的 Java 實現：

```java
class Solution {
    public int jump(int[] nums) {
        int jumps = 0;
        int currentEnd = 0;
        int farthest = 0;

        for (int i = 0; i < nums.length - 1; i++) {
            // 更新可以到達的最遠位置
            farthest = Math.max(farthest, i + nums[i]);

            // 到達當前跳躍的末尾
            if (i == currentEnd) {
                jumps++; // 增加跳躍次數
                currentEnd = farthest; // 更新當前跳躍的末尾

                // 提前結束，如果已到達或超過最後一個位置
                if (currentEnd >= nums.length - 1) {
                    break;
                }
            }
        }

        return jumps;
    }
}
```

### 說明

1. **初始化變數**：

   - `jumps` 用來記錄跳躍次數，初始化為 0。

   - `currentEnd` 用來記錄當前跳躍的末尾，初始化為 0。

   - `farthest` 用來記錄在當前跳躍範圍內可以到達的最遠位置，初始化為 0。

2. **遍歷陣列**：

   - 從第一個元素開始遍歷陣列到倒數第二個元素。

   - 更新 `farthest` 為當前索引 `i` 和 `nums[i]` 的和與當前 `farthest` 的最大值。

   - 如果當前索引 `i` 達到了 `currentEnd`，說明需要進行一次跳躍：

      - 增加 `jumps` 計數。

      - 更新 `currentEnd` 為 `farthest`。

      - 如果 `currentEnd` 已經到達或超過最後一個索引，則提前結束迴圈。

3. **返回結果**：

   - 遍歷結束後返回 `jumps`，即為最少的跳躍次數。

這個演算法的時間複雜度是 O(n)，空間複雜度是 O(1)，通過一次遍歷陣列就能找到到達最後一個位置的最少跳躍次數。
