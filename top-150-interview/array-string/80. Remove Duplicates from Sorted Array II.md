# 80. Remove Duplicates from Sorted Array II

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an integer array `nums` sorted in **non-decreasing order**, remove some duplicates **[in-place](https://en.wikipedia.org/wiki/In-place_algorithm)** such that each unique element appears **at most twice**. The **relative order** of the elements should be kept the **same**.

Since it is impossible to change the length of the array in some languages, you must instead have the result be placed in the **first part** of the array `nums`. More formally, if there are `k` elements after removing the duplicates, then the first `k` elements of `nums` should hold the final result. It does not matter what you leave beyond the first `k` elements.

Return `k` *after placing the final result in the first* `k` *slots of* `nums`.

Do **not** allocate extra space for another array. You must do this by **modifying the input array [in-place](https://en.wikipedia.org/wiki/In-place_algorithm)** with O(1) extra memory.

<https://leetcode.com/problems/remove-duplicates-from-sorted-array-ii/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

這個問題可以通過雙指標法來解決，一個指標用來遍歷整個陣列，另一個指標用來標記修改後陣列的位置。下面是詳細的 Java 實現：

```java
class Solution {
    public int removeDuplicates(int[] nums) {
        // 如果陣列長度小於等於 2，直接返回其長度
        if (nums.length <= 2) return nums.length;

        // 用於標記新陣列的位置
        int k = 2;

        // 從第三個元素開始遍歷陣列
        for (int i = 2; i < nums.length; i++) {
            // 如果當前元素不等於 nums[k-2]，則將其放在 nums[k] 位置，並將 k 增加 1
            if (nums[i] != nums[k - 2]) {
                nums[k] = nums[i];
                k++;
            }
        }

        // 返回新陣列的長度
        return k;
    }
}
```

### 說明

1. **處理特殊情況**：如果陣列長度小於等於2，直接返回其長度，因為這樣的陣列本來就滿足題目的要求。

2. **初始化指標**：`k` 用於標記新陣列的位置，從2開始，因為前兩個元素總是可以保留的。

3. **遍歷陣列**：從第三個元素開始遍歷陣列。

4. **檢查條件**：如果當前元素 `nums[i]` 不等於 `nums[k-2]`，則將其放到 `nums[k]` 位置，並將 `k` 增加 1。這保證了每個元素最多出現兩次。

5. **返回結果**：遍歷完成後，`k` 即為新陣列的長度。

這個方法確保了所有元素最多出現兩次，並且保持了原來的相對順序，同時只使用了常量級別的額外空間。
