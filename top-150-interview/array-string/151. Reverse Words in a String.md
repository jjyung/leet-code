# 151. Reverse Words in a String

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an input string `s`, reverse the order of the **words**.

A **word** is defined as a sequence of non-space characters. The **words** in `s` will be separated by at least one space.

Return *a string of the words in reverse order concatenated by a single space.*

**Note** that `s` may contain leading or trailing spaces or multiple spaces between two words. The returned string should only have a single space separating the words. Do not include any extra spaces.

<https://leetcode.com/problems/reverse-words-in-a-string/submissions/1321518560/?envType=study-plan-v2&envId=top-interview-150>

## Answer

要實現將輸入字串中的單詞順序反轉並去除多餘空格，可以按照以下步驟進行：

1. 去除字串首尾的空格。

2. 使用正規表示式按空格分割字串。

3. 反轉單詞陣列。

4. 使用單個空格將反轉後的單詞陣列連線起來。

以下是詳細的 Java 實現：

```java
class Solution {
    public String reverseWords(String s) {
        // 去除首尾空格並分割字串
        String[] words = s.trim().split("\\s+");

        // 使用StringBuilder反轉陣列中的單詞
        StringBuilder reversed = new StringBuilder();

        // 反向遍歷單詞陣列
        for (int i = words.length - 1; i >= 0; i--) {
            reversed.append(words[i]);
            if (i != 0) {
                reversed.append(" ");
            }
        }

        return reversed.toString();
    }

    public static void main(String[] args) {
        Solution sol = new Solution();
        System.out.println(sol.reverseWords("the sky is blue")); // 應輸出 "blue is sky the"
        System.out.println(sol.reverseWords("  hello world  ")); // 應輸出 "world hello"
        System.out.println(sol.reverseWords("a good   example")); // 應輸出 "example good a"
        System.out.println(sol.reverseWords("  Bob    Loves  Alice   ")); // 應輸出 "Alice Loves Bob"
        System.out.println(sol.reverseWords("Alice does not even like bob")); // 應輸出 "bob like even not does Alice"
    }
}
```

### 說明

1. **去除首尾空格並分割字串**：

   - 使用 `trim()` 方法去除字串首尾的空格。

   - 使用 `split("\\s+")` 方法將字串按照一個或多個空格分割成單詞陣列。

2. **反轉陣列中的單詞**：

   - 使用 `StringBuilder` 來構建反轉後的字串。

   - 從後向前遍歷單詞陣列，將單詞依次新增到 `StringBuilder` 中。

   - 在單詞之間新增單個空格，確保最終結果中單詞之間只有一個空格。

3. **返回最終結果**：

   - 使用 `toString()` 方法將 `StringBuilder` 轉換為字串並返回。

通過這種方法，我們可以高效地反轉字串中的單詞順序，並確保單詞之間只有一個空格，滿足題目要求。
