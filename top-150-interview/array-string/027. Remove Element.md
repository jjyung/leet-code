# 027. Remove Element

## Question

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given an integer array `nums` and an integer `val`, remove all occurrences of `val` in `nums` **[in-place](https://en.wikipedia.org/wiki/In-place_algorithm)**. The order of the elements may be changed. Then return *the number of elements in* `nums` *which are not equal to* `val`.

Consider the number of elements in `nums` which are not equal to `val` be `k`, to get accepted, you need to do the following things:

- Change the array `nums` such that the first `k` elements of `nums` contain the elements which are not equal to `val`. The remaining elements of `nums` are not important as well as the size of `nums`.

- Return `k`.

<https://leetcode.com/problems/remove-element/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

這個問題可以使用雙指標方法來解決，一個指標遍歷整個陣列，另一個指標指向要保留的元素位置。下面是詳細的 Java 實現：

```java
class Solution {
    public int removeElement(int[] nums, int val) {
        // 指向新陣列的位置
        int k = 0;

        // 遍歷陣列
        for (int i = 0; i < nums.length; i++) {
            // 如果當前元素不等於 val，則將其放在新陣列中
            if (nums[i] != val) {
                nums[k] = nums[i];
                k++;
            }
        }

        // 返回新陣列的長度
        return k;
    }
}
```

### 說明

1. **初始化指標**：`k` 用來指向新陣列的位置。

2. **遍歷陣列**：使用 `for` 迴圈遍歷陣列 `nums`。

3. **檢查元素**：如果當前元素 `nums[i]` 不等於 `val`，則將其放到 `nums[k]` 位置，並將 `k` 增加 1。

4. **返回結果**：遍歷完成後，`k` 即為新陣列的長度。

這個方法確保了所有不等於 `val` 的元素都被移動到陣列的前部，並且返回新陣列的長度。
