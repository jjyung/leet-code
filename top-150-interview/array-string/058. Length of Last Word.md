# 058. Length of Last Word

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given a string `s` consisting of words and spaces, return *the length of the **last** word in the string.*

A **word** is a maximal

substring

consisting of non-space characters only.

<https://leetcode.com/problems/length-of-last-word/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

要找到字串中最後一個單詞的長度，我們可以從字串的末尾開始向前遍歷，跳過結尾的空格，然後統計最後一個單詞的長度。

以下是詳細的 Java 實現：

```java
class Solution {
    public int lengthOfLastWord(String s) {
        int i = s.length() - 1;

        // 跳過末尾的空格
        while (i >= 0 && s.charAt(i) == ' ') {
            i--;
        }

        // 計算最後一個單詞的長度
        int length = i;
        while (i >= 0 && s.charAt(i) != ' ') {
            i--;
        }

        return length - i;
    }

    public static void main(String[] args) {
        Solution sol = new Solution();
        System.out.println(sol.lengthOfLastWord("Hello World"));     // 應輸出 5
        System.out.println(sol.lengthOfLastWord("   fly me   to   the moon  ")); // 應輸出 4
        System.out.println(sol.lengthOfLastWord("luffy is still joyboy")); // 應輸出 6
        System.out.println(sol.lengthOfLastWord("a")); // 應輸出 1
        System.out.println(sol.lengthOfLastWord(" ")); // 應輸出 0
    }
}
```

### 說明

1. **初始化變數**：

   - `length` 用來記錄最後一個單詞的長度。

   - `i` 初始化為字串的最後一個字元的索引。

2. **跳過末尾的空格**：

   - 使用一個 `while` 迴圈，從字串的末尾開始向前遍歷，跳過所有的空格字元。

3. **計算最後一個單詞的長度**：

   - 繼續向前遍歷，直到遇到空格字元或遍歷到字串的開頭，期間累加 `length` 變數。

4. **返回結果**：

   - 遍歷完成後，`length` 即為最後一個單詞的長度。

這個方法通過兩次遍歷字串（一次跳過末尾的空格，一次計算最後一個單詞的長度），能夠高效地找到字串中最後一個單詞的長度。
