# 189. Rotate Array

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an integer array `nums`, rotate the array to the right by `k` steps, where `k` is non-negative.

<https://leetcode.com/problems/rotate-array/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

要將一個整數陣列向右旋轉 k 步，可以使用三步反轉法。這種方法的時間複雜度是 O(n)，空間複雜度是 O(1)。

以下是詳細的 Java 實現：

```java
class Solution {
    public void rotate(int[] nums, int k) {
        int n = nums.length;
        k = k % n; // 若 k 大於陣列長度，取模以確保不超出範圍

        // 步驟一：反轉整個陣列
        reverse(nums, 0, n - 1);
        // 步驟二：反轉前 k 個元素
        reverse(nums, 0, k - 1);
        // 步驟三：反轉後 n-k 個元素
        reverse(nums, k, n - 1);
    }

    // 反轉陣列指定範圍內的元素
    private void reverse(int[] nums, int start, int end) {
        while (start < end) {
            int temp = nums[start];
            nums[start] = nums[end];
            nums[end] = temp;
            start++;
            end--;
        }
    }
}
```

### 說明

1. **取模運算**：

   - 由於 k 可能大於陣列的長度，需要對 k 取模以確保 k 在陣列長度範圍內。

2. **三步反轉法**：

   - **步驟一**：反轉整個陣列，使陣列順序顛倒。

   - **步驟二**：反轉前 k 個元素，使其恢復到正確的位置。

   - **步驟三**：反轉後 n-k 個元素，使其恢復到正確的位置。

3. \*\*輔助函式 `reverse`\*\*：

   - 反轉陣列中指定範圍內的元素，通過交換首尾元素來實現。

這個方法高效地在 O(n) 時間內完成陣列的旋轉，並且只使用了 O(1) 的額外空間。
