# 274. H-Index

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an array of integers `citations` where `citations[i]` is the number of citations a researcher received for their `ith` paper, return *the researcher's h-index*.

According to the [definition of h-index on Wikipedia](https://en.wikipedia.org/wiki/H-index): The h-index is defined as the maximum value of `h` such that the given researcher has published at least `h` papers that have each been cited at least `h` times.

<https://leetcode.com/problems/h-index/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

要計算研究者的 h-index，可以使用排序的方法。首先將引用次數的陣列按從大到小排序，然後找到最大值 h 使得至少有 h 篇論文的引用次數不小於 h。下面是詳細的 Java 實現：

```java
import java.util.Arrays;

class Solution {
    public int hIndex(int[] citations) {
        // 將引用次數的陣列按從大到小排序
        Arrays.sort(citations);
        
        int n = citations.length;
        for (int i = 0; i < n; i++) {
            int h = n - i;
            if (citations[i] >= h) {
                return h;
            }
        }
        
        return 0;
    }
}
```

### 說明

1. **排序**：

   - 使用 `Arrays.sort` 將引用次數陣列按從小到大排序。

2. **計算 h-index**：

   - `n` 為陣列的長度。

   - 從左到右遍歷排序後的陣列。對於每個引用次數 `citations[i]`，計算可能的 h 值 `h = n - i`。

   - 如果 `citations[i] >= h`，說明至少有 `h` 篇論文的引用次數不小於 `h`，返回這個 `h` 值。

3. **返回結果**：

   - 如果遍歷結束後仍未找到符合條件的 h 值，則返回 0。

這個演算法的時間複雜度是 O(n log n)（由於排序操作），空間複雜度是 O(1)。這樣可以有效地找到研究者的 h-index。
