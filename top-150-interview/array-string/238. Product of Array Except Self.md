# 238. Product of Array Except Self

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an integer array `nums`, return *an array* `answer` *such that* `answer[i]` *is equal to the product of all the elements of* `nums` *except* `nums[i]`.

The product of any prefix or suffix of `nums` is **guaranteed** to fit in a **32-bit** integer.

You must write an algorithm that runs in `O(n)` time and without using the division operation.

<https://leetcode.com/problems/product-of-array-except-self/?envType=study-plan-v2&envId=top-interview-150>

## Answer

要實現這個功能，我們可以使用兩次遍歷的方法來計算每個位置的字首積和字尾積，從而在 O(n) 的時間內完成計算，並且不使用除法運算。具體步驟如下：

1. 首先計算每個位置的字首積，並儲存在一個陣列中。

2. 然後計算每個位置的字尾積，並將結果乘以對應位置的字首積。

以下是詳細的 Java 實現：

```java
class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] answer = new int[n];

        // 計算字首積
        answer[0] = 1;
        for (int i = 1; i < n; i++) {
            answer[i] = answer[i - 1] * nums[i - 1];
        }

        // 計算字尾積並更新結果
        int suffixProduct = 1;
        for (int i = n - 1; i >= 0; i--) {
            answer[i] = answer[i] * suffixProduct;
            suffixProduct *= nums[i];
        }

        return answer;
    }

    public static void main(String[] args) {
        Solution sol = new Solution();
        int[] nums = {1, 2, 3, 4};
        int[] result = sol.productExceptSelf(nums);
        
        for (int num : result) {
            System.out.print(num + " "); // 應輸出 24 12 8 6
        }
    }
}
```

### 說明

1. **初始化**：

   - `n` 是輸入陣列 `nums` 的長度。

   - `answer` 是儲存最終結果的陣列。

2. **計算字首積**：

   - 初始化 `answer[0]` 為 1，因為對於第一個元素而言，前面沒有元素。

   - 遍歷陣列，對於每個位置 `i`，計算 `answer[i]` 為 `answer[i - 1]` 與 `nums[i - 1]` 的乘積。

3. **計算字尾積並更新結果**：

   - 初始化 `suffixProduct` 為 1，這代表字尾積的初始值。

   - 從後向前遍歷陣列，對於每個位置 `i`，將 `answer[i]` 乘以當前的 `suffixProduct`，然後更新 `suffixProduct` 為 `suffixProduct` 與 `nums[i]` 的乘積。

4. **返回結果**：

   - 遍歷結束後，`answer` 陣列即為所求結果。

這樣我們就能在 O(n) 的時間內完成計算，並且不使用除法運算。
