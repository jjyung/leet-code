## Problem

Design a data structure that supports adding new words and finding if a string matches any previously added string.

Implement the WordDictionary class:

WordDictionary() Initializes the object.
void addWord(word) Adds word to the data structure, it can be matched later.
bool search(word) Returns true if there is any string in the data structure that matches word or false otherwise. word may contain dots '.' where dots can be matched with any letter.

### Example 1

```text
Input: ["WordDictionary","addWord","addWord","addWord","search","search","search","search"]
Arguments: [[],["bad"],["dad"],["mad"],["pad"],["bad"],[".ad"],["b.."]]
Output: [null,null,null,null,false,true,true,true]

Explanation:
WordDictionary wordDictionary = new WordDictionary();
wordDictionary.addWord("bad");
wordDictionary.addWord("dad");
wordDictionary.addWord("mad");
wordDictionary.search("pad"); // return False
wordDictionary.search("bad"); // return True
wordDictionary.search(".ad"); // return True
wordDictionary.search("b.."); // return True
```

Constraints:

1 <= word.length <= 25
word in addWord consists of lowercase English letters.
word in search consist of '.' or lowercase English letters.
There will be at most 2 dots in word for search queries.
At most 104 calls will be made to addWord and search.

## Answer

### 解題思路

使用 Trie 儲存所有加入的單字。每個節點有 26 個子節點，`isWord` 表示從根節點走到此處是否剛好形成一個完整單字。

`addWord` 逐字建立或走訪對應的子節點，最後將終點標記為完整單字。`search` 使用 DFS：

1. 遇到英文字母時，只能走向對應的子節點；若該節點不存在，代表不可能匹配。
2. 遇到 `.` 時，嘗試所有存在的子節點，只要其中一條路徑成功即可回傳 `true`。
3. 搜尋完所有字元後，只有當目前節點的 `isWord` 為 `true` 才算匹配成功，因此不同長度的單字不會被誤判。

### Java

```java
class WordDictionary {
    private static class TrieNode {
        // children[index] 代表下一個字元為 ('a' + index) 的子節點。
        TrieNode[] children = new TrieNode[26];

        // 目前節點是否代表一個已經完整加入的單字。
        boolean isWord;
    }

    // 根節點代表空字串，所有單字都從此節點開始建立路徑。
    private final TrieNode root = new TrieNode();

    public void addWord(String word) {
        TrieNode currentNode = root;

        for (int index = 0; index < word.length(); index++) {
            // 將目前字元轉成 0 到 25 的子節點索引。
            int childIndex = word.charAt(index) - 'a';
            if (currentNode.children[childIndex] == null) {
                // 共用已存在的前綴，只有在必要時才建立新節點。
                currentNode.children[childIndex] = new TrieNode();
            }
            currentNode = currentNode.children[childIndex];
        }

        // 路徑可能還會延伸成更長單字，因此用標記區分完整單字與前綴。
        currentNode.isWord = true;
    }

    public boolean search(String word) {
        // 從根節點開始，依序比對查詢字串的每個字元。
        return searchFrom(root, word, 0);
    }

    private boolean searchFrom(TrieNode currentNode, String word, int index) {
        if (index == word.length()) {
            // 必須是完整單字，只有前綴路徑不能算匹配成功。
            return currentNode.isWord;
        }

        char currentCharacter = word.charAt(index);
        if (currentCharacter == '.') {
            // 萬用字元可以匹配任一字母，因此嘗試所有存在的分支。
            for (TrieNode childNode : currentNode.children) {
                if (childNode != null && searchFrom(childNode, word, index + 1)) {
                    // 只要有一條分支能匹配剩餘字串，就代表查詢成功。
                    return true;
                }
            }
            // 所有可能的字母都無法匹配剩餘字串。
            return false;
        }

        // 一般字元只能沿著對應的唯一分支繼續搜尋。
        int childIndex = currentCharacter - 'a';
        TrieNode childNode = currentNode.children[childIndex];
        return childNode != null && searchFrom(childNode, word, index + 1);
    }
}
```

### 複雜度分析

令 `n` 為輸入單字的長度，`d` 為搜尋字串中 `.` 的數量。

- `addWord`：每個字元只建立或走訪一次，時間複雜度為 $O(n)$。
- `search`：固定字元只延伸一條路徑；每個 `.` 最多延伸 26 條路徑，因此最壞時間複雜度為 $O(26^d \cdot n)$，題目限制 `d <= 2`。
- 空間複雜度：Trie 儲存所有加入單字的節點，若所有單字的總字元數為 `S`，需要 $O(S)$；DFS 額外使用最多 $O(n)$ 的遞迴堆疊。

搜尋空字串時會直接檢查目前節點的 `isWord`；題目雖然保證輸入長度至少為 1，這個終止條件也能正確處理一般 Trie 邊界。
