# 130. Surrounded Regions

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

給定一個 `m x n` 的字元矩陣 `board`，每格是 `'X'` 或 `'O'`。

若一個由 `'O'` 組成的區域沒有接觸到邊界，則該區域會被 `'X'` 完全包圍。請你把所有被包圍的區域原地改為 `'X'`。

https://leetcode.com/problems/surrounded-regions/

## Answer

這題可以反向思考：

1. 與邊界連通的 `'O'` 一定不會被包圍，因此必須保留。
2. 先從四條邊上的 `'O'` 出發，使用 BFS 找出所有連通的安全格，並暫時標記成 `'#'`。
3. 掃描整個矩陣：仍然是 `'O'` 的格子代表沒有與邊界連通，應改成 `'X'`；`'#'` 則改回 `'O'`。

因此，中間的 `while` 迴圈不是在標記「圓圈」，而是在進行四方向的 flood fill：只要某個 `'O'` 能透過上下左右走到邊界，就會被標記為安全。

```java
import java.util.ArrayDeque;
import java.util.Queue;

class Solution {
    /**
     * 將所有被 'X' 包圍的 'O' 原地改成 'X'。
     *
     * @param board 由 'X' 與 'O' 組成的 m x n 字元矩陣；方法會直接修改此矩陣
     */
    public void solve(char[][] board) {
        int m = board.length;
        int n = board[0].length;

        // queue 儲存待處理的安全格座標，元素格式為 {row, col}。
        Queue<int[]> queue = new ArrayDeque<>();

        // 掃描左邊界與右邊界，先處理兩條垂直邊上的所有格子。
        for (int i = 0; i < m; i++) {
            addIfO(board, queue, i, 0);
            addIfO(board, queue, i, n - 1);
        }

        // 掃描上邊界與下邊界。四個角落可能會被重複呼叫，
        // 但 addIfO 只會加入尚未標記的 'O'，所以不會重複入隊。
        for (int j = 0; j < n; j++) {
            addIfO(board, queue, 0, j);
            addIfO(board, queue, m - 1, j);
        }

        // 四個方向依序代表：下、上、右、左。
        int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

        // 從所有邊界安全格出發，找出與邊界連通的所有 'O'。
        while (!queue.isEmpty()) {
            int[] cur = queue.poll();
            int r = cur[0];
            int c = cur[1];

            // 檢查目前格子的四個相鄰格子。
            for (int[] d : dirs) {
                int nr = r + d[0];
                int nc = c + d[1];

                // 超出矩陣範圍的座標不能處理。
                if (nr < 0 || nr >= m || nc < 0 || nc >= n) {
                    continue;
                }

                // 只有尚未標記的 'O' 才是新的安全格；'X' 與 '#' 都跳過。
                if (board[nr][nc] != 'O') {
                    continue;
                }

                // 入隊前立即標記，避免同一格被多個方向重複加入 queue。
                board[nr][nc] = '#';
                queue.offer(new int[] {nr, nc});
            }
        }

        // 最後掃描整個矩陣：未被邊界 BFS 找到的 'O' 必定被包圍，
        // 找到的 '#' 則是安全格，還原成原本的 'O'。
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (board[i][j] == 'O') {
                    board[i][j] = 'X';
                } else if (board[i][j] == '#') {
                    board[i][j] = 'O';
                }
            }
        }
    }

    /**
     * 若指定座標是 'O'，就將它標記為安全格並加入 BFS 佇列。
     *
     * @param board 要檢查並修改的字元矩陣
     * @param queue 儲存待進行 BFS 的座標佇列
     * @param row   要檢查的列索引，範圍為 0 到 board.length - 1
     * @param col   要檢查的欄索引，範圍為 0 到 board[0].length - 1
     */
    private void addIfO(char[][] board, Queue<int[]> queue, int row, int col) {
        if (board[row][col] == 'O') {
            board[row][col] = '#';
            queue.offer(new int[] {row, col});
        }
    }
}
```

### 說明

1. 從邊界做 BFS，時間複雜度為 `O(m * n)`，每格最多進出一次。
2. 空間複雜度為 `O(m * n)`，最壞情況下佇列可能存到大量格子。
3. 先標記安全格再統一翻轉，是本題最穩定且好實作的策略。
