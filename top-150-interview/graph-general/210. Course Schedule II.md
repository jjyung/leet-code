# 210. Course Schedule II

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

There are a total of numCourses courses you have to take, labeled from 0 to numCourses - 1. You are given an array prerequisites where prerequisites[i] = [ai, bi] indicates that you must take course bi first if you want to take course ai.

For example, the pair [0, 1], indicates that to take course 0 you have to first take course 1.
Return the ordering of courses you should take to finish all courses. If there are many valid answers, return any of them. If it is impossible to finish all courses, return an empty array.

### Example 1

```text
Input: numCourses = 2, prerequisites = [[1,0]]
Output: [0,1]
Explanation: There are a total of 2 courses to take. To take course 1 you should have finished course 0. So the correct course order is [0,1].
```

### Example 2

```text
Input: numCourses = 4, prerequisites = [[1,0],[2,0],[3,1],[3,2]]
Output: [0,2,1,3]
Explanation: There are a total of 4 courses to take. To take course 3 you should have finished both courses 1 and 2. Both courses 1 and 2 should be taken after you finished course 0. So one correct course order is [0,1,2,3]. Another correct ordering is [0,2,1,3].
```

### Example 3

```text
Input: numCourses = 1, prerequisites = []
Output: [0]
Explanation: There is only one course to take, so the order is [0].
```

### Constraints

- 1 <= numCourses <= 2000
- 0 <= prerequisites.length <= numCourses * (numCourses - 1)
- prerequisites[i].length == 2
- 0 <= ai, bi < numCourses
- ai != bi
- All the pairs [ai, bi] are distinct.

## Answer

### 解題思路

把每門課視為有向圖中的一個節點。若 `prerequisites[i] = [a, b]`，代表必須先修 `b` 再修 `a`，因此建立一條 `b -> a` 的邊。`indegree[a]` 記錄課程 `a` 尚未完成的先修課數量；入度為 0 的課程就是目前可以修的候選。

使用 Kahn 拓樸排序：先把所有入度為 0 的課程放入佇列。每次取出一門可修課程並加入答案，再將它指向的後續課程入度減一；某門課入度降為 0 時，代表它的所有先修課都已排入答案，便可加入佇列。若最後排入答案的課程數少於 `numCourses`，表示圖中有環，無法完成所有課程，回傳空陣列。

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.List;
import java.util.Queue;

class Solution {
    public int[] findOrder(int numCourses, int[][] prerequisites) {
        // graph.get(course) 儲存修完 course 後可以接著修的課程。
        List<List<Integer>> graph = new ArrayList<>();
        for (int course = 0; course < numCourses; course++) {
            graph.add(new ArrayList<>());
        }

        int[] indegree = new int[numCourses];
        for (int[] prerequisite : prerequisites) {
            int course = prerequisite[0];
            int requiredCourse = prerequisite[1];

            // 邊 requiredCourse -> course 表示先修課完成後才能修 course。
            graph.get(requiredCourse).add(course);
            indegree[course]++;
        }

        // 入度為 0 代表沒有尚未完成的先修課，先作為可修課程候選。
        Queue<Integer> availableCourses = new ArrayDeque<>();
        for (int course = 0; course < numCourses; course++) {
            if (indegree[course] == 0) {
                availableCourses.offer(course);
            }
        }

        int[] order = new int[numCourses];
        int orderIndex = 0;
        while (!availableCourses.isEmpty()) {
            int completedCourse = availableCourses.poll();
            order[orderIndex++] = completedCourse;

            // 修完一門課後，移除它對後續課程造成的先修依賴。
            for (int nextCourse : graph.get(completedCourse)) {
                indegree[nextCourse]--;
                if (indegree[nextCourse] == 0) {
                    // 所有先修依賴都已處理，這門課現在也可以修讀。
                    availableCourses.offer(nextCourse);
                }
            }
        }

        // 有環時，環上的課程入度不會降為 0，故無法排出全部課程。
        if (orderIndex != numCourses) {
            return new int[0];
        }
        return order;
    }
}
```

### 說明

設 `n = numCourses`，`m = prerequisites.length`。

- **正確性判斷**：只有在所有先修課都已處理後，課程的入度才會變成 0 並進入佇列；因此答案中的每門課都排在其先修課之後。若有環，環內課程會互相等待，最終無法排入答案。
- **邊界條件**：沒有先修關係時，所有課程一開始都會入列，包含只有一門課的情況；若有環，處理數量會小於 `n`，回傳空陣列。互不相依的課程可以用任何順序排列。
- **時間複雜度**：`O(n + m)`。每門課最多入列與取出一次，每條先修關係只更新一次。
- **空間複雜度**：`O(n + m)`，用來儲存鄰接串列、入度陣列、佇列與結果陣列。
