# 207. Course Schedule

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

There are a total of numCourses courses you have to take, labeled from 0 to numCourses - 1. You are given an array prerequisites where prerequisites[i] = [ai, bi] indicates that you must take course bi first if you want to take course ai.

For example, the pair [0, 1], indicates that to take course 0 you have to first take course 1.
Return true if you can finish all courses. Otherwise, return false.

### Example 1

```text
Input: numCourses = 2, prerequisites = [[1,0]]
Output: true
Explanation: There are a total of 2 courses to take.
To take course 1 you should have finished course 0. So it is possible.
```

### Example 2

```text
Input: numCourses = 2, prerequisites = [[1,0],[0,1]]
Output: false
Explanation: There are a total of 2 courses to take.
To take course 1 you should have finished course 0, and to take course 0 you should also have finished course 1. So it is impossible.
```

### Constraints

1 <= numCourses <= 2000
0 <= prerequisites.length <= 5000
prerequisites[i].length == 2
0 <= ai, bi < numCourses
All the pairs prerequisites[i] are unique.

## Answer

### 解題思路

把每門課視為有向圖中的一個節點。若 `prerequisites[i] = [a, b]`，代表必須先修 `b` 再修 `a`，因此建立一條 `b -> a` 的邊。若圖中有環，環上的課程會互相等待，無法全部完成；若能依序移除所有入度為 0 的課程，則可以完成所有課程。

使用 Kahn 拓樸排序：先將所有入度為 0 的課程放入佇列。每次取出一門可修課程，並將它指向的後續課程入度減一；某門課入度降為 0 時，代表其所有先修課都已完成，可以加入佇列。最後比較已處理課程數與 `numCourses`，即可判斷是否存在環。

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.List;
import java.util.Queue;

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // graph.get(course) 儲存修完 course 後可以接著修的課程。
        List<List<Integer>> graph = new ArrayList<>();
        for (int course = 0; course < numCourses; course++) {
            graph.add(new ArrayList<>());
        }

        int[] indegree = new int[numCourses];
        for (int[] prerequisite : prerequisites) {
            int course = prerequisite[0];
            int requiredCourse = prerequisite[1];

            // 邊 requiredCourse -> course 表示先修課完成後才能修 course。
            graph.get(requiredCourse).add(course);
            indegree[course]++;
        }

        // 入度為 0 代表沒有尚未完成的先修課，因此可作為第一批修課候選。
        Queue<Integer> availableCourses = new ArrayDeque<>();
        for (int course = 0; course < numCourses; course++) {
            if (indegree[course] == 0) {
                availableCourses.offer(course);
            }
        }

        int completedCourses = 0;
        while (!availableCourses.isEmpty()) {
            int completedCourse = availableCourses.poll();
            completedCourses++;

            // 完成一門課後，移除它對後續課程造成的先修依賴。
            for (int nextCourse : graph.get(completedCourse)) {
                indegree[nextCourse]--;
                if (indegree[nextCourse] == 0) {
                    // 所有先修依賴都已移除，這門課現在也可以修讀。
                    availableCourses.offer(nextCourse);
                }
            }
        }

        // 有環時，環上的課程入度無法降為 0，因此不會全部完成。
        return completedCourses == numCourses;
    }
}
```

### 複雜度與邊界條件

- 時間複雜度：`O(n + m)`，其中 `n = numCourses`、`m = prerequisites.length`。每門課入列與處理一次，每條先修關係也只更新一次。
- 空間複雜度：`O(n + m)`，用來儲存鄰接串列、入度陣列與佇列。
- 沒有先修關係時，所有課程初始入度皆為 0，會全部加入佇列並回傳 `true`。存在自我先修或較長的環時，相關課程不會被處理，最終回傳 `false`。
