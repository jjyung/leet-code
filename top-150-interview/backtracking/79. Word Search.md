# 79. Word Search

## Problem

<!-- markdownlint-disable MD033 -->
<span style="color: #f59e0b;"><strong>Medium</strong></span>
<!-- markdownlint-enable MD033 -->

Given an `m x n` grid of characters `board` and a string `word`, return `true` if `word` exists in the grid.

The word can be constructed from letters of sequentially adjacent cells, where adjacent cells are horizontally or vertically neighboring. The same letter cell may not be used more than once.

### Example 1

```text
Input: board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCCED"
Output: true
Explanation: The word can be constructed by following adjacent cells: A -> B -> C -> C -> E -> D.
```

### Example 2

```text
Input: board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "SEE"
Output: true
Explanation: The word can be constructed by following adjacent cells: S -> E -> E.
```

### Example 3

```text
Input: board = [["A","B","C","E"],["S","F","C","S"],["A","D","E","E"]], word = "ABCB"
Output: false
Explanation: The only B cell would have to be used twice, so the word cannot be formed.
```

### Constraints

```text
m == board.length
n = board[i].length
1 <= m, n <= 6
1 <= word.length <= 15
board and word consists of only lowercase and uppercase English letters.
```

Follow up: Could you use search pruning to make your solution faster with a larger board?

## Answer

### 解題思路

使用深度優先搜尋（DFS）逐格嘗試，並以回溯法追蹤目前已匹配的路徑。每一步只能移動到上下左右相鄰的格子；進入格子後先暫時標記，避免同一條路徑重複使用該格，搜尋返回時再還原字元。

開始搜尋前先統計棋盤與 `word` 中各字元的出現次數。若 `word` 需要的任一字元比棋盤中還多，就能立即判定不存在。接著比較 `word` 首尾字元在棋盤中的頻率；若首字元較常見，便反轉 `word`，改從較少見的字元開始搜尋。上下左右的相鄰關係是雙向的，因此反轉後存在路徑，等價於原字串存在反向路徑。

### Java 程式碼

```java
class Solution {
    private static final int[][] DIRECTIONS = {
        {1, 0}, {-1, 0}, {0, 1}, {0, -1}
    };

    public boolean exist(char[][] board, String word) {
        int rows = board.length;
        int columns = board[0].length;
        int[] boardFrequency = new int[128];
        int[] wordFrequency = new int[128];

        // 題目限定英文字母，以固定大小陣列統計兩邊的字元數量。
        for (int row = 0; row < rows; row++) {
            for (int column = 0; column < columns; column++) {
                boardFrequency[board[row][column]]++;
            }
        }
        for (int index = 0; index < word.length(); index++) {
            wordFrequency[word.charAt(index)]++;
        }

        // 棋盤缺少任何必要字元時，不可能組成目標字串。
        for (int character = 0; character < boardFrequency.length; character++) {
            if (wordFrequency[character] > boardFrequency[character]) {
                return false;
            }
        }

        // 從較少見的端點開始，可減少外層 DFS 的起始位置。
        if (boardFrequency[word.charAt(0)]
                > boardFrequency[word.charAt(word.length() - 1)]) {
            word = new StringBuilder(word).reverse().toString();
        }

        for (int row = 0; row < rows; row++) {
            for (int column = 0; column < columns; column++) {
                if (search(board, word, row, column, 0)) {
                    return true;
                }
            }
        }
        return false;
    }

    private boolean search(char[][] board, String word, int row, int column, int index) {
        // 超出邊界或字元不符時，這條路徑無法繼續。
        if (row < 0 || row >= board.length
                || column < 0 || column >= board[0].length
                || board[row][column] != word.charAt(index)) {
            return false;
        }

        if (index == word.length() - 1) {
            return true;
        }

        char originalCharacter = board[row][column];
        // 暫時改寫目前格，讓後續遞迴不能重複使用；回傳前會還原。
        board[row][column] = '#';

        for (int[] direction : DIRECTIONS) {
            int nextRow = row + direction[0];
            int nextColumn = column + direction[1];
            if (search(board, word, nextRow, nextColumn, index + 1)) {
                board[row][column] = originalCharacter;
                return true;
            }
        }

        board[row][column] = originalCharacter;
        return false;
    }
}
```

### 複雜度與邊界條件

令 `m`、`n` 分別為棋盤的列數與欄數，`L` 為 `word.length()`。

- **時間複雜度：** 字元統計需要 `O(mn + L)`；DFS 最壞情況為 `O(mn × 3^L)`。每個格子都可能作為起點，之後每一步最多有三個方向可走，因為上一格已標記為使用中。
- **空間複雜度：** `O(L)`，來自最深為 `L` 層的遞迴堆疊；字元統計陣列大小固定為 128。搜尋會暫時修改棋盤，但每次返回前都會還原。
- **邊界條件：** 題目保證棋盤與 `word` 非空；若字元頻率不足則在 DFS 前回傳 `false`。`word` 只有一個字元時，只要棋盤含有該字元就會在起點檢查時成功。棋盤只含英文字母，因此 `'#'` 可安全作為暫時標記。
