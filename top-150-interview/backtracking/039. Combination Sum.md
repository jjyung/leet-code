# 039. Combination Sum

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an array of distinct integers candidates and a target integer target, return a list of all unique combinations of candidates where the chosen numbers sum to target. You may return the combinations in any order.

The same number may be chosen from candidates an unlimited number of times. Two combinations are unique if the frequency of at least one of the chosen numbers is different.

The test cases are generated such that the number of unique combinations that sum up to target is less than 150 combinations for the given input.

### Example 1

```text
Input: candidates = [2,3,6,7], target = 7
Output: [[2,2,3],[7]]
Explanation:
2 and 3 are candidates, and 2 + 2 + 3 = 7. Note that 2 can be used multiple times.
7 is a candidate, and 7 = 7.
These are the only two combinations.
```

### Example 2

```text
Input: candidates = [2,3,5], target = 8
Output: [[2,2,2,2],[2,3,3],[3,5]]
```

### Example 3

```text
Input: candidates = [2], target = 1
Output: []
```

### Constraints

```text
1 <= candidates.length <= 30
2 <= candidates[i] <= 40
All elements of candidates are distinct.
1 <= target <= 40
```

## Answer

### 解題思路

本題要找出總和等於 `target` 的所有候選數字組合，而且每個候選數字可以重複使用。先將候選陣列排序，再用回溯法逐步建立目前組合：

1. `start` 記錄這一層可以開始選取的候選位置。遞迴下一層時傳入目前位置 `i`，因此同一個數字仍可再次選取；候選位置只往後移，能避免產生順序不同但內容相同的組合。
2. 每次選取候選數字後，從剩餘目標值扣除它，再遞迴搜尋。
3. 當剩餘目標值為 `0`，代表找到一組答案，複製目前路徑加入結果。
4. 程式會先排序候選陣列；若排序後目前候選大於剩餘目標值，後面的候選也都不可能符合，因此可以提前結束迴圈。

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        List<List<Integer>> result = new ArrayList<>();

        // 排序副本以支援剪枝，同時保留輸入陣列原本的順序。
        int[] sortedCandidates = Arrays.copyOf(candidates, candidates.length);
        Arrays.sort(sortedCandidates);

        backtrack(sortedCandidates, target, 0, new ArrayList<>(), result);
        return result;
    }

    private void backtrack(
            int[] candidates,
            int remaining,
            int start,
            List<Integer> path,
            List<List<Integer>> result) {
        if (remaining == 0) {
            // 複製目前路徑，避免之後回溯修改已儲存的答案。
            result.add(new ArrayList<>(path));
            return;
        }

        for (int i = start; i < candidates.length; i++) {
            int candidate = candidates[i];
            if (candidate > remaining) {
                // 候選陣列已在前處理排序，後續數字只會更大，無法再組成剩餘總和。
                break;
            }

            path.add(candidate);
            // 傳入 i 而非 i + 1，允許下一層繼續使用同一個候選數字。
            backtrack(candidates, remaining - candidate, i, path, result);
            // 移除最後選入的數字，恢復目前路徑供其他分支使用。
            path.remove(path.size() - 1);
        }
    }
}
```

### 說明

令 `N` 為候選數字個數，`D = floor(target / 最小候選值)` 為遞迴深度上限，`S` 為回溯實際造訪的狀態數，`R` 為答案組數。每個狀態最多檢查 `N` 個候選，複製答案的成本最多為 `O(R × D)`，因此時間複雜度為 `O(N × S + R × D)`。額外空間複雜度為 `O(N + D)`：排序副本佔 `O(N)`，遞迴堆疊與目前路徑佔 `O(D)`；以上不計算回傳答案所需的空間。
