# 022. Generate Parentheses

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given n pairs of parentheses, write a function to generate all combinations of well-formed parentheses.

### Example 1

```text
Input: n = 3
Output: ["((()))","(()())","(())()","()(())","()()()"]
Explanation: There are five valid combinations of well-formed parentheses for n = 3.
```

### Example 2

```text
Input: n = 1
Output: ["()"]
Explanation: There is one valid combination of well-formed parentheses for n = 1.
```

### Constraints

1 <= n <= 8

## Answer

### 解題思路

使用回溯法逐字建立括號字串。`current` 儲存目前的前綴，`openCount` 與 `closeCount` 分別記錄已放入的左、右括號數量。

- 當左括號數量小於 `n` 時，可以加入 `(`。
- 只有在右括號數量小於左括號數量時，才能加入 `)`，如此可確保每個前綴都不會先關閉尚未開啟的括號。
- 字串長度到達 `2 * n` 時，收下這個完整組合。每次遞迴返回後移除剛加入的字元，讓同一個前綴能繼續探索另一種選擇。

### Java 程式碼

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> result = new ArrayList<>();
        StringBuilder current = new StringBuilder(2 * n);

        backtrack(n, 0, 0, current, result);
        return result;
    }

    private void backtrack(
        int n,
        int openCount,
        int closeCount,
        StringBuilder current,
        List<String> result
    ) {
        if (current.length() == 2 * n) {
            result.add(current.toString());
            return;
        }

        // 尚未使用完左括號時，加入左括號並探索後續選擇。
        if (openCount < n) {
            current.append('(');
            backtrack(n, openCount + 1, closeCount, current, result);
            current.deleteCharAt(current.length() - 1);
        }

        // 只有已有未配對的左括號時，才加入右括號以維持前綴合法。
        if (closeCount < openCount) {
            current.append(')');
            backtrack(n, openCount, closeCount + 1, current, result);
            current.deleteCharAt(current.length() - 1);
        }
    }
}
```

### 說明

1. `closeCount` 始終不大於 `openCount`，因此不會產生右括號多於左括號的無效前綴；字串長度達到 `2 * n` 時，兩種括號都恰好使用 `n` 個。
2. 每個合法字串都能依序選擇其下一個括號走到，且每個位置的選擇只有一條路徑，因此不會遺漏或重複產生結果。

### 複雜度分析

令 `n` 為括號對數，`C_n` 為第 `n` 個 Catalan 數，也就是合法組合的數量。

- 時間複雜度：`O(n * C_n)`。每個完整結果長度為 `2 * n`，建立並複製所有結果需要與輸出總長度成正比的時間。
- 輔助空間：`O(n)`，包含遞迴呼叫堆疊與目前的字串前綴；不計回傳結果。若計入結果列表，空間為 `O(n * C_n)`。
