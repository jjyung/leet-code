# 77. Combinations

## Problem

<!-- markdownlint-disable MD033 -->
<span style="color: #f59e0b;"><strong>Medium</strong></span>
<!-- markdownlint-enable MD033 -->

Given two integers n and k, return all possible combinations of k numbers chosen from the range [1, n].

You may return the answer in any order.

### Example 1

```text
Input: n = 4, k = 2
Output: [[1,2],[1,3],[1,4],[2,3],[2,4],[3,4]]
Explanation: There are 4 choose 2 = 6 total combinations.
Note that combinations are unordered, i.e., [1,2] and [2,1] are considered to be the same combination.
```

### Example 2

```text
Input: n = 1, k = 1
Output: [[1]]
Explanation: There is 1 choose 1 = 1 total combination.
```

### Constraints

```text
1 <= n <= 20
1 <= k <= n
```

## Answer

### 解題思路

兩個版本都使用回溯法建立組合。`candidate` 只會從 `start` 往後選取，因此每組數字都維持遞增順序，不會產生 `[1, 2]` 與 `[2, 1]` 這種重複結果。

### 版本一：複製清單（較直覺）

每次準備選取下一個數字時，先複製上一層的組合，再將候選數字加入複本：

```java
List<Integer> currentCombination = new ArrayList<>(prevCombination);
currentCombination.add(candidate);
```

因此每個遞迴分支都有自己的清單，分支之間不會互相影響，也不需要在遞迴返回後使用 `remove` 恢復狀態。當組合長度達到 `k` 時，可以直接將目前清單加入答案，因為之後不會再修改這個清單。

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> combine(int n, int k) {
        List<List<Integer>> combinations = new ArrayList<>();
        List<Integer> currentCombination = new ArrayList<>();

        backtrack(1, n, k, currentCombination, combinations);
        return combinations;
    }

    private void backtrack(
            int start,
            int n,
            int k,
            List<Integer> prevCombination,
            List<List<Integer>> combinations) {
        if (prevCombination.size() == k) {
            // 每個分支都有獨立清單，因此可以直接加入答案，不會被其他分支修改。
            combinations.add(prevCombination);
            return;
        }

        int remaining = k - prevCombination.size();
        int lastCandidate = n - remaining + 1;

        for (int candidate = start; candidate <= lastCandidate; candidate++) {
            // 複製上一層狀態，讓每個遞迴分支擁有自己的組合。
            List<Integer> currentCombination = new ArrayList<>(prevCombination);
            currentCombination.add(candidate);
            backtrack(candidate + 1, n, k, currentCombination, combinations);
        }
    }
}
```

### 版本二：共用清單並回溯（較省記憶體）

這個版本只維護一份 `currentCombination`。選取候選數字後先加入清單，遞迴返回時再移除最後一個數字，讓清單恢復成進入該層之前的狀態：

每次從 `start` 開始嘗試候選數字：

1. 將候選數字加入目前組合。
2. 遞迴選擇下一個數字，下一層從 `candidate + 1` 開始，確保不會重複使用或倒序選取。
3. 遞迴返回後移除最後一個數字，恢復現場，讓迴圈可以嘗試下一個候選。
4. 當目前組合的長度達到 `k` 時，複製一份結果加入答案，避免後續回溯修改已儲存的內容。

迴圈上界使用「目前還需要選取的數量」計算。若剩餘名額為 `remaining`，候選數字最多只能到 `n - remaining + 1`，如此可確保選定目前數字後，後面仍有足夠的數字完成組合。

```java
import java.util.ArrayList;
import java.util.List;

class Solution {
    public List<List<Integer>> combine(int n, int k) {
        List<List<Integer>> combinations = new ArrayList<>();
        List<Integer> currentCombination = new ArrayList<>();

        backtrack(1, n, k, currentCombination, combinations);
        return combinations;
    }

    private void backtrack(
            int start,
            int n,
            int k,
            List<Integer> currentCombination,
            List<List<Integer>> combinations) {
        if (currentCombination.size() == k) {
            // 必須複製目前路徑，避免回溯時移除元素而改變已加入的答案。
            combinations.add(new ArrayList<>(currentCombination));
            return;
        }

        int remaining = k - currentCombination.size();
        int lastCandidate = n - remaining + 1;

        for (int candidate = start; candidate <= lastCandidate; candidate++) {
            currentCombination.add(candidate);
            // 下一層只能選更大的數字，確保每組組合維持遞增且不重複。
            backtrack(candidate + 1, n, k, currentCombination, combinations);
            currentCombination.remove(currentCombination.size() - 1);
        }
    }
}
```

### 複雜度分析

令 `n` 為候選數字的總數，輸出組合數為 $\binom{n}{k}$。

- 版本一時間複雜度：$O\left(k^2 \times \binom{n}{k}\right)$。每個遞迴分支都會複製目前清單，複製成本最多為 $O(k)$；若計入完整答案的複製，輸出本身仍需要 $O\left(k \times \binom{n}{k}\right)$。
- 版本一額外空間複雜度：$O(k^2)$。遞迴最深時，每一層都保留一份不同長度的清單；若計入輸出，則再加上 $O\left(k \times \binom{n}{k}\right)$。
- 版本二時間複雜度：$O\left(k \times \binom{n}{k}\right)$。它只在找到完整組合時複製長度為 `k` 的清單，其他回溯操作只需常數時間。
- 版本二額外空間複雜度：$O(k)$。遞迴堆疊與共用的 `currentCombination` 最大長度都是 `k`；若計入輸出，則再加上 $O\left(k \times \binom{n}{k}\right)$。

題目保證 `1 <= k <= n`，因此不需要處理 `k` 大於 `n` 的無效輸入；`n = 1、k = 1` 時，第一次遞迴即可產生 `[1]`。
