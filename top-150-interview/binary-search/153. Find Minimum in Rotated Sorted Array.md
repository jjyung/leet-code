# 153. Find Minimum in Rotated Sorted Array

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Suppose an array of length n sorted in ascending order is rotated between 1 and n times. For example, the array `nums = [0,1,2,4,5,6,7]` might become:

- `[4,5,6,7,0,1,2]` if it was rotated 4 times.
- `[0,1,2,4,5,6,7]` if it was rotated 7 times.

Notice that rotating an array `[a[0], a[1], a[2], ..., a[n-1]]` 1 time results in the array `[a[n-1], a[0], a[1], a[2], ..., a[n-2]]`.

Given the sorted rotated array `nums` of unique elements, return the minimum element of this array.

You must write an algorithm that runs in `O(log n)` time.

### Example 1

```text
Input: nums = [3,4,5,1,2]
Output: 1
Explanation: The original array was [1,2,3,4,5] rotated 3 times.
```

### Example 2

```text
Input: nums = [4,5,6,7,0,1,2]
Output: 0
Explanation: The original array was [0,1,2,4,5,6,7] and it was rotated 4 times.
```

### Example 3

```text
Input: nums = [11,13,15,17]
Output: 11
Explanation: The original array was [11,13,15,17] rotated 4 times.
```

### Constraints

- `n == nums.length`
- `1 <= n <= 5000`
- `-5000 <= nums[i] <= 5000`
- All the integers of `nums` are unique.
- `nums` is sorted and rotated between 1 and `n` times.

## Answer

### 解題思路

旋轉後的陣列最多分成兩段遞增區間，最小值位於右側較小的區段開頭。每次取中間位置 `mid`，並與右界 `right` 比較：

- 若 `nums[mid] > nums[right]`，表示最小值在 `mid` 右側，因此令 `left = mid + 1`。
- 若 `nums[mid] < nums[right]`，表示 `mid` 到 `right` 是遞增區段，最小值在 `mid` 或其左側，因此令 `right = mid`。

每次都保留包含最小值的一半區間。當 `left == right` 時，該位置就是最小值。題目保證陣列非空且元素互異，因此不需要額外處理空陣列或相等值。

```java
class Solution {
    public int findMin(int[] nums) {
        int left = 0;
        int right = nums.length - 1;

        // 最小值始終位於 [left, right] 範圍內，逐次縮小搜尋區間。
        while (left < right) {
            int mid = left + (right - left) / 2; // 先算區間長度，避免 left + right 溢位

            if (nums[mid] > nums[right]) {
                // 中點仍在較大的左區段，最小值必定在中點右側。
                left = mid + 1;
            } else {
                // 中點位於較小的右區段，或本身就是最小值。
                right = mid;
            }
        }

        return nums[left];
    }
}
```

### 說明

- **邊界條件：** 單一元素時 `left` 與 `right` 一開始相同，迴圈不執行並直接回傳該元素；未旋轉陣列則會持續縮小右界，最後回傳首項。
- **時間複雜度：** `O(log n)`，每輪將搜尋範圍縮小約一半；`n` 為 `nums` 的元素數量。
- **空間複雜度：** `O(1)`，只使用固定數量的變數。
