# 74. Search a 2D Matrix

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

You are given an `m x n` integer matrix `matrix` with the following two properties:

- Each row is sorted in non-decreasing order.
- The first integer of each row is greater than the last integer of the previous row.

Given an integer `target`, return `true` if `target` is in `matrix` or `false` otherwise.

You must write a solution in O(log(m * n)) time complexity.

### Constraints

- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 100`
- `-10^4 <= matrix[i][j], target <= 10^4`

### Example 1

```text
Input: matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3
Output: true
Explanation: The target 3 is found in the first row of the matrix.
```

### Example 2

```text
Input: matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13
Output: false
Explanation: The target 13 is not present in the matrix.
```

## Answer

### 解題思路

由於每一列都已排序，且下一列的第一個元素大於上一列的最後一個元素，因此可以把整個矩陣視為一個排序後的一維陣列：

```text
[1, 3, 5, 7, 10, 11, 16, 20, 23, 30, 34, 60]
```

對這個虛擬的一維陣列進行二分搜尋。將一維索引 `mid` 轉換為矩陣座標：

- 列索引：`mid / columns`
- 欄索引：`mid % columns`

每次比較目前元素與 `target`：相等時回傳 `true`，目前元素較小時搜尋右半部，否則搜尋左半部。搜尋範圍縮小至空集合後，代表矩陣中不存在 `target`。

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        // 處理邊界：矩陣為空時，目標值一定不存在。
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            return false;
        }

        int rows = matrix.length;
        int columns = matrix[0].length;
        int left = 0;
        int right = rows * columns - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            // 將一維索引 mid 轉換為矩陣座標。
            int value = matrix[mid / columns][mid % columns];

            // 以下就是標準二元搜尋。
            // 依照排序結果縮小搜尋範圍。
            if (value == target) {
                return true;
            } else if (value < target) {
                // value 太小, mid 與左側元素都不可能是答案
                left = mid + 1;
            } else {
                // value 太大, mid 與右側元素都不可能是答案
                right = mid - 1;
            }
        }

        return false;
    }
}
```

### 說明

1. `left` 與 `right` 代表虛擬一維陣列中仍可能包含答案的索引範圍，迴圈條件 `left <= right` 可確保單一元素也會被檢查。
2. `mid / columns` 和 `mid % columns` 能將一維索引正確映射回矩陣的列與欄；因為矩陣至少有一列一欄，所以不會發生除以零。
3. 若 `matrix` 為空或第一列為空，直接回傳 `false`；題目限制雖保證矩陣非空，這個檢查讓程式更安全。
4. 令 `m` 為列數、`n` 為欄數，矩陣總元素數為 `N = m * n`。每次二分搜尋排除約一半元素，因此時間複雜度為 `O(log N) = O(log(m * n))`，空間複雜度為 `O(1)`。
