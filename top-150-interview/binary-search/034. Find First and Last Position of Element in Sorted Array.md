# 034. Find First and Last Position of Element in Sorted Array

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an array of integers `nums` sorted in non-decreasing order, find the starting and ending position of a given `target` value.

If `target` is not found in the array, return `[-1, -1]`.

You must write an algorithm with `O(log n)` runtime complexity.

### Example 1

```text
Input: nums = [5,7,7,8,8,10], target = 8
Output: [3,4]
Explanation: The first and last positions of 8 are 3 and 4.
```

### Example 2

```text
Input: nums = [5,7,7,8,8,10], target = 6
Output: [-1,-1]
Explanation: The target 6 is not found in nums.
```

### Example 3

```text
Input: nums = [], target = 0
Output: [-1,-1]
Explanation: The array is empty, so the target is not found.
```

### Constraints

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `nums` is a non-decreasing array.
- `-10^9 <= target <= 10^9`

## Answer

### 解題思路

利用排序陣列進行兩次二分搜尋，分別找出目標值的左右邊界：

1. 第一次找第一個大於或等於 `target` 的位置。若該位置超出陣列，或該位置的值不等於 `target`，代表目標不存在，回傳 `[-1, -1]`。
2. 第二次找第一個大於 `target` 的位置，該位置的前一格就是目標值最後一次出現的位置。

每次搜尋都維持半開區間 `[left, right)`，每輪將搜尋範圍縮小一半。迴圈條件是 `left < right`，因此只有當兩個邊界相等時才會停止。更新 `left = mid + 1` 後，如果 `right > left`，代表範圍仍有元素，迴圈會繼續；若這是最後一輪，則會收斂成 `left == right == mid + 1`。另一種最後更新是 `right = mid`，此時會收斂成 `left == right == mid`。

若第一輪搜尋結束時 `left == nums.length`，表示陣列中沒有任何元素大於或等於 `target`，也就是所有元素都小於 `target`。這時 `left` 已在有效索引範圍之外，必須先檢查再讀取 `nums[left]`。空陣列也會得到 `left == nums.length == 0`，由同一個檢查安全處理。

```java
class Solution {
    public int[] searchRange(int[] nums, int target) {
        int left = 0;
        int right = nums.length;

        // 找第一個大於或等於 target 的位置；半開區間縮至 left == right 時停止。
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] >= target) {
                // mid 已符合條件，保留它作為候選，並繼續往左找第一個符合的位置。
                right = mid;
            } else {
                // mid 不符合條件，連同它左側的範圍一起排除；若尚未收斂，迴圈會繼續。
                left = mid + 1;
            }
        }

        // left == nums.length 表示所有元素都小於 target；先檢查可避免存取陣列外的位置。
        // 若 left 仍在陣列內但值不等於 target，代表找到的是較大的下一個值。
        if (left == nums.length || nums[left] != target) {
            return new int[] {-1, -1};
        }
        int first = left;

        // 找第一個大於 target 的位置；left == right 時收斂完成，其前一格即為右邊界。
        left = 0;
        right = nums.length;
        while (left < right) {
            int mid = left + (right - left) / 2;
            if (nums[mid] > target) {
                // mid 已大於 target，答案在 mid 或其左側。
                right = mid;
            } else {
                // nums[mid] <= target，第一個大於 target 的位置必定在 mid 右側。
                left = mid + 1;
            }
        }

        return new int[] {first, left - 1};
    }
}
```

### 說明

1. 左邊界搜尋時，`nums[mid] >= target` 就把右界移到 `mid`，因為 `mid` 可能就是第一個符合條件的位置；若 `nums[mid] < target`，就把左界移到 `mid + 1`，排除不可能的區段。每次更新都縮小半開區間，直到 `left == right`。若最後等於 `nums.length`，表示所有元素都小於 `target`；若位置仍在陣列內但值不等於 `target`，則該值大於 `target`，兩種情況都代表找不到目標。
2. 右邊界搜尋時，`nums[mid] > target` 就往左收縮；否則將左界移到 `mid + 1`。搜尋結束的 `left` 是第一個大於 `target` 的位置，因此 `left - 1` 是最後一個等於 `target` 的索引。
3. 時間複雜度為 `O(log n)`，其中 `n` 是 `nums` 的長度；空間複雜度為 `O(1)`，不計算回傳陣列所需空間。
