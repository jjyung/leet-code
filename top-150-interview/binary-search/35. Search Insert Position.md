# 35. Search Insert Position

## Question

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given a sorted array of distinct integers and a target value, return the index if the target is found. If not, return the index where it would be if it were inserted in order.

You must write an algorithm with O(log n) runtime complexity.

### Example 1

```text
Input: nums = [1,3,5,6], target = 5
Output: 2
```

**Explanation:** The target `5` is found at index `2`.

### Example 2

```text
Input: nums = [1,3,5,6], target = 2
Output: 1
```

**Explanation:** The target `2` should be inserted at index `1` to keep the array sorted.

### Example 3

```text
Input: nums = [1,3,5,6], target = 7
Output: 4
```

**Explanation:** The target `7` is greater than every element, so it should be inserted at index `4`.

### Constraints

- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` contains distinct values sorted in ascending order.
- `-10^4 <= target <= 10^4`

## Answer

### 解題思路

題目要求尋找 `target` 的位置，若不存在則找出第一個大於 `target` 的元素位置。這個位置也就是 `target` 維持排序時應插入的位置。

使用 binary search 搜尋 half-open 區間 `[left, right)`：

1. 若 `nums[mid] < target`，表示 `mid` 以及左側元素都不可能是答案，因此將 `left` 移到 `mid + 1`。
2. 否則，`mid` 可能是答案，將 `right` 移到 `mid`，繼續搜尋左半部。
3. 當 `left == right` 時，`left` 就是第一個大於或等於 `target` 的索引；若陣列所有元素都小於 `target`，它也會自然等於 `nums.length`。

### Java 程式碼

```java
class Solution {
    public int searchInsert(int[] nums, int target) {
        int left = 0;
        int right = nums.length;

        // 搜尋半開區間 [left, right)，找第一個 nums[i] >= target 的位置
        while (left < right) {
            // 剩餘搜尋範圍的中間位置：左邊界加上 offset
            int mid = left + (right - left) / 2;

            if (nums[mid] < target) {
                // nums[mid] 太小，mid 與左側元素都不可能是答案
                left = mid + 1;
            } else {
                // nums[mid] 可能是答案，保留 mid 並繼續搜尋左半部
                right = mid;
            }
        }

        return left;
    }
}
```

### 說明

- `left` 左側的元素都小於 `target`，因此不可能是插入位置。
- `right` 使用 `nums.length` 作為初始值，能涵蓋 `target` 大於所有元素、答案位於陣列尾端的情況。
- 設 `n` 為陣列 `nums` 的長度。每次迭代將搜尋範圍縮小一半，因此時間複雜度為 `O(log n)`，額外空間複雜度為 `O(1)`。
