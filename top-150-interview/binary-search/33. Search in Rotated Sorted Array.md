# 33. Search in Rotated Sorted Array

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

There is an integer array `nums` sorted in ascending order (with distinct values).

Prior to being passed to your function, `nums` is possibly left rotated at an unknown index `k` (`1 <= k < nums.length`) such that the resulting array is `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]` (0-indexed). For example, `[0,1,2,4,5,6,7]` might be left rotated by 3 indices and become `[4,5,6,7,0,1,2]`.

Given the array `nums` after the possible rotation and an integer `target`, return the index of `target` if it is in `nums`, or `-1` if it is not in `nums`.

You must write an algorithm with `O(log n)` runtime complexity.

### Example 1

```text
Input: nums = [4,5,6,7,0,1,2], target = 0
Output: 4
Explanation: The target 0 is found at index 4.
```

### Example 2

```text
Input: nums = [4,5,6,7,0,1,2], target = 3
Output: -1
Explanation: The target 3 is not present in nums.
```

### Example 3

```text
Input: nums = [1], target = 0
Output: -1
Explanation: The only value in nums is 1, so the target 0 is not present.
```

### Constraints

- `1 <= nums.length <= 5000`
- `-10^4 <= nums[i] <= 10^4`
- All values of `nums` are unique.
- `nums` is an ascending array that is possibly rotated.
- `-10^4 <= target <= 10^4`

## Answer

### 解題思路

每一輪只在閉區間 `[left, right]` 中搜尋。由於原本遞增的陣列最多只有一個旋轉切點，將搜尋區間從 `mid` 分成左右兩側後，至少有一側仍是遞增的。找到有序側後，就能用它的首尾值判斷 `target` 是否可能在其中：

1. 計算中間位置 `mid`。若 `nums[mid] == target`，直接回傳 `mid`。
2. 判斷左側是否有序：若 `nums[left] <= nums[mid]`，代表 `[left, mid]` 遞增。若 `nums[left] <= target < nums[mid]`，目標在左側，令 `right = mid - 1`；否則目標不在左側，令 `left = mid + 1`。
3. 若左側無序，右側 `[mid, right]` 必定遞增。若 `nums[mid] < target <= nums[right]`，目標在右側，令 `left = mid + 1`；否則令 `right = mid - 1`。
4. 縮小搜尋區間後，重新判斷哪一側有序。另一側可能跨過旋轉切點，也可能已經變成完整有序的區間；不需要假設目標一定在無序側。

例如 `nums = [4,5,6,7,0,1,2]`、`target = 0`：第一輪 `mid` 位於值 `7`，左側 `[4,5,6,7]` 有序，但 `0` 不在 `[4,7]`，因此排除左側，搜尋 `[0,1,2]`。下一輪這段已經有序，`0` 落在左側值域內，於是保留左側並找到索引 `4`。題目保證元素互不相同，因此可以用端點比較判斷半側是否有序；若搜尋區間縮至空仍未找到，就回傳 `-1`。

### Java 程式碼

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0;
        int right = nums.length - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;

            if (nums[mid] == target) {
                return mid;
            }

            // 至少一側有序；先判斷左半側是否為遞增區間。
            if (nums[left] <= nums[mid]) {
                // 左側有序時，只在目標落於其值域內才保留左側。
                if (nums[left] <= target && target < nums[mid]) {
                    right = mid - 1;
                } else {
                    left = mid + 1;
                }
            } else {
                // 左側無序時，右半側必定有序，依目標值域選擇搜尋方向。
                if (nums[mid] < target && target <= nums[right]) {
                    left = mid + 1;
                } else {
                    right = mid - 1;
                }
            }
        }

        return -1;
    }
}
```

### 說明

1. 搜尋範圍維持在閉區間 `[left, right]`；每輪比較中間值，並根據有序半側的值域排除不可能包含目標的一側。
2. 題目限制陣列至少有一個元素，因此單一元素也會由同一個迴圈正確處理；元素互異的條件讓有序半側的判斷不會遇到重複值歧義。
3. 設 `n = nums.length`，時間複雜度為 `O(log n)`，額外空間複雜度為 `O(1)`。
