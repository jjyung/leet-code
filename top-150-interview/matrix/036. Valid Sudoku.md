# 036. Valid Sudoku

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

給定一個 `9 x 9` 的數獨棋盤，請判斷目前已填入的內容是否有效。只需要檢查已填入的格子是否符合以下規則：

- 每一列都不能重複出現數字 `1` 到 `9`。
- 每一欄都不能重複出現數字 `1` 到 `9`。
- 九個 `3 x 3` 的宮格中，每個宮格都不能重複出現數字 `1` 到 `9`。

數獨棋盤可能是有效的，但不一定能夠被解出完整答案；只需要驗證目前已填入的格子即可。

### Example 1

```text
Input: board =
[["5","3",".",".","7",".",".",".","."],
 ["6",".",".","1","9","5",".",".","."],
 [".","9","8",".",".",".",".","6","."],
 ["8",".",".",".","6",".",".",".","3"],
 ["4",".",".","8",".","3",".",".","1"],
 ["7",".",".",".","2",".",".",".","6"],
 [".","6",".",".",".",".","2","8","."],
 [".",".",".","4","1","9",".",".","5"],
 [".",".",".",".","8",".",".","7","9"]]
Output: true
```

### Example 2

```text
Input: board =
[["8","3",".",".","7",".",".",".","."],
 ["6",".",".","1","9","5",".",".","."],
 [".","9","8",".",".",".",".","6","."],
 ["8",".",".",".","6",".",".",".","3"],
 ["4",".",".","8",".","3",".",".","1"],
 ["7",".",".",".","2",".",".",".","6"],
 [".","6",".",".",".",".","2","8","."],
 [".",".",".","4","1","9",".",".","5"],
 [".",".",".",".","8",".",".","7","9"]]
Output: false
Explanation: 左上角的 `3 x 3` 宮格中有兩個 `8`，因此棋盤無效。
```

### Constraints

- `board.length == 9`
- `board[i].length == 9`
- `board[i][j]` 是數字 `1` 到 `9` 或字元 `'.'`。

題目連結：[LeetCode - Valid Sudoku](https://leetcode.com/problems/valid-sudoku/)

## Answer

使用三組布林陣列，分別記錄每一列、每一欄與每一個 `3 x 3` 宮格是否已經出現過某個數字。

走訪每個格子時，忽略空格 `'.'`。對於已填入的數字，透過下列公式找到所屬宮格：
先用 / 3 找宮格位置，再用「宮格列 × 每列宮格數 + 宮格欄」轉成編號。

```text
boxIndex = (row / boxSize) * boxesPerRow + (column / boxSize);
```

本題 boxSize = 3、boxesPerRow = 3，所以才會是：

```text
boxIndex = (row / 3) * 3 + (column / 3)
```

若該數字在同一列、同一欄或同一宮格中已出現過，立即回傳 `false`；否則將三個紀錄位置標記為 `true`。所有格子檢查完成後，回傳 `true`。

```java
class Solution {
    public boolean isValidSudoku(char[][] board) {
        // 第一維代表 9 組列、欄或宮格；第二維用數字作為索引。
        // 索引 0 不使用，索引 1~9 分別代表數字 1~9。
        boolean[][] rows = new boolean[9][10];
        boolean[][] columns = new boolean[9][10];
        boolean[][] boxes = new boolean[9][10];

        for (int row = 0; row < 9; row++) {
            for (int column = 0; column < 9; column++) {
                char cell = board[row][column];

                // 空格不需要驗證，直接跳過。
                if (cell == '.') {
                    continue;
                }

                // 將字元數字轉成整數，讓它可以直接當作陣列索引。
                int digit = cell - '0';

                // 先找出所在的宮格列與宮格欄，再轉成 0~8 的一維索引。
                int boxRow = row / 3;
                int boxColumn = column / 3;
                int boxIndex = boxRow * 3 + boxColumn;

                // 同時檢查列、欄與宮格是否已出現此數字。
                if (rows[row][digit]
                        || columns[column][digit]
                        || boxes[boxIndex][digit]) {
                    return false;
                }

                // 記錄此數字已在目前的列、欄與宮格出現。
                rows[row][digit] = true;
                columns[column][digit] = true;
                boxes[boxIndex][digit] = true;
            }
        }

        return true;
    }
}
```

### 說明

1. `rows[row][digit]`、`columns[column][digit]` 與 `boxes[boxIndex][digit]` 分別表示數字是否在列、欄與宮格中出現過。
2. 每個已填入的數字都必須同時通過三種檢查，才能確保棋盤符合數獨規則。
3. 時間複雜度為 `O(9²)`，也可視為固定大小棋盤上的 `O(1)`。
4. 額外空間複雜度為 `O(9²)`，也可視為固定大小棋盤上的 `O(1)`。
