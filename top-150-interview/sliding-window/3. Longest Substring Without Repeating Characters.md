# 3. Longest Substring Without Repeating Characters

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given a string `s`, find the length of the longest substring without duplicate characters.

Example 1:

Input: s = "abcabcbb"
Output: 3
Explanation: The answer is "abc", with the length of 3. Note that "bca" and "cab" are also correct answers.

Example 2:

Input: s = "bbbbb"
Output: 1
Explanation: The answer is "b", with the length of 1.

Example 3:

Input: s = "pwwkew"
Output: 3
Explanation: The answer is "wke", with the length of 3. Notice that the answer must be a substring, "pwke" is a subsequence and not a substring.

## Answer

### 一、先理解題目

題目要找的是「連續」且「不能有重複字元」的最長子字串。

例如 `s = "abcabcbb"`：

- `"abc"` 是合法子字串，長度為 `3`。
- `"bca"` 與 `"cab"` 也都是合法子字串，長度同樣是 `3`。
- `"abca"` 不是合法答案，因為 `a` 出現了兩次。
- `"acb"` 雖然沒有重複字元，但它不是連續的一段，因此是子序列，不是子字串。

所以我們要在字串中維護一段「目前沒有重複字元的連續範圍」，並找出這段範圍的最大長度。

### 二、滑動視窗的想法

把目前正在檢查的子字串稱為滑動視窗，範圍是 `[left, right]`：

- `left`：視窗左邊界。
- `right`：視窗右邊界，逐一向右走訪字串。
- `right - left + 1`：目前視窗的長度。

每次讓 `right` 向右移動一格，將新字元加入視窗：

1. 如果新字元沒有在目前視窗出現過，視窗仍然合法。
2. 如果新字元重複，必須移動 `left`，直到移除重複字元為止。
3. 每次視窗合法時，更新目前看過的最大長度。

若逐格移動 `left`，需要額外檢查很多字元。更有效率的做法是使用 `lastSeen`，直接記錄每個字元最後一次出現的索引：

```text
lastSeen[字元] = 該字元最後出現的位置
```

當字元 `current` 在索引 `right` 重複，而它上次出現在 `lastSeen[current]` 時，新的左邊界至少必須是：

```text
lastSeen[current] + 1
```

如此可以一次跳過不可能成為答案的範圍。

### 三、逐步追蹤 `abcabcbb`

| `right` | 目前字元 | `left` | 目前視窗 | 最大長度 |
| ---: | :---: | ---: | :--- | ---: |
| 0 | `a` | 0 | `a` | 1 |
| 1 | `b` | 0 | `ab` | 2 |
| 2 | `c` | 0 | `abc` | 3 |
| 3 | `a` | 1 | `bca` | 3 |
| 4 | `b` | 2 | `cab` | 3 |
| 5 | `c` | 3 | `abc` | 3 |
| 6 | `b` | 5 | `cb` | 3 |
| 7 | `b` | 7 | `b` | 3 |

以索引 `3` 的 `a` 為例：

- `a` 上次出現在索引 `0`。
- 如果 `left` 仍是 `0`，視窗會變成 `abca`，其中有兩個 `a`。
- 因此將 `left` 移到 `0 + 1 = 1`，視窗變成 `bca`。
- `bca` 沒有重複字元，可以繼續往右延伸。

### 四、為什麼要使用 `Math.max`？

`left` 只能向右移動，不能倒退。考慮 `s = "abba"`：

- 讀到索引 `2` 的 `b` 時，`left` 會移到 `2`。
- 讀到索引 `3` 的 `a` 時，`a` 上次出現在索引 `0`。
- 直接設定 `left = 0 + 1` 會讓 `left` 從 `2` 倒退到 `1`，這是不正確的。

因此使用：

```java
left = Math.max(left, lastSeen.get(current) + 1);
```

這樣可以確保 `left` 永遠不會倒退，也能確保目前視窗內沒有重複字元。

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int lengthOfLongestSubstring(String s) {
        // 記錄每個字元最後一次出現的索引。
        Map<Character, Integer> lastSeen = new HashMap<>();

        // 滑動視窗的左邊界，以及目前找到的最大長度。
        int left = 0;
        int answer = 0;

        // right 逐一向右掃描字串，將目前字元加入滑動視窗。
        for (int right = 0; right < s.length(); right++) {
            char current = s.charAt(right);

            if (lastSeen.containsKey(current)) {
                // 若字元重複，將左邊界跳到上次出現位置的下一格。
                // Math.max 可避免 left 倒退到目前視窗左側。
                left = Math.max(left, lastSeen.get(current) + 1);
            }

            // 更新目前字元最後一次出現的位置。
            lastSeen.put(current, right);

            // 目前視窗 [left, right] 已沒有重複字元，更新最大長度。
            answer = Math.max(answer, right - left + 1);
        }

        // 回傳最長的不重複子字串長度。
        return answer;
    }
}
```

### 說明

1. `right` 從左到右掃描字串，每次處理一個新字元。
2. `lastSeen` 儲存每個字元最近一次出現的索引，讓 `left` 可以直接跳到正確位置。
3. 迴圈結束時，`[left, right]` 一定是一段不含重複字元的合法視窗。
4. `answer` 儲存所有合法視窗中的最大長度。
5. 設 `n` 為字串長度。`right` 只向右走一次，且 `left` 也只向右移動，因此時間複雜度為 `O(n)`。
6. `HashMap` 最多儲存字元集中的每個不同字元，空間複雜度為 `O(min(n, 字元集大小))`。
