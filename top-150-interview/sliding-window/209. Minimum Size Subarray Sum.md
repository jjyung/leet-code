# 209. Minimum Size Subarray Sum

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an array of positive integers `nums` and a positive integer `target`, return the minimal length of a subarray whose sum is greater than or equal to `target`. If there is no such subarray, return `0` instead.

<https://leetcode.com/problems/minimum-size-subarray-sum/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

這題可用 Sliding Window 在 O(n) 內解決。因為陣列元素皆為正數，右指標右移時，視窗總和只會增加；左指標右移時，總和只會減少，因此可以用雙指標維護「目前總和 >= target 的最短長度」。

```java
class Solution {
    public int minSubArrayLen(int target, int[] nums) {
        int left = 0;
        int sum = 0;
        int minLen = Integer.MAX_VALUE;

        for (int right = 0; right < nums.length; right++) {
            sum += nums[right];

            while (sum >= target) {
                minLen = Math.min(minLen, right - left + 1);
                sum -= nums[left];
                left++;
            }
        }

        return minLen == Integer.MAX_VALUE ? 0 : minLen;
    }
}
```

### 說明

1. 使用 `left` 與 `right` 維護目前視窗 `[left, right]`，並以 `sum` 記錄視窗總和。
2. 先持續擴張右邊界（`right++`）直到 `sum >= target`。
3. 一旦滿足條件，就嘗試收縮左邊界（`left++`），並在每次收縮前更新最短長度。
4. 每個元素最多被加入與移出視窗各一次，整體時間複雜度為 O(n)。
5. 若最後 `minLen` 仍為初始值，代表不存在符合條件的子陣列，回傳 `0`。

時間複雜度：O(n)  
空間複雜度：O(1)
