# 076. Minimum Window Substring

## Problem

<span style="color: #ef4444;"><strong>Hard</strong></span>

Given two strings s and t of lengths m and n respectively, return the minimum window substring of s such that every character in t (including duplicates) is included in the window. If there is no such substring, return the empty string "".

The testcases will be generated such that the answer is unique.

### Example 1

```text
Input: s = "ADOBECODEBANC", t = "ABC"
Output: "BANC"
Explanation: The minimum window substring "BANC" includes 'A', 'B', and 'C' from string t.
```

### Example 2

```text
Input: s = "a", t = "a"
Output: "a"
Explanation: The entire string s is the minimum window.
```

### Example 3

```text
Input: s = "a", t = "aa"
Output: ""
Explanation: Both 'a's from t must be included in the window.
Since the largest window of s only has one 'a', return empty string.
```

Constraints:

- m == s.length
- n == t.length
- 1 <= m, n <= 10<sup>5</sup>
- s and t consist of uppercase and lowercase English letters.

Follow up: Could you find an algorithm that runs in O(m + n) time?

## Answer

### 解題思路

使用滑動視窗與字元計數。`needed[c]` 表示目前視窗還缺少多少個字元 `c`；負數表示視窗中該字元有多餘的數量。`missing` 記錄還缺少的字元總數，包含重複字元。

向右擴張視窗時，若加入的字元原本仍有欠缺，就減少 `missing`。當 `missing` 為 0，視窗已包含 `t` 的所有字元；此時記錄最短視窗，並持續移動左指標縮小視窗。移除字元後若其需求數變為正數，代表視窗再次缺少該字元，必須繼續向右擴張。

每個右端點都會嘗試縮小至不再符合條件，因此不會漏掉以該右端點結尾的最短有效視窗。若始終沒有有效視窗，回傳空字串。

```java
class Solution {
    public String minWindow(String s, String t) {
        // 題目僅包含英文字母，可用 ASCII 索引記錄所缺的字元數。
        int[] needed = new int[128];
        for (int i = 0; i < t.length(); i++) {
            needed[t.charAt(i)]++;
        }

        int missing = t.length();
        int left = 0;
        int bestStart = 0;
        int bestLength = Integer.MAX_VALUE;

        for (int right = 0; right < s.length(); right++) {
            char incoming = s.charAt(right);
            // 只有原本缺少的字元才能減少尚缺的總數。
            if (needed[incoming] > 0) {
                missing--;
            }
            needed[incoming]--;

            // 視窗有效時持續縮小，找出目前右端點對應的最短視窗。
            while (missing == 0) {
                int windowLength = right - left + 1;
                if (windowLength < bestLength) {
                    bestStart = left;
                    bestLength = windowLength;
                }

                char outgoing = s.charAt(left++);
                needed[outgoing]++;
                // 移除必要字元後，視窗不再滿足條件。
                if (needed[outgoing] > 0) {
                    missing++;
                }
            }
        }

        return bestLength == Integer.MAX_VALUE
                ? ""
                : s.substring(bestStart, bestStart + bestLength);
    }
}
```

### 複雜度與邊界條件

令 `m` 為 `s` 的長度，`n` 為 `t` 的長度。計數會保留重複字元的需求，且區分大小寫；若 `t` 比 `s` 長或缺少必要字元，找不到有效視窗時回傳空字串。

- 時間複雜度：`O(m + n)`。初始化計數需 `O(n)`，兩個指標各自最多移動 `m` 次；取出結果最多需 `O(m)`。
- 空間複雜度：`O(1)` 額外空間，計數陣列大小固定；若計入回傳字串，最多需 `O(m)` 空間。
