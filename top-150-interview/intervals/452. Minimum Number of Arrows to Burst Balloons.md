# 452. Minimum Number of Arrows to Burst Balloons

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

There are some spherical balloons taped onto a flat wall that represents the XY-plane. The balloons are represented by a 2D integer array `points` where `points[i] = [xstart, xend]` denotes a balloon whose horizontal diameter stretches between `xstart` and `xend`. You do not know the exact y-coordinates of the balloons.

Arrows can be shot up directly vertically (in the positive y-direction) from different points along the x-axis. A balloon with `xstart` and `xend` is burst by an arrow shot at `x` if `xstart <= x <= xend`. There is no limit to the number of arrows that can be shot. A shot arrow keeps traveling up infinitely, bursting any balloons in its path.

Given the array `points`, return the minimum number of arrows that must be shot to burst all balloons.

### Example 1

```text
Input: points = [[10,16],[2,8],[1,6],[7,12]]
Output: 2
Explanation: The balloons can be burst by 2 arrows:
- Shoot an arrow at x = 6, bursting the balloons [2,8] and [1,6].
- Shoot an arrow at x = 11, bursting the balloons [10,16] and [7,12].
```

### Example 2

```text
Input: points = [[1,2],[3,4],[5,6],[7,8]]
Output: 4
Explanation: One arrow needs to be shot for each balloon for a total of 4 arrows.
```

### Example 3

```text
Input: points = [[1,2],[2,3],[3,4],[4,5]]
Output: 2
Explanation: The balloons can be burst by 2 arrows:
- Shoot an arrow at x = 2, bursting the balloons [1,2] and [2,3].
- Shoot an arrow at x = 4, bursting the balloons [3,4] and [4,5].
```

### Constraints

- `1 <= points.length <= 10^5`
- `points[i].length == 2`
- `-2^31 <= xstart < xend <= 2^31 - 1`

## Answer

### 解題思路

將所有氣球依照右端點 `xend` 由小到大排序。對於目前尚未被爆破的氣球，將箭射在它的右端點，可以讓這支箭盡可能與後續氣球重疊，保留最多共用同一支箭的機會。

排序後逐一檢查氣球：

1. 第一支箭射在第一個氣球的右端點。
2. 如果下一個氣球的左端點 `xstart` 小於或等於目前箭的位置，代表該氣球也會被這支箭爆破。
3. 如果 `xstart` 大於目前箭的位置，代表兩個區間沒有交集，必須增加一支箭，並將新箭射在該氣球的右端點。

由於氣球的端點可以相等，判斷條件使用 `xstart > arrowPosition` 才需要新增箭。

```java
import java.util.Arrays;

class Solution {
    public int findMinArrowShots(int[][] points) {
        // 依照氣球的右端點排序，優先處理最早結束的區間。
        Arrays.sort(points, (a, b) -> Integer.compare(a[1], b[1]));

        int arrows = 1;
        // 將第一支箭射在第一個氣球的右端點。
        int arrowPosition = points[0][1];

        for (int i = 1; i < points.length; i++) {
            // 左端點超過目前箭的位置，表示無法共用這支箭。
            if (points[i][0] > arrowPosition) {
                arrows++;
                // 新箭射在目前氣球的右端點，以保留最大的後續重疊範圍。
                arrowPosition = points[i][1];
            }
        }

        return arrows;
    }
}
```

### 複雜度分析

- 時間複雜度：`O(n log n)`，主要成本來自排序氣球區間。
- 空間複雜度：`O(log n)`，用於排序時的堆疊空間；不計入輸入陣列本身。
