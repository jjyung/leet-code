# 056. Merge Intervals

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an array of `intervals` where `intervals[i] = [starti, endi]`, merge all overlapping intervals, and return an array of the non-overlapping intervals that cover all the intervals in the input.

<https://leetcode.com/problems/merge-intervals/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

這題的標準做法是「先排序，再線性掃描合併」。

```java
import java.util.*;

class Solution {
    public int[][] merge(int[][] intervals) {
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));

        List<int[]> merged = new ArrayList<>();
        int[] current = intervals[0];

        for (int i = 1; i < intervals.length; i++) {
            int[] next = intervals[i];

            if (next[0] <= current[1]) {
                current[1] = Math.max(current[1], next[1]);
            } else {
                merged.add(current);
                current = next;
            }
        }

        merged.add(current);
        return merged.toArray(new int[merged.size()][]);
    }
}
```

### 說明

1. 先依區間起點排序，確保可從左到右處理。
2. 用 `current` 保存目前正在合併的區間。
3. 若下一個區間 `next[0] <= current[1]`，代表重疊，更新右邊界。
4. 若不重疊，先把 `current` 放入答案，再把 `next` 當作新的 `current`。
5. 迴圈結束後要補上最後一個 `current`。

時間複雜度：O(n log n)（排序主導）  
空間複雜度：O(n)（輸出列表）
