# 228. Summary Ranges

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

You are given a sorted unique integer array `nums`.

Return the smallest sorted list of ranges that cover all the numbers in the array exactly. Each range `[a, b]` should be output as:

- `"a->b"` if `a != b`
- `"a"` if `a == b`

<https://leetcode.com/problems/summary-ranges/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

這題是線性掃描分段。當數字不再連續時，就把目前區間結算到答案中。

```java
import java.util.*;

class Solution {
    public List<String> summaryRanges(int[] nums) {
        List<String> result = new ArrayList<>();
        if (nums.length == 0) {
            return result;
        }

        int start = nums[0];

        for (int i = 1; i < nums.length; i++) {
            if (nums[i] != nums[i - 1] + 1) {
                addRange(result, start, nums[i - 1]);
                start = nums[i];
            }
        }

        addRange(result, start, nums[nums.length - 1]);
        return result;
    }

    private void addRange(List<String> result, int start, int end) {
        if (start == end) {
            result.add(String.valueOf(start));
        } else {
            result.add(start + "->" + end);
        }
    }
}
```

### 說明

1. `start` 表示目前區間起點。
2. 逐一檢查 `nums[i]` 是否連續於前一個值（`nums[i - 1] + 1`）。
3. 若不連續，代表前一段結束，加入 `[start, nums[i - 1]]`，並更新新起點。
4. 迴圈結束後，補上最後一段區間。

時間複雜度：O(n)  
空間複雜度：O(1)（不含輸出）
