# 11. Container With Most Water

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

[LeetCode 題目連結](https://leetcode.com/problems/container-with-most-water/)

You are given an integer array height of length n. There are n vertical lines drawn such that the two endpoints of the ith line are (i, 0) and (i, height[i]).

Find two lines that together with the x-axis form a container, such that the container contains the most water.

Return the maximum amount of water a container can store.

Notice that you may not slant the container.

![alt text](image.png)

Input: height = [1,8,6,2,5,4,8,3,7]
Output: 49
Explanation: The above vertical lines are represented by array [1,8,6,2,5,4,8,3,7]. In this case, the max area of water (blue section) the container can contain is 49.
Example 2:

Input: height = [1,1]
Output: 1

## Answer

### 解題思路

使用左右雙指標 `left` 與 `right`，分別指向陣列的最左端與最右端。兩條線所形成的容積為：

```text
寬度 × 高度 = (right - left) × min(height[left], height[right])
```

每次計算目前容積並更新最大值。接著移動高度較短的那一側：

- 容積高度由較短的線決定，因此移動較高的線，寬度變小後不可能增加容積。
- 移動較短的線，才有機會找到更高的線，彌補寬度縮小造成的損失。

重複上述步驟，直到兩個指標相遇。

```java
class Solution {
    public int maxArea(int[] height) {
        int left = 0;
        int right = height.length - 1;
        int maxArea = 0;

        while (left < right) {
            int width = right - left;
            int currentHeight = Math.min(height[left], height[right]);
            int currentArea = width * currentHeight;
            maxArea = Math.max(maxArea, currentArea);

            if (height[left] < height[right]) {
                left++;
            } else {
                right--;
            }
        }

        return maxArea;
    }
}
```

### 說明

1. 初始時使用最寬的區間，因此從陣列兩端開始搜尋。
2. 每次只移動較短的一側，保留找到更高邊界的可能性。
3. 所有可能成為最佳解的區間都會在雙指標收縮過程中被考慮。
4. 時間複雜度為 `O(n)`，每個指標最多移動 `n` 次。
5. 空間複雜度為 `O(1)`，只使用固定數量的變數。
