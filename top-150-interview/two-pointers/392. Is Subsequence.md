# 392. Is Subsequence

## Question

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given two strings `s` and `t`, return `true` *if* `s`* is a **subsequence** of *`t`*, or* `false` *otherwise*.

A **subsequence** of a string is a new string that is formed from the original string by deleting some (can be none) of the characters without disturbing the relative positions of the remaining characters. (i.e., `"ace"` is a subsequence of `"abcde"` while `"aec"` is not).

## Answer

要判斷字串 `s` 是否為字串 `t` 的子序列，我們可以使用雙指標法逐個比較兩個字串的字元。具體步驟如下：

1. 初始化兩個指標 `i` 和 `j`，分別指向字串 `s` 和 `t` 的起始位置。

2. 遍歷字串 `t`，如果 `t[j]` 與 `s[i]` 相等，則移動指標 `i`，指向 `s` 的下一個字元。

3. 無論字元是否相等，都移動指標 `j`，指向 `t` 的下一個字元。

4. 如果指標 `i` 遍歷完字串 `s`，說明 `s` 是 `t` 的子序列；否則，不是子序列。

以下是詳細的 Java 實現：

```java
class Solution {
    public boolean isSubsequence(String s, String t) {
        if (s.length() == 0) {
            return true;
        }
        
        int i = 0, j = 0;
        
        while (j < t.length()) {
            if (s.charAt(i) == t.charAt(j)) {
                i++;
                if (i == s.length()) {
                    return true;
                }
            }
            j++;
        }
        
        return i == s.length();
    }

    public static void main(String[] args) {
        Solution sol = new Solution();
        System.out.println(sol.isSubsequence("abc", "ahbgdc")); // 應輸出 true
        System.out.println(sol.isSubsequence("axc", "ahbgdc")); // 應輸出 false
        System.out.println(sol.isSubsequence("", "ahbgdc"));    // 應輸出 true
        System.out.println(sol.isSubsequence("ace", "abcde"));  // 應輸出 true
        System.out.println(sol.isSubsequence("aec", "abcde"));  // 應輸出 false
    }
}
```

### 說明

1. **特殊情況處理**：

   - 如果 `s` 是空字串，直接返回 `true`，因為空字串是任何字串的子序列。

2. **雙指標遍歷**：

   - 使用兩個指標 `i` 和 `j`，分別指向 `s` 和 `t` 的起始位置。

   - 遍歷 `t`，如果當前字元 `t[j]` 與 `s[i]` 相等，則移動指標 `i`，指向 `s` 的下一個字元。

   - 無論字元是否相等，都移動指標 `j`，指向 `t` 的下一個字元。

3. **檢查結果**：

   - 如果指標 `i` 遍歷完 `s`，說明 `s` 是 `t` 的子序列，返回 `true`。

   - 否則，返回 `false`。

通過這種方法，我們可以高效地判斷一個字串是否為另一個字串的子序列，時間複雜度是 O(n)，其中 n 是字串 `t` 的長度。
