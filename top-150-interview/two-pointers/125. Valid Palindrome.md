# 125. Valid Palindrome

## Question

<span style="color: #16a34a;"><strong>Easy</strong></span>

A phrase is a **palindrome** if, after converting all uppercase letters into lowercase letters and removing all non-alphanumeric characters, it reads the same forward and backward. Alphanumeric characters include letters and numbers.

Given a string `s`, return `true`* if it is a **palindrome**, or *`false` *otherwise*.

## Answer

要判斷一個字串是否為迴文，我們需要執行以下步驟：

1. 將所有大寫字母轉換為小寫字母。

2. 移除所有非字母數字字元。

3. 判斷處理後的字串是否在正序和倒序下相同。

以下是詳細的 Java 實現：

```java
class Solution {
    public boolean isPalindrome(String s) {
        // 將字串轉換為小寫並移除非字母數字字元
        StringBuilder filtered = new StringBuilder();
        for (char c : s.toCharArray()) {
            if (Character.isLetterOrDigit(c)) {
                filtered.append(Character.toLowerCase(c));
            }
        }

        // 獲取處理後的字串
        String filteredStr = filtered.toString();
        int left = 0, right = filteredStr.length() - 1;

        // 雙指標判斷字串是否迴文
        while (left < right) {
            if (filteredStr.charAt(left) != filteredStr.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }

        return true;
    }

    public static void main(String[] args) {
        Solution sol = new Solution();
        System.out.println(sol.isPalindrome("A man, a plan, a canal: Panama")); // 應輸出 true
        System.out.println(sol.isPalindrome("race a car")); // 應輸出 false
        System.out.println(sol.isPalindrome(" ")); // 應輸出 true
        System.out.println(sol.isPalindrome("0P")); // 應輸出 false
    }
}
```

### 說明

1. **轉換為小寫並移除非字母數字字元**：

   - 使用 `StringBuilder` 來儲存過濾後的字元。

   - 遍歷字串的每個字元，檢查是否為字母或數字，如果是，則轉換為小寫並新增到 `StringBuilder` 中。

2. **判斷是否為迴文**：

   - 使用雙指標法，從字串的兩端向中間移動，逐個字元進行比較。

   - 如果在某個位置字元不相等，則返回 `false`。

   - 如果所有字元都相等，則返回 `true`。

通過這種方法，我們可以高效地判斷一個字串是否為迴文。
