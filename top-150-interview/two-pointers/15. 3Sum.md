# 15. 3Sum

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

給定一個整數陣列 `nums`，請找出所有由三個不同索引組成的三元組
`[nums[i], nums[j], nums[k]]`，使三個數字的總和為 `0`。

答案中不能包含重複的三元組。三元組內的元素順序，以及答案中各三元組的順序皆不影響結果。

[LeetCode 題目連結](https://leetcode.com/problems/3sum/)

### 範例 1

```text
輸入：nums = [-1, 0, 1, 2, -1, -4]
輸出：[[-1, -1, 2], [-1, 0, 1]]
```

### 範例 2

```text
輸入：nums = [0, 1, 1]
輸出：[]
```

### 範例 3

```text
輸入：nums = [0, 0, 0]
輸出：[[0, 0, 0]]
```

### 限制

- `3 <= nums.length <= 3000`
- `-10^5 <= nums[i] <= 10^5`

## Answer

### 解題思路

先將陣列排序，接著固定第一個數字 `nums[i]`，再使用左右雙指標尋找另外兩個數字：

1. `left` 從 `i + 1` 開始，`right` 從陣列尾端開始。
2. 計算 `nums[i] + nums[left] + nums[right]`：
   - 總和小於 `0`：增加 `left`，讓總和變大。
   - 總和大於 `0`：減少 `right`，讓總和變小。
   - 總和等於 `0`：加入結果，並同時移動兩個指標。
3. 為避免重複三元組，固定第一個數字時跳過相同值；找到解後，也跳過左右指標上的相同值。
4. 若固定的數字大於 `0`，因為陣列已排序，後續數字不可能讓總和回到 `0`，可以提早結束迴圈。

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;

class Solution {
    public List<List<Integer>> threeSum(int[] nums) {
        List<List<Integer>> result = new ArrayList<>();
        Arrays.sort(nums);

        // i 固定第一個數字後，還需要保留 left 與 right 兩個位置，
        // 因此 i 最多只能到 nums.length - 3，條件寫成 i < nums.length - 2。
        for (int i = 0; i < nums.length - 2; i++) {
            // 由小到大, 最小值已經大於 0 後續總和就不可能為 0
            if (nums[i] > 0) {
                break;
            }

            // 相同的第一個數字只需要處理一次。
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = nums.length - 1;

            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];

                if (sum < 0) {
                    left++;
                } else if (sum > 0) {
                    right--;
                } else {
                    result.add(Arrays.asList(nums[i], nums[left], nums[right]));
                    left++;
                    right--;

                    // 跳過相同的第二、第三個數字，避免產生重複結果。
                    while (left < right && nums[left] == nums[left - 1]) {
                        left++;
                    }
                    while (left < right && nums[right] == nums[right + 1]) {
                        right--;
                    }
                }
            }
        }

        return result;
    }
}
```

### 說明

1. 排序後，當總和小於 `0` 時向右移動 `left`，當總和大於 `0` 時向左移動 `right`，因此每次移動都能排除不可能的組合。
2. 固定 `nums[i]` 後，左右指標最多各掃描一次剩餘區間；外層迴圈最多執行 `n` 次。
3. 排序的時間複雜度為 `O(n log n)`，雙指標搜尋的時間複雜度為 `O(n^2)`，總時間複雜度為 `O(n^2)`。
4. 除了存放答案的空間外，演算法使用 `O(1)` 額外空間；若將排序實作的堆疊空間計入，則為 `O(log n)`。
