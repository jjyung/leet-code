# 167. Two Sum II - Input Array Is Sorted

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given a **1-indexed** array of integers `numbers` that is already ***sorted in non-decreasing order***, find two numbers such that they add up to a specific `target` number. Let these two numbers be `numbers[index1]` and `numbers[index2]` where `1 <= index1 < index2 <= numbers.length`.

Return *the indices of the two numbers,* `index1` *and* `index2`*, **added by one** as an integer array *`[index1, index2]` *of length 2.*

The tests are generated such that there is **exactly one solution**. You **may not** use the same element twice.

Your solution must use only constant extra space.

## Answer

要找到兩個數，使它們相加等於目標值，並且陣列是已排序的，可以使用雙指標的方法。這個方法只使用常數級的額外空間，符合題目要求。

### 詳細步驟

1. 初始化兩個指標，一個指向陣列的開頭（left），另一個指向陣列的末尾（right）。

2. 計算這兩個指標指向的數字的和。

   - 如果和等於目標值，返回這兩個指標的索引（注意題目要求索引從1開始）。

   - 如果和小於目標值，移動左指標，使和變大。

   - 如果和大於目標值，移動右指標，使和變小。

3. 重複步驟2，直到找到兩個數使它們的和等於目標值。

以下是詳細的 Java 實現：

```java
class Solution {
    public int[] twoSum(int[] numbers, int target) {
        int left = 0;
        int right = numbers.length - 1;
        
        while (left < right) {
            int sum = numbers[left] + numbers[right];
            
            if (sum == target) {
                return new int[]{left + 1, right + 1}; // 返回1-indexed結果
            } else if (sum < target) {
                left++; // 增大和
            } else {
                right--; // 減小和
            }
        }
        
        return new int[]{-1, -1}; // 按題目要求應該總是有解，這行實際上不會執行到
    }

    public static void main(String[] args) {
        Solution sol = new Solution();
        int[] numbers1 = {2, 7, 11, 15};
        int target1 = 9;
        int[] result1 = sol.twoSum(numbers1, target1);
        System.out.println("[" + result1[0] + ", " + result1[1] + "]"); // 應輸出 [1, 2]

        int[] numbers2 = {2, 3, 4};
        int target2 = 6;
        int[] result2 = sol.twoSum(numbers2, target2);
        System.out.println("[" + result2[0] + ", " + result2[1] + "]"); // 應輸出 [1, 3]

        int[] numbers3 = {-1, 0};
        int target3 = -1;
        int[] result3 = sol.twoSum(numbers3, target3);
        System.out.println("[" + result3[0] + ", " + result3[1] + "]"); // 應輸出 [1, 2]
    }
}
```

### 說明

1. **初始化指標**：

   - `left` 指向陣列的第一個元素。

   - `right` 指向陣列的最後一個元素。

2. **雙指標遍歷**：

   - 計算 `numbers[left]` 和 `numbers[right]` 的和。

   - 如果和等於目標值，返回這兩個指標的1-indexed索引。

   - 如果和小於目標值，移動左指標使和變大。

   - 如果和大於目標值，移動右指標使和變小。

3. **返回結果**：

   - 按題目要求，輸入資料總是保證有解，所以迴圈中一定會找到兩個數使它們的和等於目標值。

通過這種方法，可以在 O(n) 的時間複雜度內找到結果，並且只使用常數級的額外空間。
