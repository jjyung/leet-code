# 530. Minimum Absolute Difference in BST

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given the `root` of a Binary Search Tree (BST), return the minimum absolute difference between the values of any two different nodes in the tree.

## Answer

BST 中序走訪會得到遞增序列，因此最小差值一定出現在「相鄰」兩個值之間。

```java
class Solution {
  private Integer prev = null;
  private int minDiff = Integer.MAX_VALUE;

  public int getMinimumDifference(TreeNode root) {
    inorder(root);
    return minDiff;
  }

  private void inorder(TreeNode node) {
    if (node == null) {
      return;
    }

    inorder(node.left);

    if (prev != null) {
      minDiff = Math.min(minDiff, node.val - prev);
    }
    prev = node.val;

    inorder(node.right);
  }
}
```

### 說明

1. 以 inorder（`left -> root -> right`）訪問 BST，節點值自然遞增。
2. 每訪問到新節點時，只要和前一個節點值 `prev` 比較即可。
3. 逐步更新 `minDiff`，最終得到最小絕對差。

時間複雜度：O(n)  
空間複雜度：O(h)，`h` 為樹高（遞迴堆疊）

```

然後：

```
排序後找最小差值 → 只比較相鄰元素

```

所以這題完整思路是：

```
題目要找任兩個節點值的最小差
→ 不看樹上連線關係
→ 把 BST 用 inorder 轉成排序順序
→ 比較相鄰節點值
→ 得到答案

```
