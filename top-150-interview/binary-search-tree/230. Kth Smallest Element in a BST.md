# 230. Kth Smallest Element in a BST

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given the `root` of a binary search tree, and an integer `k`, return the `kth` smallest value (1-indexed) of all the values of the nodes in the tree.

## Answer

BST 的中序走訪（inorder）順序為 `left -> root -> right`，會得到由小到大的序列，所以只要走到第 `k` 個被拜訪的節點即可。

```java
import java.util.*;

class Solution {
    public int kthSmallest(TreeNode root, int k) {
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;

        // 只要還有目前節點，或 stack 中還有尚未處理的節點，就繼續走訪。
        while (cur != null || !stack.isEmpty()) {
            // 將目前節點與一路往左的所有節點依序壓入 stack。
            // 這些節點會按照「左子樹 -> 根節點」的順序被取出。
            while (cur != null) {
                stack.push(cur);
                cur = cur.left;
            }

            // 左側路徑已保存完成，取出中序走訪的下一個節點。
            cur = stack.pop();
            k--;

            // 中序走訪的第 k 個節點就是第 k 小的元素。
            if (k == 0) {
                return cur.val;
            }

            // 左子樹與目前節點都處理完後，改處理右子樹。
            // 下一輪會先走到右子樹最左側的節點。
            cur = cur.right;
        }

        // 題目保證 k 合法；走訪結束仍未找到時，代表輸入不符合題目條件。
        return -1;
    }
}
```

### 說明

1. `while (cur != null)` 會先把目前節點到最左側的路徑放入 stack，但此時只是暫存，還沒有正式拜訪這些節點。
2. `pop()` 一個節點時，才代表按照中序順序拜訪它；拜訪後將 `k` 減一。
3. 若 `k` 尚未歸零，就把 `cur` 移到右子樹；下一輪會先走到右子樹的最左側，再繼續遵循中序順序。
4. 當計數遞減到 `k == 0`，目前節點就是原始 `k` 所代表的第 `k` 小元素。
5. 題目保證 `k` 合法，因此正常情況一定會在迴圈中回傳。最後的 `return -1` 只是防禦性處理，表示輸入不符合題目條件。

時間複雜度：`O(h + k)`，`h` 為樹高；最壞情況為 `O(n)`。

空間複雜度：`O(h)`，stack 最多保存一條從根節點到葉節點的路徑。
