# 067. Add Binary

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given two binary strings `a` and `b`, return their sum as a binary string.

### Example 1

```text
Input: a = "11", b = "1"
Output: "100"
```

### Example 2

```text
Input: a = "1010", b = "1011"
Output: "10101"
```

### Constraints

- `1 <= a.length, b.length <= 10^4`
- `a` and `b` consist only of `'0'` or `'1'` characters。
- Each string does not contain leading zeros except for the zero itself。

<https://leetcode.com/problems/add-binary/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

從兩個二進位字串的最右側開始相加，模擬一般直式加法。每一位的總和由目前兩個位元和 `carry` 進位組成，再將該位結果加入 `StringBuilder`，並更新下一位要使用的進位。

若其中一個字串已經沒有可處理的位元，則將該字串的位元視為 `0`。處理完所有位元後，若仍有進位，需再補上一個 `'1'`。由於計算順序是由低位到高位，因此最後將 `StringBuilder` 反轉即可得到答案。

### Big-endian 補充

Endian 是描述多位元組資料與記憶體位址的排列方式：小端（little-endian）會將低位位元組資料儲存在低位址，大端（big-endian）會將高位位元組資料儲存在低位址。例如數值 `0x12345678` 若從低位址開始儲存，大端排列會先放 `0x12`，小端排列則會先放 `0x78`。

這題處理的是二進位字串，不涉及實際記憶體位址；但可以用相同概念理解高低位順序。輸入字串由左到右表示高位至低位，例如 `"1011"` 中，最左側的 `1` 代表 `2^3`，最右側的 `1` 代表 `2^0`，因此可視為一般 big-endian 的顯示順序。

不過，二進位加法必須從最低位開始處理，因此程式會從字串右側往左側走。這只是運算順序，不代表輸入資料改成 little-endian；`StringBuilder` 暫時依低位到高位累積結果，最後再反轉回一般的 big-endian 顯示順序。

```java
class Solution {
    public String addBinary(String a, String b) {
        StringBuilder result = new StringBuilder();
        int i = a.length() - 1;
        int j = b.length() - 1;
        int carry = 0;

        // 從最低位開始，逐位計算兩個二進位字串的總和。
        while (i >= 0 || j >= 0 || carry != 0) {
            int sum = carry;

            if (i >= 0) {
                sum += a.charAt(i) - '0';
                i--;
            }
            if (j >= 0) {
                sum += b.charAt(j) - '0';
                j--;
            }

            // sum % 2 是目前位元，sum / 2 是要帶到下一位的進位。
            result.append(sum % 2);
            carry = sum / 2;
        }

        // 目前結果是由低位到高位排列，因此需要反轉。
        return result.reverse().toString();
    }
}
```

### 說明

1. `i` 與 `j` 分別指向兩個字串的最右側，模擬從個位數開始的加法。
2. 每次將兩個位元與進位相加；`sum % 2` 產生目前位元，`sum / 2` 保留下一位的進位。
3. 迴圈條件包含 `carry != 0`，因此可以正確處理最後仍有進位的情況，例如 `"1" + "1"`。
4. **時間複雜度：** `O(max(m, n))`，其中 `m`、`n` 分別是 `a`、`b` 的長度。
5. **空間複雜度：** `O(max(m, n))`，用於儲存結果。
