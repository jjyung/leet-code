# 136. Single Number

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given a non-empty array of integers `nums`, every element appears twice except for one. Find that single one.

You must implement a solution with a linear runtime complexity and use only constant extra space.

### Example 1

```text
Input: nums = [2,2,1]
Output: 1
Explanation: The element 1 appears only once; the other element appears twice.
```

### Example 2

```text
Input: nums = [4,1,2,1,2]
Output: 4
Explanation: The element 4 appears only once; the other elements appear twice.
```

### Example 3

```text
Input: nums = [1]
Output: 1
Explanation: The only element appears once.
```

Constraints:

- `1 <= nums.length <= 3 * 10^{4}`
- `-3 * 10^{4} <= nums[i] <= 3 * 10^{4}`
- Each element in the array appears twice except for one element which appears only once.

## Answer

### 解題思路

使用 XOR（互斥或）累計陣列中的所有數字。XOR 有兩個關鍵性質：相同的數 XOR 後為 `0`（`x ^ x = 0`），而任何數與 `0` XOR 都會保留原值（`x ^ 0 = x`）。因此，成對的數字會互相抵消，最後留下只出現一次的數字。

從 `0` 開始累計並逐一處理陣列即可。這種作法只需一次走訪，額外只使用一個變數；負數也能直接使用 Java 的整數位元運算處理。

```java
class Solution {
    public int singleNumber(int[] nums) {
        int result = 0;

        // 逐一 XOR，讓成對的數字抵消，保留唯一未成對的值
        for (int num : nums) {
            result ^= num;
        }

        return result;
    }
}
```

### 複雜度

- 時間複雜度：`O(n)`，`n` 是陣列 `nums` 的元素數量；每個元素只處理一次。
- 空間複雜度：`O(1)`，只使用固定數量的額外變數。
