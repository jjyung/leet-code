# 137. Single Number II

<span style="color: #f59e0b;"><strong>Medium</strong></span>

## Problem

Given an integer array nums where every element appears three times except for one, which appears exactly once. Find the single element and return it.

You must implement a solution with a linear runtime complexity and use only constant extra space. 

### Example 1

```text
Input: nums = [2,2,3,2]
Output: 3
```

### Example 2

```text
Input: nums = [0,1,0,1,0,1,99]
Output: 99
```

### Constraints

- `1 <= nums.length <= 3 * 10^4`
- `-2^31 <= nums[i] <= 2^31 - 1`
- Each element in `nums` appears exactly three times except for one element which appears once.

## Answer

將所有數字的每一個 bit 分別計算出現次數。由於除了答案以外，其餘數字都會出現三次，因此每個 bit 的出現次數對 `3` 取餘數後，剩下的 bit 就是只出現一次的數字。

Java 的 `int` 固定有 32 個 bit，因此可以使用長度為 32 的陣列統計每個 bit。最後若第 `i` 個 bit 的計數不是 0，就將該 bit 設回答案。

```java
class Solution {
    public int singleNumber(int[] nums) {
        int[] bitCount = new int[32];

        // 統計每個 bit 在所有數字中出現的次數。
        for (int num : nums) {
            for (int bit = 0; bit < 32; bit++) {
                // 將第 bit 位移到最低位，取出 0 或 1 後累加其出現次數。
                bitCount[bit] += (num >>> bit) & 1;
            }
        }

        int result = 0;

        // 對 3 取餘數，重建只出現一次的數字。
        for (int bit = 0; bit < 32; bit++) {
            if (bitCount[bit] % 3 != 0) {
                // 將答案的第 bit 位設為 1，還原只出現一次的數字。
                result |= 1 << bit;
            }
        }

        return result;
    }
}
```

### 說明

1. `num >>> bit` 將目標 bit 移到最低位，再透過 `& 1` 取出該 bit；使用無號右移可正確處理負數的補數表示。
2. 出現三次的數字會讓每個 bit 的貢獻以 3 為週期抵銷，答案出現一次的 bit 則會留下餘數 `1`。
3. `result |= 1 << bit` 將餘數為 `1` 的 bit 設回答案，因此也能正確處理答案為負數的情況。

### 位元移位語法補充

Java 常見的位元移位運算如下：

| 語法 | 名稱 | 行為 |
| --- | --- | --- |
| `value << count` | 左移 | 向左移動 `count` 位，右側補 `0`。 |
| `value >> count` | 算術右移 | 向右移動 `count` 位，左側補上原本的符號位；正數補 `0`，負數補 `1`。 |
| `value >>> count` | 無號右移 | 向右移動 `count` 位，左側一律補 `0`。 |

`>>` 與 `>>>` 的差異在於右側移動後左側如何補值；`>>>` 多出來的第三個 `>` 代表無號右移。Java 沒有 `<<<` 運算子，左移只有 `<<`。

本題中，`num >>> bit` 是將指定 bit 移到最低位，再搭配 `& 1` 取出它；`1 << bit` 則是建立只有第 `bit` 位為 `1` 的遮罩，讓我們可以用 `|=` 將該 bit 放回答案。

4. 時間複雜度為 `O(32n) = O(n)`，其中 `n` 是 `nums` 的長度。
5. 空間複雜度為 `O(32) = O(1)`。
