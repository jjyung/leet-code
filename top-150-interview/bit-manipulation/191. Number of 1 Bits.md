# 191. Number of 1 Bits

<span style="color: #16a34a;"><strong>Easy</strong></span>

## Problem

Given a positive integer `n`, write a function that returns the number of set bits in its binary representation (also known as the Hamming weight).

### Example 1

```text
Input: n = 11
Output: 3
Explanation: The input binary string 1011 has a total of three set bits.
```

### Example 2

```text
Input: n = 128
Output: 1
Explanation: The input binary string 10000000 has a total of one set bit.
```

### Example 3

```text
Input: n = 2147483645
Output: 30
Explanation: The input binary string 1111111111111111111111111111101 has a total of thirty set bits.
```

Constraints:

`1 <= n <= 2^31 - 1`

Follow up: If this function is called many times, how would you optimize it?

## Answer

### 解題思路

每次執行 `n & (n - 1)` 都會清除 `n` 最右側的 `1`。因此，只要重複清除並計數，直到 `n` 變成 `0`，計數器就是原本二進位表示中的 `1` 數量。

這是因為二進位減 `1` 時，會從最右側的 `1` 借位：該位變成 `0`，右邊原本的 `0` 都變成 `1`。例如 `n = 12` 時，`n` 是 `1100`，`n - 1` 是 `1011`，逐位 AND 後得到 `1000`。原本最右側的 `1` 與減一後的 `0` 相 AND 而清除；右側的位元因 `0 & 1` 仍是 `0`，左側則保持不變。

此方法的迴圈次數等於 `n` 中 `1` 的個數；即使 `n` 很大，也不必逐一檢查每個位元。題目保證 `n` 為正整數，所以至少會執行一次迴圈；若延伸到 `n = 0`，迴圈會直接跳過並回傳 `0`。

```java
class Solution {
    public int hammingWeight(int n) {
        int bitCount = 0;

        // 每次清除最右側的 1，並累計清除次數。
        while (n != 0) {
            n &= n - 1;
            bitCount++;
        }

        return bitCount;
    }
}
```

### 說明

1. `n & (n - 1)` 會將最右側的 `1` 清為 `0`，其他位元維持不變，因此每次迴圈恰好計入一個 set bit。
2. 對單一位元為 `1` 的數字只會迴圈一次；對題目允許的最大值，最多迴圈 31 次。
3. 若此函式需要處理大量輸入，可預先建立 8 位元數值的 set bit 數量查表，將整數拆成位元組後查表加總，避免逐個清除位元。
4. 時間複雜度：令 `n` 為輸入整數、`k` 為其二進位表示中 `1` 的數量，為 `O(k)`，最壞情況為 `O(31)`。
5. 空間複雜度：`O(1)`，只使用固定數量的變數。
