# 201. Bitwise AND of Numbers Range

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given two integers left and right that represent the range [left, right], return the bitwise AND of all numbers in this range, inclusive.

### Example 1

```text
Input: left = 5, right = 7
Output: 4
```

### Example 2

```text
Input: left = 0, right = 0
Output: 0
```

### Example 3

```text
Input: left = 1, right = 2147483647
Output: 0
```

### Constraints

- `0 <= left <= right <= 2^31 - 1`

## Answer

### 解題思路

區間內所有數字做位元 AND 後，只有 `left` 與 `right` 從最高位開始相同的 bit 才可能保留為 `1`。只要某一位在區間中會從 `0` 變成 `1`，該位就一定存在某個數字為 `0`，AND 的結果便會是 `0`。

因此，同時將 `left` 與 `right` 右移，直到兩者相等；此時保留下來的值就是共同二進位前綴。最後再左移相同次數，於低位補回必為 `0` 的 bit，即為答案。

以 `left = 5`、`right = 7` 為例，區間中的數字為 `5`、`6`、`7`：

```text
5 = 101
6 = 110
7 = 111

101 & 110 & 111 = 100 = 4
```

程式不必逐一計算每個數字，而是找出 `5` 與 `7` 的共同前綴：

```text
left = 101, right = 111
右移一次：left = 10, right = 11
右移兩次：left = 1,  right = 1
```

兩者相等時保留的 `1` 是共同前綴，且共右移了兩次。因此將它左移兩次，補回兩個必為 `0` 的低位：`1 << 2 = 100 = 4`。

```java
class Solution {
	public int rangeBitwiseAnd(int left, int right) {
		int shiftedBits = 0;

		// 持續移除兩端不同的低位，留下兩數共同的二進位前綴。
		while (left != right) {
			left >>= 1;
			right >>= 1;
			shiftedBits++;
		}

		// 被移除的低位在原區間中至少會出現一個 0，因此補回時皆為 0。
		return left << shiftedBits;
	}
}
```

### 說明

1. 當 `left == right` 時，區間只有一個數字，迴圈不會執行並直接回傳該數字。
2. 當某個低位在 `left` 與 `right` 不同時，區間已跨越該位的進位點，所以該位的 AND 結果必為 `0`。
3. 迴圈結束時的 `left` 與 `right` 相同，代表它們的共同高位前綴；左移 `shiftedBits` 次即可重建答案。
4. 時間複雜度為 `O(log n)`，其中 `n` 是 `right` 的數值範圍上界；最多處理 31 個 bit。空間複雜度為 `O(1)`。
