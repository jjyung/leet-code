# 242. Valid Anagram

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given two strings s and t, return true if t is an anagram of s, and false otherwise.

### Example 1

```text
Input: s = "anagram", t = "nagaram"
Output: true
```

### Example 2

```text
Input: s = "rat", t = "car"
Output: false
```

### Constraints

- 1 <= s.length, t.length <= 5 * 10^4
- s and t consist of lowercase English letters.

**Follow up:** What if the inputs contain Unicode characters? How would you adapt your solution to such a case?

[LeetCode Problem Link](https://leetcode.com/problems/valid-anagram/)

## Answer

### 解題思路

若兩個字串互為異位詞，代表每個字元出現的次數完全相同，與字元排列順序無關。因此可以使用 `HashMap` 統計每個字元的出現次數：

1. 走訪 `s`，將每個字元的出現次數加一。
2. 走訪 `t`，將每個字元的出現次數減一；若 `t` 出現了 `s` 沒有的字元，直接回傳 `false`。
3. 若某個字元的計數扣除後變成 0，就從 `HashMap` 移除。
4. 走訪結束後，若 `HashMap` 為空，代表每個字元的數量都剛好抵銷，兩個字串就是異位詞。

若兩個字串長度不同，不可能互為異位詞，可以直接回傳 `false`。

### Java 程式碼

```java
import java.util.HashMap;

class Solution {
    public boolean isAnagram(String s, String t) {
        // 長度不同時，兩個字串不可能包含完全相同的字母數量。
        if (s.length() != t.length()) {
            return false;
        }

        HashMap<Character, Integer> count = new HashMap<>();

        // 統計 s 中每個字元的出現次數。
        for (char c : s.toCharArray()) {
            count.put(c, count.getOrDefault(c, 0) + 1);
        }

        // 扣除 t 中每個字元的出現次數。
        for (char c : t.toCharArray()) {
            if (!count.containsKey(c)) {
                // t 出現 s 沒有的字元，兩者不可能是異位詞。
                return false;
            }

            int remaining = count.get(c) - 1;
            if (remaining == 0) {
                // 數量剛好抵銷後移除，最後可用 map 是否為空判斷結果。
                count.remove(c);
            } else {
                count.put(c, remaining);
            }
        }

        return count.isEmpty();
    }
}
```

### 複雜度分析

- 時間複雜度：`O(n)`，其中 `n` 為字串長度；需要各走訪一次 `s` 與 `t`。
- 空間複雜度：`O(k)`，其中 `k` 為 `s` 中不同字元的數量。

### Follow-up：Unicode 字元

此解法使用 `HashMap`，因此比固定大小的字母陣列更容易延伸至 Unicode 字元。若需要正確處理由代理對組成的 Unicode code point，則應改以 `codePoints()` 逐一處理整數字元碼。
