# 128. Longest Consecutive Sequence

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an unsorted array of integers `nums`, return the length of the longest consecutive elements sequence.

You must write an algorithm that runs in O(n) time.

### Example 1

```text
Input: nums = [100,4,200,1,3,2]
Output: 4
Explanation: The longest consecutive elements sequence is [1, 2, 3, 4]. Therefore its length is 4.
```

### Example 2

```text
Input: nums = [0,3,7,2,5,8,4,6,0,1]
Output: 9
```

### Example 3

```text
Input: nums = [1,0,1,2]
Output: 3
```

### Constraints

- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`

## Answer

### 解題思路

先將所有數字放入 `HashSet`，讓我們可以在平均 O(1) 時間內判斷某個數字是否存在。

對集合中的每個數字 `num` 而言，只有在 `num - 1` 不存在時，`num` 才可能是某個連續序列的起點。從起點開始持續檢查 `num + 1`、`num + 2`……是否存在，並計算目前序列長度，再更新最大值。

直接走訪 `HashSet` 中的元素可以自然排除重複數字，避免同一個連續序列被重複掃描。由於每個不重複的數字最多被加入集合一次、也最多在延伸序列時檢查一次，因此整體平均時間複雜度為 O(n)。

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> numbers = new HashSet<>();

        // 將所有數字放入集合，去除重複值並支援快速查找。
        for (int num : nums) {
            numbers.add(num);
        }

        int longest = 0;

        // 只從沒有前驅數字的元素開始，確保它是連續序列的起點。
        for (int num : numbers) {
            if (numbers.contains(num - 1)) {
                continue;
            }

            int currentNum = num;
            int currentLength = 1;

            // 從起點向後延伸，計算這個連續序列的長度。
            while (numbers.contains(currentNum + 1)) {
                currentNum++;
                currentLength++;
            }

            longest = Math.max(longest, currentLength);
        }

        return longest;
    }
}
```

### 說明

1. `HashSet` 能在平均 O(1) 時間內檢查數字是否存在，因此不需要先排序陣列。
2. `num - 1` 不存在代表 `num` 是序列起點；只從起點開始延伸，可避免重複計算。
3. 使用集合走訪可以排除重複元素，符合題目要求並維持線性時間的平均複雜度。
4. 時間複雜度為 **O(n)**，其中 `n` 是陣列長度；空間複雜度為 **O(n)**，用來儲存集合。
