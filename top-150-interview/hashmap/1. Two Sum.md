# 1. Two Sum

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

You are given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to `target`.

You may assume that each input would have exactly one solution, and you may not use the same element twice.

You can return the answer in any order.

### Example 1

```text
Input: nums = [2,7,11,15], target = 9
Output: [0,1]
Explanation: Because nums[0] + nums[1] == 9, we return [0, 1].
```

### Example 2

```text
Input: nums = [3,2,4], target = 6
Output: [1,2]
Explanation: Because nums[1] + nums[2] == 6, we return [1, 2].
```

### Example 3

```text
Input: nums = [3,3], target = 6
Output: [0,1]
Explanation: Because nums[0] + nums[1] == 6, we return [0, 1].
```

### Constraints

- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- Only one valid answer exists.

Follow-up: Can you come up with an algorithm that is less than O(n2) time complexity?

<https://leetcode.com/problems/two-sum/>

## Answer

### 解題思路

使用 `HashMap` 記錄已經走訪過的數字與索引，讓我們能在 O(1) 平均時間內查找目前數字所需要的配對值。

對於目前的 `nums[i]`，其配對值為 `target - nums[i]`。若配對值已存在於 `HashMap`，代表先前的索引與 `i` 就是答案；否則將目前數字及其索引加入 `HashMap`，繼續處理下一個元素。

查找必須放在加入目前元素之前，因此即使陣列中有重複值，也不會使用同一個索引兩次。題目保證一定存在唯一解，因此迴圈結束後的預設回傳值只用來滿足 Java 方法的語法要求。

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        // key 為已走訪的數字，value 為該數字在陣列中的索引。
        Map<Integer, Integer> indexByNumber = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];

            // 先查找配對值，確保不會重複使用目前的索引。
            if (indexByNumber.containsKey(complement)) {
                return new int[] {indexByNumber.get(complement), i};
            }

            // 找不到配對值時，保存目前數字，供後續元素查找。
            indexByNumber.put(nums[i], i);
        }

        // 題目保證存在唯一解；此行僅為符合 Java 回傳型別要求。
        return new int[0];
    }
}
```

### 說明

1. `HashMap` 儲存的是「已走訪數字 → 索引」，每次只需查找 `target - nums[i]`。
2. 先查找再加入目前元素，可正確處理 `[3, 3]` 這類重複值案例。
3. 負數與 `target` 的範圍都能直接使用整數運算；依題目限制，`target - nums[i]` 仍在 `int` 可表示的範圍內。
4. 設 `n` 為 `nums` 的長度，每個元素最多被走訪一次，因此時間複雜度為 **O(n)**，`HashMap` 最多儲存 `n` 個元素，空間複雜度為 **O(n)**。
