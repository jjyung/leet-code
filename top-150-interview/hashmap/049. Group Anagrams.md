# 049. Group Anagrams

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an array of strings `strs`, group the anagrams together. You can return the answer in any order.

<https://leetcode.com/problems/group-anagrams/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

這題核心是把「同一組 anagram」映射到同一個 key。最直覺做法是把每個字串排序後作為 key。

```java
import java.util.*;

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();

        for (String s : strs) {
            char[] chars = s.toCharArray();
            Arrays.sort(chars);
            String key = new String(chars);

            map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }

        return new ArrayList<>(map.values());
    }
}
```

### 說明

1. Anagram 的特性是字母組成相同，因此排序後的字串會一致。
2. 用 `Map<String, List<String>>` 儲存分組，key 是排序後字串，value 是原字串清單。
3. 每遇到一個字串就計算 key，追加到對應群組。
4. 最後回傳 `map.values()` 轉為 `List<List<String>>`。

時間複雜度：O(n * k log k)，其中 `n` 是字串數量、`k` 是平均字串長度。  
空間複雜度：O(n * k)
