# 290. Word Pattern

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

[LeetCode 題目連結](https://leetcode.com/problems/word-pattern/)

Given a pattern and a string s, find if s follows the same pattern.

Here follow means a full match, such that there is a bijection between a letter in pattern and a non-empty word in s. Specifically:

Each letter in pattern maps to exactly one unique word in s.
Each unique word in s maps to exactly one letter in pattern.
No two letters map to the same word, and no two words map to the same letter.
 

Example 1:

Input: pattern = "abba", s = "dog cat cat dog"

Output: true

Explanation:

The bijection can be established as:

'a' maps to "dog".
'b' maps to "cat".
Example 2:

Input: pattern = "abba", s = "dog cat cat fish"

Output: false

Example 3:

Input: pattern = "aaaa", s = "dog cat cat dog"

Output: false

## Answer

### 解題思路

這題要求 `pattern` 中的每個字母與 `s` 中的單字建立一對一的映射關係，因此需要同時檢查兩個方向：

- `字母 → 單字`：同一個字母必須固定對應到同一個單字。
- `單字 → 字母`：不同字母不能對應到同一個單字。

使用兩個 `HashMap` 儲存雙向映射。逐一比對每個字母與單字：

1. 若字母已經有映射，確認它是否對應目前單字。
2. 若單字已經有映射，確認它是否對應目前字母。
3. 若兩者都尚未出現，建立雙向映射。

此外，`pattern` 的長度必須與單字數量相同，否則不可能完全匹配。

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean wordPattern(String pattern, String s) {
        String[] words = s.split("\\s+");

        if (pattern.length() != words.length) {
            return false;
        }

        Map<Character, String> charToWord = new HashMap<>();
        Map<String, Character> wordToChar = new HashMap<>();

        for (int i = 0; i < pattern.length(); i++) {
            char character = pattern.charAt(i);
            String word = words[i];

            if (charToWord.containsKey(character)
                    && !charToWord.get(character).equals(word)) {
                return false;
            }

            if (wordToChar.containsKey(word)
                    && wordToChar.get(word) != character) {
                return false;
            }

            charToWord.put(character, word);
            wordToChar.put(word, character);
        }

        return true;
    }
}
```

### 說明

1. 先將字串切分成單字，並檢查單字數量是否等於 `pattern` 長度。
2. 每次檢查字母與單字的既有映射，避免同一字母對應多個單字。
3. 同時檢查反向映射，避免多個字母對應同一個單字。
4. 所有字母與單字都符合雙向映射時，回傳 `true`。
5. 時間複雜度為 `O(n)`，其中 `n` 為 `pattern` 的長度。
6. 空間複雜度為 `O(n)`，用於儲存雙向映射與切分後的單字。

### 為什麼字串比較要使用 `equals()`？

Java 中：

- `equals()` 比較兩個 `String` 的內容是否相同。
- `==` 比較兩個變數是否指向同一個物件，也就是參考是否相同。

Java 確實有 String Pool。字串常值例如：

```java
String first = "dog";
String second = "dog";
```

通常會共用 String Pool 中的同一個物件，因此 `first == second` 可能是 `true`。但這只是特定情況，不能依賴它判斷字串內容。

本題的單字來自 `s.split("\\s+")`，屬於執行時期產生的字串。即使內容相同，也不保證它與 String Pool 中的字串是同一個物件，例如：

```java
String first = new String("dog");
String second = "dog";

System.out.println(first == second);      // false：參考不同
System.out.println(first.equals(second)); // true：內容相同
```

因此程式中使用 `charToWord.get(character).equals(word)`，才能正確比較單字內容。若使用 `==`，可能因為兩個字串是不同物件而錯誤回傳 `false`。
