# 205. Isomorphic Strings

## Question

<span style="color: #16a34a;"><strong>Easy</strong></span>

給定兩個字串 `s` 與 `t`，請判斷它們是否為同構（isomorphic）字串。

若 `s` 中的每個字元都可以「一對一」替換成 `t` 中的字元，且替換後可得到 `t`，則兩者同構。

規則如下：

1. `s` 中相同字元，必須對應到 `t` 中相同字元。
2. `s` 中不同字元，不能對應到 `t` 中同一個字元。
3. 字元可以對應到自己。

<https://leetcode.com/problems/isomorphic-strings/>

## Answer

使用兩個 HashMap 來維護雙向映射：

1. `sToT`：記錄 `s` 的字元對應到 `t` 的哪個字元。
2. `tToS`：記錄 `t` 的字元對應回 `s` 的哪個字元。

逐一掃描字元時：

1. 若映射已存在，必須與目前字元一致，否則回傳 `false`。
2. 若映射不存在，建立雙向映射。

全部檢查完都沒有衝突就回傳 `true`。

```java
import java.util.HashMap;
import java.util.Map;

class Solution {
    public boolean isIsomorphic(String s, String t) {
        if (s.length() != t.length()) {
            return false;
        }

        Map<Character, Character> sToT = new HashMap<>();
        Map<Character, Character> tToS = new HashMap<>();

        for (int i = 0; i < s.length(); i++) {
            char cs = s.charAt(i);
            char ct = t.charAt(i);

            if (sToT.containsKey(cs) && sToT.get(cs) != ct) {
                return false;
            }
            if (tToS.containsKey(ct) && tToS.get(ct) != cs) {
                return false;
            }

            sToT.put(cs, ct);
            tToS.put(ct, cs);
        }

        return true;
    }
}
```

### 說明

1. 雙向映射可同時避免「一對多」與「多對一」的衝突。
2. 每個位置只做常數次查表與寫表，流程清楚且容易驗證正確性。
3. 時間複雜度：`O(n)`，其中 `n` 為字串長度。
4. 空間複雜度：`O(k)`，其中 `k` 為不同字元數量（最壞情況可視為 `O(n)`）。
