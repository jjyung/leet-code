# 219. Contains Duplicate II

<span style="color: #16a34a;"><strong>Easy</strong></span>

## Problem

Given an integer array nums and an integer k, return true if there are two distinct indices i and j in the array such that nums[i] == nums[j] and abs(i - j) <= k.

 

### Example 1

```text
Input: nums = [1,2,3,1], k = 3
Output: true
```

### Example 2

```text
Input: nums = [1,0,1,1], k = 1
Output: true
```

### Example 3

```text
Input: nums = [1,2,3,1,2,3], k = 2
Output: false
```
 

### Constraints

1 <= nums.length <= 105
-109 <= nums[i] <= 109
0 <= k <= 105

## Answer

使用大小最多為 `k` 的滑動視窗，維護目前索引前方、距離不超過 `k` 的元素。

對每個 `nums[i]` 依序處理：

1. 若 `HashSet` 已包含 `nums[i]`，代表視窗內存在另一個相同元素，且兩個索引距離不超過 `k`，直接回傳 `true`。
2. 將 `nums[i]` 加入視窗。
3. 當 `i >= k` 時，移除索引 `i - k` 的元素，讓下一輪視窗維持最多 `k` 個較近的元素。

若掃描結束仍未找到重複元素，則回傳 `false`。

```java
import java.util.HashSet;
import java.util.Set;

class Solution {
    public boolean containsNearbyDuplicate(int[] nums, int k) {
        Set<Integer> window = new HashSet<>();

        for (int i = 0; i < nums.length; i++) {
            // 視窗內出現相同值，表示存在符合條件的兩個索引。
            if (window.contains(nums[i])) {
                return true;
            }

            window.add(nums[i]);

            // 移除距離下一個索引已超過 k 的最舊元素。
            if (i >= k) {
                window.remove(nums[i - k]);
            }
        }

        return false;
    }
}
```

### 說明

1. `HashSet` 能在平均 `O(1)` 時間內判斷元素是否已存在。
2. 滑動視窗只保留可能與目前元素形成合法索引距離的元素。
3. 時間複雜度為 `O(n)`，其中 `n` 是陣列長度。
4. 空間複雜度為 `O(min(n, k))`。
