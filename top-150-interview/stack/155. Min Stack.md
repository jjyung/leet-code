# 155. Min Stack

<span style="color: #f59e0b;"><strong>Medium</strong></span>

## Problem

Design a stack that supports push, pop, top, and retrieving the minimum element in constant time.

Implement the MinStack class:

MinStack() initializes the stack object.
void push(int value) pushes the element value onto the stack.
void pop() removes the element on the top of the stack.
int top() gets the top element of the stack.
int getMin() retrieves the minimum element in the stack.
You must implement a solution with O(1) time complexity for each function.



Example 1:

Input
```
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]
```
Output
```
[null,null,null,null,-3,null,0,-2]
```

Explanation
MinStack minStack = new MinStack();
minStack.push(-2);
minStack.push(0);
minStack.push(-3);
minStack.getMin(); // return -3
minStack.pop();
minStack.top();    // return 0
minStack.getMin(); // return -2

## Answer

`Deque` 是 Java 的雙端佇列，可以從頭尾兩端操作元素；這裡使用它的 `push`、`pop` 與 `peek` 方法來模擬堆疊。

使用兩個堆疊：

- `stack` 儲存所有元素。
- `minStack` 儲存每個位置對應的最小值。

執行 `push` 時，將新元素放入 `stack`；若 `minStack` 為空，或新元素小於等於目前最小值，便將新元素也放入 `minStack`。執行 `pop` 時，若移除的元素等於目前最小值，同時從 `minStack` 移除頂端元素。如此一來，`minStack` 的頂端永遠是目前堆疊中的最小值。

每個操作都只涉及堆疊頂端，因此可以在 `O(1)` 時間內完成。

```java
import java.util.ArrayDeque;
import java.util.Deque;

class MinStack {
    private final Deque<Integer> stack;
    private final Deque<Integer> minStack;

    public MinStack() {
        stack = new ArrayDeque<>();
        minStack = new ArrayDeque<>();
    }

    public void push(int val) {
        stack.push(val);

        if (minStack.isEmpty() || val <= minStack.peek()) {
            minStack.push(val);
        }
    }

    public void pop() {
        int removed = stack.pop();

        if (removed == minStack.peek()) {
            minStack.pop();
        }
    }

    public int top() {
        return stack.peek();
    }

    public int getMin() {
        return minStack.peek();
    }
}
```

### 說明

1. 使用 `<=` 儲存重複的最小值，確保其中一個最小值被移除後，仍能正確取得下一個最小值。
2. `stack` 與 `minStack` 的每次操作皆為 `O(1)`。
3. 時間複雜度：`push`、`pop`、`top`、`getMin` 皆為 `O(1)`。
4. 空間複雜度：`O(n)`，其中 `n` 為堆疊中的元素數量。
