# 071. Simplify Path

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

You are given an absolute path for a Unix-style file system, which always begins with a slash `/`. Transform this path into its simplified canonical path.

Rules:

- `.` means current directory.
- `..` means parent directory.
- Multiple slashes should be treated as a single slash.
- Other forms like `...` are treated as normal directory names.

<https://leetcode.com/problems/simplify-path/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

使用 stack（或 deque）模擬目錄導航：

- 正常目錄名稱：push
- `..`：pop 一層（若可 pop）
- `.` 與空字串：忽略

```java
import java.util.*;

class Solution {
    public String simplifyPath(String path) {
        String[] parts = path.split("/");
        Deque<String> stack = new ArrayDeque<>();

        for (String part : parts) {
            if (part.equals("") || part.equals(".")) {
                continue;
            }

            if (part.equals("..")) {
                if (!stack.isEmpty()) {
                    stack.pollLast();
                }
            } else {
                stack.offerLast(part);
            }
        }

        StringBuilder result = new StringBuilder();
        for (String dir : stack) {
            result.append('/').append(dir);
        }

        return result.length() == 0 ? "/" : result.toString();
    }
}
```

### 說明

1. `split("/")` 後會出現空字串，代表連續斜線，要忽略。
2. `.` 代表停留在原地，直接忽略。
3. `..` 代表回上一層，若 stack 不為空就移除最後一層。
4. 其他 token 都視為有效目錄名稱（包含 `...`），加入 stack。
5. 最後將 stack 中的路徑用 `/` 串接；若為空，回傳根目錄 `/`。

時間複雜度：O(n)  
空間複雜度：O(n)
