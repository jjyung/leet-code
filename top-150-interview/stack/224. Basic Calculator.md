# 224. Basic Calculator

## Problem

<span style="color: #ef4444;"><strong>Hard</strong></span>

Given a string s representing a valid expression, implement a basic calculator to evaluate it, and return the result of the evaluation.

Note: You are not allowed to use any built-in function which evaluates strings as mathematical expressions, such as eval().

Constraints:

- 1 <= s.length <= 3 * 10<sup>5</sup>
- s consists of digits, '+', '-', '(', ')', and ' '.
- s represents a valid expression.
- '+' is not used as a unary operation (i.e., "+1" and "+(2 + 3)" is invalid).
- '-' could be used as a unary operation (i.e., "-1" and "-(2 + 3)" is valid).
- There will be no two consecutive operators in the input.
- Every number and running calculation will fit in a signed 32-bit integer.

### Example 1

```text
Input: s = "1 + 1"
Output: 2
```

### Example 2

```text
Input: s = " 2-1 + 2 "
Output: 3
```

### Example 3

```text
Input: s = "(1+(4+5+2)-3)+(6+8)"
Output: 23
```

## Answer

### 解題思路

只有加減法時，同一層括號內可以由左到右計算；括號則要先算完內層，再把整個結果視為外層的一個數字。使用堆疊保存尚未完成的外層狀態，不使用遞迴，以免括號很深時耗盡呼叫堆疊。

維護三個變數：

- `result`：目前括號層已結算的總和，不含正在讀取的數字。
- `number`：目前連續數字所組成的非負整數。
- `sign`：`number` 或接下來括號結果的符號，為 `1` 或 `-1`。

每個堆疊元素是一個完整的 `Context`，包含外層的總和 `subtotal` 與括號前的符號 `sign`。堆疊起初為空，頂端永遠對應最近一個尚未配對的左括號。

依序掃描字元：

1. **數字**：用 `number = number * 10 + digit` 組合多位數。
2. **`+` 或 `-`**：將 `sign * number` 加入 `result`，清空 `number`，再設定下一項的符號。
3. **`(`**：將目前的 `result`、`sign` 包成一個狀態推入堆疊，並將內層重設為 `result = 0`、`number = 0`、`sign = 1`。
4. **`)`**：先結算內層最後一個數字，再取出最近的外層狀態，合併為 `外層總和 + 括號前的符號 × 內層結果`，最後清空 `number` 並重設 `sign`。
5. **空白**：略過，不改變狀態。

掃描結束後，還要結算最後的 `sign * number`，避免漏掉沒有接運算子的最後一個數字。

### Java 程式碼

```java
import java.util.ArrayDeque;
import java.util.Deque;

class Solution {
    private static class Context {
        final long subtotal;
        final int sign;

        Context(long subtotal, int sign) {
            this.subtotal = subtotal;
            this.sign = sign;
        }
    }

    public int calculate(String s) {
        // 每個元素保存一層外部總和與括號前的符號。
        Deque<Context> contexts = new ArrayDeque<>();
        long result = 0;
        long number = 0;
        int sign = 1;

        for (int index = 0; index < s.length(); index++) {
            char current = s.charAt(index);

            if (current >= '0' && current <= '9') {
                number = number * 10 + (current - '0');
            } else if (current == '+' || current == '-') {
                // 運算子代表上一個數字已完整，先依原本的符號結算。
                result += sign * number;
                number = 0;
                sign = current == '+' ? 1 : -1;
            } else if (current == '(') {
                // 暫存外層，讓內層從獨立的初始狀態開始計算。
                contexts.push(new Context(result, sign));
                result = 0;
                number = 0;
                sign = 1;
            } else if (current == ')') {
                result += sign * number;
                Context outer = contexts.pop();
                // 整個括號視為外層的一項，套用括號前的符號。
                result = outer.subtotal + outer.sign * result;
                number = 0;
                sign = 1;
            }
        }

        // 題目保證答案落在 int 範圍；long 避免尚未套用負號時溢位。
        return (int) (result + sign * number);
    }
}
```

### 正確性與邊界條件

- **迴圈不變量**：在目前括號層，`result` 保存已完成項目的帶符號總和，`number` 保存尚未結算的數字，`sign` 決定該數字的正負。遇到運算子時結算上一項，因此不會漏算或重複計算。
- **括號配對**：進入括號時保存外層，離開時依後進先出順序還原最近的外層。內層計算完成後只合併一次，等同先算括號再套用外部運算子；任意深度的巢狀括號都遵循相同規則。
- **一元負號**：開頭或左括號後的 `-` 會先結算 `0`，再將 `sign` 設為 `-1`。例如 `-(2 + 3)` 保存外層狀態 `(0, -1)`，內層得到 `5`，合併後為 `-5`；`1-(-2)` 也能正確處理。
- **單一數字、多位數與空白**：數字連續累積，空白不影響狀態，最後一項在迴圈結束時結算。
- **整數邊界**：使用 `long` 保存數值與總和，避免讀取 `-2147483648` 時，其尚未套用負號的大小 `2147483648` 超出 `int`。最終答案依題目保證轉回 `int`。
- **輸入有效性**：題目保證字串非空、運算式有效且括號配對，因此不需要處理空字串、非法字元或缺少左括號的情況。

### 複雜度分析

令 `n` 為字串 `s` 的長度，`d` 為括號的最大巢狀深度。

- **時間複雜度：`O(n)`**。每個字元只掃描一次，每個括號狀態最多推入、取出各一次，堆疊操作的攤銷時間為 `O(1)`。
- **空間複雜度：`O(d)`，最壞為 `O(n)`**。堆疊只保存尚未完成的外層狀態，其餘變數使用固定空間。
