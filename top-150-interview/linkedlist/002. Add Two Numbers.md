# 002. Add Two Numbers

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

You are given two non-empty linked lists representing two non-negative integers. The digits are stored in reverse order, and each node contains a single digit. Add the two numbers and return the sum as a linked list.

## Answer

因為是反向儲存，從頭節點開始剛好就是個位數，可直接模擬直式加法。

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummy = new ListNode(0);
        ListNode cur = dummy;
        int carry = 0;

        while (l1 != null || l2 != null || carry != 0) {
            int x = (l1 != null) ? l1.val : 0;
            int y = (l2 != null) ? l2.val : 0;

            int sum = x + y + carry;
            carry = sum / 10;

            cur.next = new ListNode(sum % 10);
            cur = cur.next;

            if (l1 != null) l1 = l1.next;
            if (l2 != null) l2 = l2.next;
        }

        return dummy.next;
    }
}
```

### 說明

1. 使用 `dummy` 節點簡化新 linked list 建構。
2. 每輪取 `l1`、`l2` 當前位數，若節點不存在則視為 `0`。
3. `sum = x + y + carry`，新節點值為 `sum % 10`，進位為 `sum / 10`。
4. 迴圈條件包含 `carry != 0`，確保最後仍有進位時可補一個節點。
5. 回傳 `dummy.next` 即為答案。

時間複雜度：O(max(m, n))  
空間複雜度：O(max(m, n))（輸出 linked list）

## Step 3

```
3 + 4 + carry(1) = 8

```

答案：

```
7 -> 0 -> 8

```

```
dummy node
```

# 為什麼需要 dummy node？

如果不用 dummy node：

第一個節點通常要特殊處理。

例如：

```
if (head == null) {
    head = newNode;
}

```

很煩。

# Dummy Node 思想

先建立一個假的頭：

```
ListNode dummy = new ListNode(0);
ListNode current = dummy;

```

一開始：

```
dummy
  |
  v
[0]

```

---

# 接第一個節點

```
current.next = new ListNode(7);
current = current.next;

```

變成：

```
[0] -> [7]

```

---

# 再接下一個

```
[0] -> [7] -> [0]

```

---

# 最後

```
[0] -> [7] -> [0] -> [8]

```

真正答案：

```
return dummy.next;

```

也就是：

```
[7] -> [0] -> [8]

```

```
消除第一個節點的特殊情況
```

讓所有節點：

```
統一邏輯
```

這是工程上很常見的技巧。

# Java 解法

```
class Solution {

    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {

        ListNode dummy = new ListNode(0);
        ListNode current = dummy;

        int carry = 0;

        while (l1 != null || l2 != null || carry != 0) {

            int x = (l1 != null) ? l1.val : 0;
            int y = (l2 != null) ? l2.val : 0;

            int sum = x + y + carry;

            carry = sum / 10;
            int digit = sum % 10;

            current.next = new ListNode(digit);

            current = current.next;

            if (l1 != null) {
                l1 = l1.next;
            }

            if (l2 != null) {
                l2 = l2.next;
            }
        }

        return dummy.next;
    }
}

```

# 最重要的注意點

# 1\. while 條件

很多人會寫：

```
while (l1 != null && l2 != null)
```

這是錯的。

---

# 為什麼？

因為：

## linked list 長度可能不同

例如：

```
[9,9,9]
[1]
```

---

# 而且最後可能還有 carry

例如：

```
999 + 1 = 1000
```

最後還要再多一位。

---

# 正確寫法

```
while (l1 != null || l2 != null || carry != 0)
```

---

# 2\. null 要當 0

這段很重要：

```
int x = (l1 != null) ? l1.val : 0;
```

因為：

```
長度可能不同
```

---

# 3\. carry 不要忘記

例如：

```
9 + 9 = 18
```

要：

```
digit = 8
carry = 1
```

# 這題的模板感很重

很多 linked list 題都會長這樣：

```
ListNode dummy = new ListNode(0);
ListNode current = dummy;

while (...) {

    current.next = ...

    current = current.next;
}

return dummy.next;

```

這是一個非常值得熟記的 linked list 模板。
