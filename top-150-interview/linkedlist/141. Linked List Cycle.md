# 141. Linked List Cycle

## Question

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given `head`, the head of a linked list, determine if the linked list has a cycle in it.

There is a cycle if some node can be reached again by continuously following the `next` pointer.

<https://leetcode.com/problems/linked-list-cycle/description/?envType=study-plan-v2&envId=top-interview-150>

## Answer

使用 Floyd 快慢指標（龜兔賽跑）：

- `slow` 每次走 1 步
- `fast` 每次走 2 步

若有環，兩者一定會相遇；若無環，`fast` 或 `fast.next` 會先變成 `null`。

```java
public class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;

        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;

            if (slow == fast) {
                return true;
            }
        }

        return false;
    }
}
```

### 說明

1. `fast != null && fast.next != null` 用來避免存取 `fast.next.next` 時發生空指標。
2. 在有環情況下，`fast` 每輪都比 `slow` 多前進 1 步，距離會在環中逐步縮短。
3. 若最終能相遇，代表存在 cycle；若 `fast` 走到終點，代表沒有 cycle。

時間複雜度：O(n)  
空間複雜度：O(1)
