# 215. Kth Largest Element in an Array

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an integer array `nums` and an integer `k`, return the kth largest element in the array.

Note that it is the kth largest element in the sorted order, not the kth distinct element.

Can you solve it without sorting?

### Example 1

```text
Input: nums = [3,2,1,5,6,4], k = 2
Output: 5
Explanation: After sorting in descending order, the second element is 5.
```

### Example 2

```text
Input: nums = [3,2,3,1,2,4,5,5,6], k = 4
Output: 4
Explanation: After sorting in descending order, the fourth element is 4.
```

### Constraints

- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

[LeetCode 題目連結](https://leetcode.com/problems/kth-largest-element-in-an-array/description/?envType=study-plan-v2&envId=top-interview-150)

## Answer

### 方法一：固定大小的最小堆（推薦）

使用大小為 `k` 的最小堆，維護目前看過的 `k` 個最大元素：

1. 將每個數字加入最小堆。
2. 當堆的大小超過 `k` 時，移除堆頂，也就是目前 `k` 個元素中最小的值。
3. 掃描完陣列後，堆頂就是第 `k` 大的元素。重複數字會保留，因此符合題目所說的「排序後的第 `k` 大」定義。

```java
import java.util.PriorityQueue;

class Solution {
    public int findKthLargest(int[] nums, int k) {
        // 最小堆的堆頂是目前保留元素中的最小值。
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();

        for (int num : nums) {
            minHeap.offer(num);

            // 只保留最大的 k 個元素，移除多出的最小值。
            if (minHeap.size() > k) {
                minHeap.poll();
            }
        }

        // 堆中最小的元素即為第 k 大的元素。
        return minHeap.peek();
    }
}
```

### 說明

- 時間複雜度：`O(n log k)`，其中 `n` 是陣列長度；每個元素至多加入及移除堆各一次。
- 空間複雜度：`O(k)`，最小堆最多只保存 `k` 個元素。

### 方法二：最大堆取出 `k - 1` 次

最大堆的堆頂永遠是目前最大的元素，因此可以先將所有數字加入最大堆，再移除堆頂 `k - 1` 次，最後堆頂就是第 `k` 大的元素。

```java
import java.util.Collections;
import java.util.PriorityQueue;

class Solution {
    public int findKthLargest(int[] nums, int k) {
        // Collections.reverseOrder() 將 PriorityQueue 改為最大堆。
        PriorityQueue<Integer> maxHeap =
                new PriorityQueue<>(Collections.reverseOrder());

        for (int num : nums) {
            maxHeap.offer(num);
        }

        // 移除前 k - 1 個較大的元素，堆頂即為第 k 大元素。
        for (int i = 1; i < k; i++) {
            maxHeap.poll();
        }

        return maxHeap.peek();
    }
}
```

### 兩種方法的差異

| 方法 | 核心想法 | 時間複雜度 | 空間複雜度 | 特點 |
| --- | --- | --- | --- | --- |
| 固定大小的最小堆 | 保留目前最大的 `k` 個元素 | `O(n log k)` | `O(k)` | 適合 `k` 遠小於 `n`，較節省資源 |
| 最大堆 | 保存全部元素，移除前 `k - 1` 大元素 | `O(n log n)` | `O(n)` | 思路直觀，適合用來理解堆頂取最大值 |

兩種方法都能正確處理重複值。實務上通常優先使用固定大小的最小堆；如果只追求最直觀的解法，最大堆會更容易想到。以上兩段程式碼請分別提交，不能同時放在同一個 Java 檔案中，因為都宣告了 `class Solution`。
