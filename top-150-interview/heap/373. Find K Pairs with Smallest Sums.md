# 373. Find K Pairs with Smallest Sums

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

You are given two integer arrays `nums1` and `nums2` sorted in non-decreasing order and an integer `k`.

Define a pair `(u, v)` which consists of one element from the first array and one element from the second array.

Return the `k` pairs `(u1, v1), (u2, v2), ..., (uk, vk)` with the smallest sums.

### Example 1

```text
Input: nums1 = [1,7,11], nums2 = [2,4,6], k = 3
Output: [[1,2],[1,4],[1,6]]
Explanation: The first 3 pairs are returned from the sequence: [1,2],[1,4],[1,6],[7,2],[7,4],[11,2],[7,6],[11,4],[11,6]
```

### Example 2

```text
Input: nums1 = [1,1,2], nums2 = [1,2,3], k = 2
Output: [[1,1],[1,1]]
Explanation: The first 2 pairs are returned from the sequence: [1,1],[1,1],[1,2],[2,1],[1,2],[2,2],[1,3],[1,3],[2,3]
```

### Constraints

- `1 <= nums1.length, nums2.length <= 10^5`
- `-10^9 <= nums1[i], nums2[i] <= 10^9`
- `nums1` and `nums2` are both sorted in non-decreasing order.
- `1 <= k <= 10^4`
- `k <= nums1.length * nums2.length`

## Answer

### 解題思路

將每個 `nums1[i]` 視為一列：

```text
(nums1[i], nums2[0]), (nums1[i], nums2[1]), (nums1[i], nums2[2]), ...
```

因為 `nums2` 已排序，同一列的配對總和會由小到大排列。對每一列只需要保留目前尚未取出的最小配對，使用最小堆即可合併這些排序後的列。

1. 先將每個 `nums1[i]` 與 `nums2[0]` 組成的配對放入最小堆。最多只需初始化 `k` 列，因為答案最多只有 `k` 個配對。
2. 每次取出堆頂的最小總和，將該配對加入答案。
3. 若該配對是 `(nums1[i], nums2[j])`，則下一個可能的配對是 `(nums1[i], nums2[j + 1])`，將它放回最小堆。
4. 重複直到取得 `k` 個配對。

由於配對使用陣列索引表示，即使數值相同，也能正確保留不同元素所產生的重複配對。

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.Comparator;
import java.util.List;
import java.util.PriorityQueue;

class Solution {
    // 每個 heap 元素都是一個 int[3]，三個位置分別儲存以下資訊。
    private static final int SUM_INDEX = 0;
    private static final int NUMS1_INDEX = 1;
    private static final int NUMS2_INDEX = 2;

    public List<List<Integer>> kSmallestPairs(int[] nums1, int[] nums2, int k) {
        List<List<Integer>> answer = new ArrayList<>();
        /*
         * PriorityQueue<int[]> 代表 heap 儲存「多個 int[] 物件」。
         *
         * 每一個 int[] 都是一個完整的候選配對，格式固定為：
         * [配對總和, nums1 的索引, nums2 的索引]
         *
         * 例如 [9, 1, 0] 代表：
         * nums1[1] + nums2[0] = 9
         * 也就是配對 (nums1[1], nums2[0])。
         *
         * heap 只根據 int[] 的第 0 個位置，也就是配對總和排序。
         */
        PriorityQueue<int[]> minHeap = new PriorityQueue<>(
                Comparator.comparingInt(candidate -> candidate[SUM_INDEX])
        );

        /*
         * 把所有配對想成多列：
         *
         * 第 0 列：(nums1[0], nums2[0]), (nums1[0], nums2[1]), ...
         * 第 1 列：(nums1[1], nums2[0]), (nums1[1], nums2[1]), ...
         * 第 2 列：(nums1[2], nums2[0]), (nums1[2], nums2[1]), ...
         *
         * nums2 已排序，所以每一列的總和都是由小到大。
         * 因此，每一列一開始只需要把第一個配對 (nums1[i], nums2[0]) 放入 heap。
         *
         * new int[]{sum, i, 0} 是一個單獨的 int[] 物件，
         * 並不是把 sum、i、0 三個數字分開放入 heap。
         */
        int rowCount = Math.min(k, nums1.length);
        for (int i = 0; i < rowCount; i++) {
            int sum = nums1[i] + nums2[0];
            int[] firstCandidate = new int[]{sum, i, 0};
            minHeap.offer(firstCandidate);
        }

        /*
         * 每次從 heap 取出目前總和最小的候選配對。
         * heap 只依照 candidate[SUM_INDEX] 排序，
         * 因此 poll() 會取出總和最小的 int[]。
         */
        while (answer.size() < k && !minHeap.isEmpty()) {
            int[] current = minHeap.poll();

            // 從目前這個 int[3] 取出 nums1 與 nums2 的索引。
            int i = current[NUMS1_INDEX];
            int j = current[NUMS2_INDEX];

            // current 儲存的是索引；真正加入答案的是索引對應的兩個數值。
            answer.add(Arrays.asList(nums1[i], nums2[j]));

            /*
             * current 位於第 i 列、第 j 欄。
             * 因為同一列的下一個候選一定是第 j + 1 欄，
             * 所以把 (nums1[i], nums2[j + 1]) 放入 heap。
             * 這會讓該列的下一個配對有機會在後續被選出。
             */
            if (j + 1 < nums2.length) {
                int nextSum = nums1[i] + nums2[j + 1];
                int[] nextCandidate = new int[]{nextSum, i, j + 1};
                minHeap.offer(nextCandidate);
            }
        }

        return answer;
    }
}
```

### 複雜度分析

- 時間複雜度：`O(k log min(k, nums1.length))`。最小堆最多同時維護 `min(k, nums1.length)` 個候選配對，並取出 `k` 次。
- 空間複雜度：`O(min(k, nums1.length))`，不計算存放答案所需的空間；答案本身需要 `O(k)` 空間。
