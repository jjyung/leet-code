# 053. Maximum Subarray

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an integer array `nums`, find the subarray with the largest sum, and return its sum.

### Example 1

```text
Input: nums = [-2,1,-3,4,-1,2,1,-5,4]
Output: 6
Explanation: The subarray [4,-1,2,1] has the largest sum 6.
```

### Example 2

```text
Input: nums = [1]
Output: 1
Explanation: The subarray [1] has the largest sum 1.
```

### Example 3

```text
Input: nums = [5,4,-1,7,8]
Output: 23
Explanation: The subarray [5,4,-1,7,8] has the largest sum 23.
```

[LeetCode 題目連結](https://leetcode.com/problems/maximum-subarray/)

## Answer

使用 Kadane's Algorithm 從左到右掃描陣列，維護兩個值：

- `currentSum`：以目前元素結尾的連續子陣列最大總和。
- `maxSum`：掃描至目前位置為止，所有子陣列中的最大總和。

處理每個元素時，可以選擇將它接在前一段子陣列後面，或從目前元素重新開始：

```text
currentSum = max(nums[i], currentSum + nums[i])
```

若前一段總和為負數，保留它只會讓結果變小，因此應捨棄前段並重新開始。每次更新 `currentSum` 後，再更新 `maxSum`。初始值使用 `nums[0]`，即可正確處理所有元素皆為負數的情況。

```java
class Solution {
    public int maxSubArray(int[] nums) {
        // 以第一個元素初始化，避免全為負數時錯誤地回傳 0。
        int currentSum = nums[0];
        int maxSum = nums[0];

        for (int i = 1; i < nums.length; i++) {
            // 若前一段總和為負數，從目前元素重新開始會更好。
            currentSum = Math.max(nums[i], currentSum + nums[i]);
            // 記錄目前為止找到的最大子陣列總和。
            maxSum = Math.max(maxSum, currentSum);
        }

        return maxSum;
    }
}
```

### 複雜度分析

- 時間複雜度：`O(n)`，只需掃描陣列一次。
- 空間複雜度：`O(1)`，只使用固定數量的變數。

### 說明

1. `currentSum` 只保留以目前位置結尾的最佳結果，因此不需要儲存所有子陣列。
2. 以第一個元素作為初始值，能確保全負數輸入仍會選出最大的負數。
