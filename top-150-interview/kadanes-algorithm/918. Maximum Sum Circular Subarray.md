# 918. Maximum Sum Circular Subarray

<span style="color: #f59e0b;"><strong>Medium</strong></span>

## Problem

Given a circular integer array nums of length n, return the maximum possible sum of a non-empty subarray of nums.

A circular array means the end of the array connects to the beginning of the array. Formally, the next element of nums[i] is nums[(i + 1) % n] and the previous element of nums[i] is nums[(i - 1 + n) % n].

A subarray may only include each element of the fixed buffer nums at most once. Formally, for a subarray nums[i], nums[i + 1], ..., nums[j], there does not exist i <= k1, k2 <= j with k1 % n == k2 % n.

### Example 1

```text
Input: nums = [1,-2,3,-2]
Output: 3
Explanation: Subarray [3] has maximum sum 3.
```

### Example 2

```text
Input: nums = [5,-3,5]
Output: 10
Explanation: Subarray [5,5] has maximum sum 5 + 5 = 10.
```

### Example 3

```text
Input: nums = [-3,-2,-3]
Output: -2
Explanation: Subarray [-2] has maximum sum -2.
```

### Constraints

```text
n == nums.length
1 <= n <= 3 * 104
-3 * 104 <= nums[i] <= 3 * 104
```

## Answer

### 解題思路

環狀子陣列只有兩種可能：

1. 不跨越陣列尾端，直接是一般的連續子陣列，使用 Kadane's Algorithm 求出 `maxSum`。
2. 跨越尾端與開頭。這種子陣列等同於「整個陣列扣除中間一段不選的連續子陣列」，因此候選總和為 `totalSum - minSum`，其中 `minSum` 是最小連續子陣列總和。

掃描陣列時同時維護最大與最小的連續子陣列總和，並累加整體總和，最後取 `maxSum` 與 `totalSum - minSum` 的較大值。

若 `maxSum < 0`，代表所有元素都是負數。此時 `totalSum - minSum` 會等於 0，實際上代表沒有選取任何元素，不符合題目要求的 non-empty subarray，因此直接回傳 `maxSum`。

```java
class Solution {
    public int maxSubarraySumCircular(int[] nums) {
        int totalSum = 0;
        int currentMax = 0;
        int maxSum = Integer.MIN_VALUE;
        int currentMin = 0;
        int minSum = Integer.MAX_VALUE;

        for (int num : nums) {
            // 延續目前的最大子陣列，或從目前元素重新開始。
            currentMax = Math.max(num, currentMax + num);
            maxSum = Math.max(maxSum, currentMax);

            // 同時求出最小子陣列，供跨越尾端與開頭的情況使用。
            currentMin = Math.min(num, currentMin + num);
            minSum = Math.min(minSum, currentMin);

            totalSum += num;
        }

        // 全為負數時，totalSum - minSum 會選到空子陣列，必須排除。
        if (maxSum < 0) {
            return maxSum;
        }

        return Math.max(maxSum, totalSum - minSum);
    }
}
```

### 複雜度分析

- 時間複雜度：`O(n)`，其中 `n` 是 `nums` 的長度；只需掃描陣列一次。
- 空間複雜度：`O(1)`，只使用固定數量的變數。

### 說明

1. `currentMax` 與 `currentMin` 都表示「以目前元素結尾」的最佳結果，因此每次只需決定延續前一段或從目前元素重新開始。
2. `totalSum - minSum` 取得的是未被最小子陣列覆蓋的部分，也就是跨越尾端與開頭的候選子陣列。
3. 以 `maxSum < 0` 判斷全負數情況，確保單一元素陣列與全負數陣列仍會回傳非空子陣列的最大總和。
