# 66. Plus One

<span style="color: #16a34a;"><strong>Easy</strong></span>

## Problem

You are given a large integer represented as an integer array digits, where each digits[i] is the ith digit of the integer. The digits are ordered from most significant to least significant in left-to-right order. The large integer does not contain any leading 0's.

Increment the large integer by one and return the resulting array of digits.

### Example 1

```text
Input: digits = [1,2,3]
Output: [1,2,4]
Explanation: The array represents the integer 123.
Incrementing by one gives 123 + 1 = 124.
Thus, the result should be [1,2,4].
```

### Example 2

```text
Input: digits = [4,3,2,1]
Output: [4,3,2,2]
Explanation: The array represents the integer 4321.
Incrementing by one gives 4321 + 1 = 4322.
Thus, the result should be [4,3,2,2].
```

### Example 3

```text
Input: digits = [9]
Output: [1,0]
Explanation: The array represents the integer 9.
Incrementing by one gives 9 + 1 = 10.
Thus, the result should be [1,0].
```

### Constraints

- `1 <= digits.length <= 100`
- `0 <= digits[i] <= 9`
- `digits` does not contain any leading `0`s.

## Answer

### 解題思路

加一只會影響數字最右側的連續 `9`。因此從陣列尾端開始處理：

1. 若目前位數小於 `9`，將它加一後即可直接回傳，因為沒有進位需要繼續往前傳遞。
2. 若目前位數是 `9`，將它設為 `0`，並讓進位繼續傳給左側位數。
3. 如果所有位數都是 `9`，迴圈結束後仍有進位，建立長度為 `n + 1` 的陣列，第一位設為 `1`，其餘位數維持 `0`。

這樣可以直接在原陣列上完成大部分情況，不需要把整數轉成 Java 的數值型別，也能避免大數溢位。

```java
class Solution {
    public int[] plusOne(int[] digits) {
        // 從個位數開始處理，因為加一的進位只能由右向左傳遞。
        for (int i = digits.length - 1; i >= 0; i--) {
            if (digits[i] < 9) {
                // 沒有產生進位，左側位數不需再修改。
                digits[i]++;
                return digits;
            }

            // 目前位數為 9，加一後變成 0，進位交給下一個左側位數。
            digits[i] = 0;
        }

        // 所有位數都是 9，例如 [9, 9] 會變成 [1, 0, 0]。
        int[] result = new int[digits.length + 1];
        result[0] = 1;
        return result;
    }
}
```

### 說明

- `n` 定義為 `digits` 的長度。
- 當陣列為空（題目限制不允許）時不需額外處理；單一位數與全部為 `9` 的情況則由相同的進位流程涵蓋。
- 若從右側遇到非 `9` 位數，該位加一後即可結束；若一路遇到 `9`，最後建立多一位的結果陣列以容納最高位進位。
- 時間複雜度：`O(n)`，最壞情況需要檢查所有位數。
- 空間複雜度：`O(1)` 額外空間；只有全部位數為 `9` 時，回傳的新陣列需要 `O(n)` 空間。
