# 050. Pow(x, n)

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Implement pow(x, n), which calculates x raised to the power n (i.e., xⁿ).

### Example 1

```text
Input: x = 2.00000, n = 10
Output: 1024.00000
```

### Example 2

```text
Input: x = 2.10000, n = 3
Output: 9.26100
```

### Example 3

```text
Input: x = 2.00000, n = -2
Output: 0.25000
Explanation: 2⁻² = 1/2² = 1/4 = 0.25
```

Constraints:

- `-100.0 < x < 100.0`
- `-2³¹ <= n <= 2³¹ - 1`
- `n` is an integer.
- Either `x` is not zero or `n > 0`.
- `-10⁴ <= xⁿ <= 10⁴`

## Answer

### 解題思路

使用二分冪：將指數反覆除以 2，同時將底數平方。若目前指數為奇數，就先將目前底數乘入結果；這相當於取出指數二進位表示中的一個位元。

負指數可利用 `x⁻ⁿ = 1 / xⁿ`，先計算正指數的冪，最後再取倒數，減少先取倒數造成的浮點誤差。先將 `n` 轉為 `long`，才能安全地對最小的 `int` 值取負。指數為 0 時，迴圈不執行，直接回傳 1。

```java
class Solution {
    public double myPow(double x, int n) {
        long exponent = n;
        if (exponent < 0) {
            // 先轉為 long 再取負，避免最小 int 值溢位。
            exponent = -exponent;
        }

        double result = 1.0;
        while (exponent > 0) {
            // 奇數指數多出一個目前底數，先乘入結果。
            if (exponent % 2 == 1) {
                result *= x;
            }
            // 平方底數並將指數減半，保留尚未計算的冪。
            x *= x;
            exponent /= 2;
        }
        // 負指數最後才取倒數，避免倒數誤差在平方時累積。
        return n < 0 ? 1.0 / result : result;
    }
}
```

### 說明與複雜度

- 每次迴圈前，`result` 乘以目前底數的剩餘指數次方，等於原始底數的 `|n|` 次方；奇數時先取出一個底數，再平方底數並將指數減半，因此此關係持續成立。
- 題目保證負指數時 `x` 不為 0，因此可以取倒數；負底數的正負號由乘法自然處理。
- 時間複雜度：O(log |n|)，其中 `n` 是輸入指數；每次迴圈都將指數減半。`n = 0` 時為 O(1)。
- 空間複雜度：O(1)，只使用固定數量的變數。
