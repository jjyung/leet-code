# 172. Factorial Trailing Zeroes

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an integer `n`, return the number of trailing zeroes in `n!`.

Note that `n! = n * (n - 1) * (n - 2) * ... * 3 * 2 * 1`.

### Example 1

```text
Input: n = 3
Output: 0
Explanation: 3! = 6, no trailing zero.
```

### Example 2

```text
Input: n = 5
Output: 1
Explanation: 5! = 120, one trailing zero.
```

### Example 3

```text
Input: n = 0
Output: 0
Explanation: 0! = 1, no trailing zero.
```

Constraints:

- `0 <= n <= 10^4`

Follow up: Could you write a solution that works in logarithmic time complexity?

[LeetCode problem](https://leetcode.com/problems/factorial-trailing-zeroes/)

## Answer

### 解題思路

每一個尾端 0 都來自一組因數 `10`，而 `10 = 2 × 5`。在 `n!` 中，因數 2 的數量一定比因數 5 多，因此只要計算因數 5 的總數即可。

除了 `5` 的倍數會提供一個因數 5，`25`、`125` 等倍數還會分別額外提供第二個、第三個因數 5。因此可以重複將 `n` 除以 5，並把每次除法後的商加入答案：

1. `n / 5` 計算至少含有一個因數 5 的數量。
2. `n / 25` 計算額外含有第二個因數 5 的數量。
3. 持續計算直到商變成 0。

當原始 `n` 為 0 時，迴圈不會執行，直接得到答案 0。

```java
class Solution {
    public int trailingZeroes(int n) {
        int zeroCount = 0;

        // 每次除以 5，依序計算 5、25、125 等倍數提供的因數 5。
        while (n > 0) {
            n /= 5;
            zeroCount += n;
        }

        return zeroCount;
    }
}
```

### 複雜度分析

- 時間複雜度：`O(log_5 n)`，其中 `n` 是題目輸入的整數；迴圈每次將 `n` 除以 5。
- 空間複雜度：`O(1)`，只使用固定數量的變數。
