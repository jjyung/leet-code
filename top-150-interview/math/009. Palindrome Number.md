# 009. Palindrome Number

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given an integer `x`, return `true` if `x` is a palindrome, and `false` otherwise.

### Example 1

```text
Input: x = 121
Output: true
Explanation: 121 reads as 121 from left to right and from right to left.
```

### Example 2

```text
Input: x = -121
Output: false
Explanation: From left to right, it reads -121. From right to left, it becomes 121-. Therefore, it is not a palindrome.
```

### Example 3

```text
Input: x = 10
Output: false
Explanation: It reads 01 from right to left. Therefore, it is not a palindrome.
```

### Constraints

- `-2^31 <= x <= 2^31 - 1`

## Answer

不將整數轉成字串，而是從數字的兩端逐步比較。為了避免處理整個數字的反轉結果可能造成整數溢位，只反轉 `x` 的後半段數字。

若 `x` 為負數，或數字以 `0` 結尾但本身不是 `0`，就不可能是回文數。反轉後半段時，每次取出 `x` 的個位數，加入 `reversedHalf`，並將 `x` 除以 `10`。當 `x <= reversedHalf` 時，已處理完一半數字：

- 偶數位數：`x` 應等於 `reversedHalf`。
- 奇數位數：忽略 `reversedHalf` 的中間位，因此比較 `x` 與 `reversedHalf / 10`。

```java
class Solution {
    public boolean isPalindrome(int x) {
        // 負數不可能是回文數；除了 0 以外，以 0 結尾的數字反轉後會多出前導 0。
        if (x < 0 || (x % 10 == 0 && x != 0)) {
            return false;
        }

        int reversedHalf = 0;

        // 只反轉後半段，避免完整反轉造成整數溢位。
        while (x > reversedHalf) {
            reversedHalf = reversedHalf * 10 + x % 10;
            x /= 10;
        }

        // 偶數位數直接比較；奇數位數忽略反轉結果的中間位數。
        return x == reversedHalf || x == reversedHalf / 10;
    }
}
```

### 說明

1. `x < 0` 直接排除負數；`x % 10 == 0` 可排除除 `0` 以外的尾數為 `0` 的數字。
2. `reversedHalf` 僅儲存後半段的反轉結果，因此不需要使用字串或額外陣列。
3. **時間複雜度：** `O(log₁₀(|x| + 1))`，最多處理數字位數的一半。
4. **空間複雜度：** `O(1)`。
