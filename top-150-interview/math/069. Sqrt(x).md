# 069. Sqrt(x)

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

Given a non-negative integer `x`, return the square root of `x` rounded down to the nearest integer. The returned integer should be non-negative as well.

You must not use any built-in exponent function or operator.

For example, do not use `pow(x, 0.5)` in c++ or `x ** 0.5` in python.

### Example 1

```text
Input: x = 4
Output: 2
Explanation: The square root of 4 is 2, so we return 2.
```

### Example 2

```text
Input: x = 8
Output: 2
Explanation: The square root of 8 is 2.82842..., and since we round it down to the nearest integer, 2 is returned.
```

Constraints:

- `0 <= x <= 2^31 - 1`

## Answer

### 解題思路

使用二分搜尋找出平方不大於 `x` 的最大整數。搜尋範圍從 `0` 到 `x`；每次取中間值 `mid`，若 `mid * mid <= x`，代表 `mid` 還可能是答案，記錄它並往較大的區間搜尋。否則平方已超過 `x`，往較小的區間搜尋。

這裡的 `if / else` 是根據 `mid` 的平方，決定哪一半可以排除：若 `mid` 可行，就排除 `mid` 和它左邊的數，因為我們要找「最大」可行值；若 `mid` 太大，就排除 `mid` 和它右邊的數。語法上可以改用條件運算子等寫法，但每輪仍必須依判斷結果選對方向；若不看結果、固定只移動一側，可能找到錯答案，或退化成逐一檢查。

用 `long` 計算平方，避免 `mid * mid` 超出 `int` 範圍。搜尋結束時，記錄的最大可行值就是向下取整的平方根。當 `x = 0` 時也會正確回傳 `0`。

```java
class Solution {
    public int mySqrt(int x) {
        // 搜尋範圍左右端點都包含在內；答案一定在 0 到 x 之間。
        int left = 0;
        int right = x;

        // 保存目前已確認可行的最大候選值；x = 0 時答案也會是 0。
        int answer = 0;

        // [left, right] 兩端都包含；left == right 時還有最後一個候選要檢查，
        // 因此用 <=。只有 left > right、範圍變空時，搜尋才完成。
        while (left <= right) {
            // 取中間候選，這樣每次都能排除約一半的範圍。
            int mid = left + (right - left) / 2;
            long square = (long) mid * mid;

            if (square <= x) {
                // mid 可行。平方隨非負整數遞增，所以 mid 左邊也都可行；
                // 但要找最大可行值，記下 mid 後只需繼續搜尋右半邊。
                answer = mid;
                left = mid + 1;
            } else {
                // mid 不可行；比 mid 更大的數平方只會更大，因此排除右半邊。
                right = mid - 1;
            }
        }

        // 所有更大的候選都已排除，answer 就是平方不超過 x 的最大整數。
        return answer;
    }
}
```

### 說明

1. 以 `x = 8` 為例：先檢查 `mid = 4`，平方太大，所以往左找；接著 `mid = 1`、`mid = 2` 都可行，每次記下候選並往右找；檢查 `3` 發現平方太大後，範圍清空，答案保留為 `2`。
2. `if / else` 的分支代表兩種互斥結果，並各自排除不可能的一半：可行時往右找更大的答案，太大時往左找。可以改寫分支的語法，但不能忽略這個判斷而固定往同一方向移動。
3. 平方以 `long` 計算，避免整數乘法溢位；輸入非負，因此不需處理負數。
4. **時間複雜度：** `O(log(n + 1))`，其中 `n = x`，每次迭代將搜尋範圍縮小一半。
5. **空間複雜度：** `O(1)`，只使用固定數量的變數。
