# 322. Coin Change

<span style="color: #f59e0b;"><strong>Medium</strong></span>

## Problem

You are given an integer array coins representing coins of different denominations and an integer amount representing a total amount of money.

Return the fewest number of coins that you need to make up that amount. If that amount of money cannot be made up by any combination of the coins, return -1.

You may assume that you have an infinite number of each kind of coin.

### Example 1

```text
Input: coins = [1,2,5], amount = 11
Output: 3
Explanation: 11 = 5 + 5 + 1
```

### Example 2

```text
Input: coins = [2], amount = 3
Output: -1
```

### Example 3

```text
Input: coins = [1], amount = 0
Output: 0
```

### Constraints

- 1 <= coins.length <= 12
- 1 <= coins[i] <= 231 - 1
- 0 <= amount <= 104

## Answer

### 解題思路

令 `dp[i]` 表示湊出總金額 `i` 所需的最少硬幣數量。對於最後放入的一枚硬幣 `coin`，前一個狀態必須是 `dp[i - coin]`，因此可以得到狀態轉移：

```text
dp[i] = min(dp[i], dp[i - coin] + 1)
```

先將所有狀態設為 `amount + 1`，代表目前無法湊出該金額。因為每枚硬幣至少為 `1`，任何可行解最多只需要 `amount` 枚硬幣，所以 `amount + 1` 一定不會與有效答案混淆；再設定 `dp[0] = 0` 作為轉移的起點。

依序計算 `1` 到 `amount` 的每個金額，嘗試所有硬幣。若硬幣面額不大於目前金額，就使用「先湊出 `i - coin`，再加上這枚硬幣」的方案更新最小值。由於每個組合的最後一枚硬幣都會被枚舉，所有可能的組合都能被涵蓋。

### 範例演算

以 `coins = [1, 2, 5]`、`amount = 11` 為例。先建立 `dp[0..11]`：`dp[0] = 0`，其餘位置先填入 `12`，代表目前還不知道如何湊出該金額。

接著從小金額開始計算。每個 `dp[i]` 都會嘗試把一枚硬幣放在最後，並查看前面較小金額的最佳答案：

| 金額 `i` | `dp[i]` | 一個最少硬幣組合 |
| ---: | ---: | --- |
| 0 | 0 | 不需要硬幣 |
| 1 | 1 | 1 |
| 2 | 1 | 2 |
| 3 | 2 | 2 + 1 |
| 4 | 2 | 2 + 2 |
| 5 | 1 | 5 |
| 6 | 2 | 5 + 1 |
| 7 | 2 | 5 + 2 |
| 8 | 3 | 5 + 2 + 1 |
| 9 | 3 | 5 + 2 + 2 |
| 10 | 2 | 5 + 5 |
| 11 | 3 | 5 + 5 + 1 |

特別看最後一步 `dp[11]`：

```text
最後放 1：dp[10] + 1 = 2 + 1 = 3
最後放 2：dp[9]  + 1 = 3 + 1 = 4
最後放 5：dp[6]  + 1 = 2 + 1 = 3

dp[11] = min(3, 4, 3) = 3
```

因此答案是 `3`，其中一種組合為 `5 + 5 + 1`。這裡不是看到 `5` 就直接選它，而是把三種「最後一枚硬幣」都比較過，再選硬幣數量最少的結果。由於計算順序是由小到大，`dp[10]`、`dp[9]` 和 `dp[6]` 在計算 `dp[11]` 前都已經完成；而 `dp[10] = dp[5] + 1` 也允許再次使用面額 `5`，所以能處理無限枚硬幣的情況。

### Java 程式碼

```java
import java.util.Arrays;

class Solution {
	public int coinChange(int[] coins, int amount) {
		// amount + 1 大於任何可行解，使用它表示目前無法湊出該金額
		int impossible = amount + 1;
		int[] dp = new int[amount + 1];
		Arrays.fill(dp, impossible);
		dp[0] = 0;

		for (int currentAmount = 1; currentAmount <= amount; currentAmount++) {
			for (int coin : coins) {
				if (coin <= currentAmount && dp[currentAmount - coin] != impossible) {
					// 先完成 currentAmount - coin，再使用一枚目前的硬幣
					dp[currentAmount] = Math.min(
						dp[currentAmount],
						dp[currentAmount - coin] + 1
					);
				}
			}
		}

		// 保持 impossible 代表沒有任何硬幣組合可以湊出 amount
		return dp[amount] == impossible ? -1 : dp[amount];
	}
}
```

### 說明

- `amount = 0` 時，`dp[0]` 已初始化為 `0`，不需要使用任何硬幣。
- 面額大於目前金額的硬幣會被跳過；無法到達的前置狀態不會用來產生新答案。
- 若最後的 `dp[amount]` 仍為 `impossible`，表示沒有任何組合能湊出目標金額，因此回傳 `-1`。
- 時間複雜度為 `O(A * n)`，其中 `A` 是目標金額 `amount`，`n` 是硬幣種類數 `coins.length`。
- 空間複雜度為 `O(A)`，用來儲存 `dp` 陣列。
