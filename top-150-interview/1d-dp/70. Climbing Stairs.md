# 70. Climbing Stairs

## Problem

<span style="color: #16a34a;"><strong>Easy</strong></span>

You are climbing a staircase. It takes `n` steps to reach the top.

Each time you can either climb 1 or 2 steps. In how many distinct ways can you climb to the top?

### Constraints

- `1 <= n <= 45`

### Example 1

```text
Input: n = 2
Output: 2
Explanation: There are two ways to climb to the top.
1. 1 step + 1 step
2. 2 steps
```

### Example 2

```text
Input: n = 3
Output: 3
Explanation: There are three ways to climb to the top.
1. 1 step + 1 step + 1 step
2. 1 step + 2 steps
3. 2 steps + 1 step
```

## Answer

### 解題思路

令 `dp[i]` 表示「走到第 `i` 階的方法數」。抵達第 `i` 階的最後一步只有兩種可能：

1. 從第 `i - 1` 階走 1 步上來，共有 `dp[i - 1]` 種方法。
2. 從第 `i - 2` 階走 2 步上來，共有 `dp[i - 2]` 種方法。

因此狀態轉移為 `dp[i] = dp[i - 1] + dp[i - 2]`。初始值為 `dp[1] = 1`、`dp[2] = 2`。

計算目前階數時只需要前兩個狀態，因此不必建立整個 DP 陣列，只保留 `dp[i - 2]` 與 `dp[i - 1]`。當 `n` 為 1 或 2 時，答案可直接回傳；`n` 為 45 時的結果仍在 `int` 可表示的範圍內。

```java
class Solution {
    public int climbStairs(int n) {
        // dp[i - 2] 與 dp[i - 1] 分別代表前兩個階數的方法數。
        if (n <= 2) {
            return n;
        }

        int twoStepsBefore = 1; // dp[1]，作為計算 dp[3] 的前前項
        int oneStepBefore = 2;  // dp[2]，作為計算 dp[3] 的前一項

        for (int currentStep = 3; currentStep <= n; currentStep++) {
            // 最後一步走 1 階或 2 階，兩種情況的數量相加。
            int currentWays = oneStepBefore + twoStepsBefore;

            // 滾動保存下一輪需要的前兩個 DP 狀態。
            twoStepsBefore = oneStepBefore;
            oneStepBefore = currentWays;
        }

        return oneStepBefore;
    }
}
```

### 複雜度分析

- `n = 1` 時只有走 1 階這 1 種方法；`n = 2` 時可走兩次 1 階或一次 2 階，共 2 種方法。
- 對於 `n >= 3`，每個狀態都依賴前兩個狀態，迴圈會從第 3 階計算到第 `n` 階。
- 時間複雜度：`O(n)`，其中 `n` 是階梯的總階數。
- 空間複雜度：`O(1)`，只使用固定數量的變數保存 DP 狀態。
