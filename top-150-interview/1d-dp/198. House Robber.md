# 198. House Robber

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

You are a professional robber planning to rob houses along a street. Each house has a certain amount of money stashed, the only constraint stopping you from robbing each of them is that adjacent houses have security systems connected and it will automatically contact the police if two adjacent houses were broken into on the same night.

Given an integer array `nums` representing the amount of money of each house, return the maximum amount of money you can rob tonight without alerting the police.

### Example 1

```text
Input: nums = [1,2,3,1]
Output: 4
Explanation: Rob house 1 (money = 1) and then rob house 3 (money = 3).
Total amount you can rob = 1 + 3 = 4.
```

### Example 2

```text
Input: nums = [2,7,9,3,1]
Output: 12
Explanation: Rob house 1 (money = 2), rob house 3 (money = 9) and rob house 5 (money = 1).
Total amount you can rob = 2 + 9 + 1 = 12.
```

### Constraints

- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

[LeetCode Problem](https://leetcode.com/problems/house-robber/)

## Answer

### 解題思路

令 `dp[i]` 表示從索引 `0` 到索引 `i` 的房子中，能取得的最大金額。由於 `dp` 與 `nums` 都使用相同的索引，處理索引為 `i` 的房子時有兩種選擇：

1. 不偷目前房子，沿用前一間房子的最佳結果，金額為 `dp[i - 1]`。
2. 偷目前房子，因為不能偷相鄰房子，只能加上索引 `i - 2` 以前的最佳結果，金額為 `dp[i - 2] + nums[i]`。

因此，當 `i >= 2` 時，狀態轉移為：

```text
dp[i] = max(dp[i - 1], dp[i - 2] + nums[i])
```

初始狀態為 `dp[0] = nums[0]`；若有至少兩間房子，則 `dp[1] = max(nums[0], nums[1])`。每個狀態只依賴前兩個狀態，所以不需要保留完整的 `dp` 陣列，只用 `previousTwo` 與 `previousOne` 保存前兩個狀態。初始時兩者皆為 `0`，可將它們視為尚未處理房子時的邊界值，讓程式從第一間房子開始統一計算。

### Java 程式碼

```java
class Solution {
    public int rob(int[] nums) {
        // previousTwo 與 previousOne 保存目前房子前方的兩個最佳結果
        int previousTwo = 0;
        int previousOne = 0;

        for (int money : nums) {
            // 偷目前房子：只能加上前一間房子之前的最佳金額
            int robCurrent = previousTwo + money;

            // 不偷目前房子：沿用前一間房子結束時的最佳金額
            int currentBest = Math.max(previousOne, robCurrent);

            // 往下一間房子移動，更新前兩個狀態
            previousTwo = previousOne;
            previousOne = currentBest;
        }

        return previousOne;
    }
}
```

### 說明

- `nums` 至少包含一間房子；初始兩個狀態設為 `0`，因此空的前綴與單一房子都能正確處理。
- 每間房子都比較「偷目前房子」與「不偷目前房子」兩種情況，取其中較大的金額。
- 在題目限制下金額為非負數，且最多只有 `100` 間房子，使用 `int` 足以保存答案。
- 時間複雜度為 `O(n)`，其中 `n` 是房子數量。
- 空間複雜度為 `O(1)`，只使用兩個前置狀態變數。
