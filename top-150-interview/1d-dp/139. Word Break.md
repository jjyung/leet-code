# 139. Word Break

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given a string s and a dictionary of strings wordDict, return true if s can be segmented into a space-separated sequence of one or more dictionary words.

Note that the same word in the dictionary may be reused multiple times in the segmentation.

### Example 1

```text
Input: s = "leetcode", wordDict = ["leet","code"]
Output: true
Explanation: Return true because "leetcode" can be segmented as "leet code".
```

### Example 2

```text
Input: s = "applepenapple", wordDict = ["apple","pen"]
Output: true
Explanation: Return true because "applepenapple" can be segmented as "apple pen apple".
Note that you are allowed to reuse a dictionary word.
```

### Example 3

```text
Input: s = "catsandog", wordDict = ["cats","dog","sand","and","cat"]
Output: false
```

### Constraints

- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`
- `s` and `wordDict[i]` consist of only lowercase English letters.
- All the strings of `wordDict` are unique.

[LeetCode Problem](https://leetcode.com/problems/word-break/)

## Answer

### 解題思路

這題要判斷整個字串能否完成切分，而答案能由較短前綴的切分結果組成，是適合使用動態規劃的訊號。若直接遞迴嘗試每個切點，會反覆判斷相同的前綴；使用 `dp` 記錄前綴是否可切分，便能讓每個前綴只計算一次。

令 `dp[i]` 表示字串 `s` 的前 `i` 個字元，也就是 `s[0..i-1]`，是否可以完全由字典中的單字組成。空字串不需要任何單字即可完成切分，所以 `dp[0] = true`。

對每個結尾位置 `i`，枚舉前一段字串的切點 `j`：若 `dp[j]` 為 `true`，且子字串 `s[j..i-1]` 存在於字典中，代表前 `j` 個字元可切分，最後一段也能接上一個合法單字，因此 `dp[i] = true`。找到任一合法切點即可停止搜尋。

將 `wordDict` 轉成 `HashSet`，可在判斷候選子字串是否為字典單字時快速查詢。字典中的單字可重複使用，因為每個位置只根據先前可切分的前綴判斷，不會移除集合中的單字。

例如 `s = "leetcode"`，`wordDict = ["leet", "code"]`：

1. 一開始 `dp[0] = true`，表示空字串已能完成切分。
2. 當 `end = 4` 時，`start = 0`，而 `dp[0]` 為 `true`，且 `s.substring(0, 4)` 是 `"leet"`，所以設 `dp[4] = true`。
3. 當 `end = 8` 時，`start = 4`，而 `dp[4]` 為 `true`，且 `s.substring(4, 8)` 是 `"code"`，所以設 `dp[8] = true`。
4. `length` 為 `8`，最終回傳 `dp[length]`，也就是 `dp[8]`，結果為 `true`。這對應切分方式 `"leet code"`。

### Java 程式碼

#### 寫法一：從可切分的起點往後更新

外層的 `start` 代表一個已確認能完成切分的位置。只要 `dp[start]` 為 `true`，就嘗試把每個字典單字接在該位置之後；接得上時，將單字結尾位置標記為 `true`。這個方向可視為從每個可達位置往後走。

```java
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
	public boolean wordBreak(String s, List<String> wordDict) {
		Set<String> dictionary = new HashSet<>(wordDict);
		int length = s.length();

		// dp[i] 表示 s 的前 i 個字元是否能完全切分為字典單字
		boolean[] dp = new boolean[length + 1];
		dp[0] = true;

		for (int start = 0; start < length; start++) {
			// 只有已可切分的前綴，才能接上下一個字典單字
			if (!dp[start]) {
				continue;
			}

			// 逐一嘗試將字典單字接在 start 位置之後
			for (String word : dictionary) {
				int end = start + word.length();
				if (end <= length && s.startsWith(word, start)) {
					dp[end] = true;
				}
			}
		}

		return dp[length];
	}
}
```

#### 寫法二：以結尾位置推導狀態

外層的 `end` 代表目前要計算的 `dp[end]`；內層的 `start` 尋找最後一個單字可能的起點。因為永遠有 `start < end`，需要的 `dp[start]` 都已在較早的外層迴圈完成。

```java
import java.util.HashSet;
import java.util.List;
import java.util.Set;

class Solution {
	public boolean wordBreak(String s, List<String> wordDict) {
		Set<String> dictionary = new HashSet<>(wordDict);
		int length = s.length();

		// dp[i] 表示 s 的前 i 個字元是否能完全切分為字典單字
		boolean[] dp = new boolean[length + 1];
		dp[0] = true;

		for (int end = 1; end <= length; end++) {
			// 枚舉最後一個單字的起點，檢查已完成的前綴能否接上此單字
			for (int start = 0; start < end; start++) {
				if (dp[start] && dictionary.contains(s.substring(start, end))) {
					dp[end] = true;
					break;
				}
			}
		}

		return dp[length];
	}
}
```

### 說明

- `dp[0]` 是空字串的邊界狀態，讓第一個單字可直接從索引 `0` 開始。
- 寫法一由「已知可切分的位置」嘗試接上每個字典單字；寫法二由「目標結尾」回看最後一個單字的起點。兩者都依賴較短前綴，因此都能正確填入 `dp`。
- 寫法二中，`end` 走訪每個前綴的結尾；只有 `dp[start]` 已為 `true` 時，才檢查最後一段 `s.substring(start, end)`，避免將不可切分的前綴延伸成答案。
- 若整個字串不存在任何合法切分，`dp[length]` 維持 `false`；單一字元或整串恰為一個字典單字的情況同樣適用。
- 寫法一的時間複雜度為 `O(n * d * L)`，其中 `d` 是字典單字數量，`L` 是最長單字長度；每個可達起點最多檢查 `d` 個單字，`startsWith` 最壞比較 `L` 個字元。
- 寫法二的時間複雜度為 `O(n^3)`，其中 `n` 是 `s` 的長度：共有 `O(n^2)` 組切點，Java 建立子字串最壞需 `O(n)`。
- 兩種寫法的空間複雜度皆為 `O(n + m)`，其中 `n` 是 `s` 的長度，`m` 是字典所有字元的總長度；`dp` 使用 `O(n)`，`HashSet` 儲存字典使用 `O(m)`。
