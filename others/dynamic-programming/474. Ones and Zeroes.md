# 474. Ones and Zeroes

<span style="color: #f59e0b;"><strong>Medium</strong></span>

## Problem

You are given an array of binary strings strs and two integers m and n.

Return the size of the largest subset of strs such that there are at most m 0's and n 1's in the subset.

A set x is a subset of a set y if all elements of x are also elements of y.

Example 1:

```text
Input: strs = ["10","0001","111001","1","0"], m = 5, n = 3
Output: 4
Explanation: The largest subset with at most 5 0's and 3 1's is {"10", "0001", "1", "0"}, so the answer is 4.
Other valid but smaller subsets include {"0001", "1"} and {"10", "1", "0"}.
{"111001"} is an invalid subset because it contains 4 1's, greater than the maximum of 3.
```

Example 2:

```text
Input: strs = ["10","0","1"], m = 1, n = 1
Output: 2
Explanation: The largest subset is {"0", "1"}, so the answer is 2.
```

Constraints:

1 <= strs.length <= 600
1 <= strs[i].length <= 100
strs[i] consists only of digits '0' and '1'.
1 <= m, n <= 100

## Answer

### 解題思路

這是一個二維 0/1 背包問題。每個字串都是一個物品，字串中的 `0` 數量與 `1` 數量分別代表消耗的兩種容量，而選取一個字串可以讓子集合數量增加 1。

使用 `dp[zero][one]` 表示最多使用 `zero` 個 `0` 與 `one` 個 `1` 時，能選出的最大字串數量。處理每個字串時，先統計其中的 `0` 與 `1` 數量，再從容量上限往下更新狀態，避免同一個字串在同一輪被重複選取。

```java
class Solution {
    public int findMaxForm(String[] strs, int m, int n) {
        // dp[zero][one]：最多使用 zero 個 0 與 one 個 1 時，可選出的最大字串數量。
        int[][] dp = new int[m + 1][n + 1];

        for (String str : strs) {
            int zeros = 0;
            int ones = 0;

            // 計算目前字串需要消耗的 0 與 1 數量。
            for (char character : str.toCharArray()) {
                if (character == '0') {
                    zeros++;
                } else {
                    ones++;
                }
            }

            // 容量由大到小更新，確保每個字串在同一輪最多只會被選取一次。
            for (int zero = m; zero >= zeros; zero--) {
                for (int one = n; one >= ones; one--) {
                    // 選取目前字串，並在剩餘容量的最佳結果上加 1。
                    dp[zero][one] = Math.max(
                            dp[zero][one],
                            dp[zero - zeros][one - ones] + 1
                    );
                }
            }
        }

        return dp[m][n];
    }
}
```

### 複雜度分析

- 時間複雜度：`O(totalLength + strs.length × m × n)`，`totalLength` 是所有字串的總長度。
- 空間複雜度：`O(m × n)`，使用二維 `dp` 陣列。
