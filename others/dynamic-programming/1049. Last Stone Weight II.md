# 1049. Last Stone Weight II

<span style="color: #f59e0b;"><strong>Medium</strong></span>

## Question

You are given an array of integers stones where stones[i] is the weight of the ith stone.

We are playing a game with the stones. On each turn, we choose any two stones and smash them together. Suppose the stones have weights x and y with x <= y. The result of this smash is:

If x == y, both stones are destroyed, and
If x != y, the stone of weight x is destroyed, and the stone of weight y has new weight y - x.
At the end of the game, there is at most one stone left.

Return the smallest possible weight of the left stone. If there are no stones left, return 0.

### Example 1

```text
Input: stones = [2,7,4,1,8,1]
Output: 1
Explanation:
One possible sequence of smashes is
[2,7,4,1,8,1] -> [2,7,1,8,1] -> [2,1,1,1] -> [1,1,1] -> [1].
The smallest possible weight of the left stone is 1.
```

### Example 2

```text
Input: stones = [31,26,33,21,40]
Output: 5
```

### Constraints

- `1 <= stones.length <= 30`
- `1 <= stones[i] <= 100`

## Answer

### 解題思路

每次碰撞的結果等同於將石頭分成兩組，最後剩下的重量就是兩組總重量的差值。因此，令所有石頭的總重量為 `total`，只要找出一組石頭，其總重量 `best` 不超過 `total / 2` 且盡可能接近 `total / 2`，答案就是：

```text
total - 2 * best
```

這可以轉換成 0/1 背包問題。使用一維陣列 `dp`，其中 `dp[sum]` 表示目前處理過的石頭中，是否能組成總重量 `sum`。初始時 `dp[0] = true`，代表不選任何石頭即可組成重量 0。

處理每顆石頭時，從 `target` 倒序更新 `dp`，使每顆石頭在同一輪最多只會被使用一次。最後找出最大的可達重量 `best`，即可得到最小差值。

```java
class Solution {
    public int lastStoneWeightII(int[] stones) {
        int total = 0;
        for (int stone : stones) {
            total += stone;
        }

        int target = total / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;

        for (int stone : stones) {
            // 倒序更新，避免同一顆石頭在同一輪被重複使用。
            for (int sum = target; sum >= stone; sum--) {
                // 若 sum - stone 可達，加入目前石頭後 sum 也可達。
                dp[sum] = dp[sum] || dp[sum - stone];
            }
        }

        int best = 0;
        for (int sum = target; sum >= 0; sum--) {
            if (dp[sum]) {
                best = sum;
                break;
            }
        }

        return total - 2 * best;
    }
}
```

### 複雜度分析

- 時間複雜度：`O(n × target)`，其中 `n` 是石頭數量，`target` 是 `total / 2`。
- 空間複雜度：`O(target)`，使用一維 `dp` 陣列。
