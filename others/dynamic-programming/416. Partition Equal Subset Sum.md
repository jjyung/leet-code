# 416. Partition Equal Subset Sum

## Question

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Given an integer array nums, return true if you can partition the array into two subsets such that the sum of the elements in both subsets is equal or false otherwise.

### Example 1

**Input:** `nums = [1, 5, 11, 5]`

**Output:** `true`

**Explanation:** The array can be partitioned as `[1, 5, 5]` and `[11]`.

### Example 2

**Input:** `nums = [1, 2, 3, 5]`

**Output:** `false`

**Explanation:** The array cannot be partitioned into equal sum subsets.

### Constraints

- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`

## Answer

### 解題思路

若所有數字可以分成兩個總和相等的子集合，所有元素的總和必須是偶數，且其中一個子集合的總和必須為 `total / 2`。因此問題可以轉換成：是否能從 `nums` 中挑選一些數字，使其總和恰好等於 `target`。

使用一維布林陣列 `dp` 表示「是否可以使用目前處理過的數字，組成總和 `sum`」。初始時 `dp[0] = true`，代表不選任何數字即可組成總和 0。

處理每個數字 `num` 時，從 `target` 倒序更新 `dp[sum]`。倒序能確保同一個數字在同一輪只會被使用一次，符合每個元素只能選擇一次的 0/1 背包特性。

### 為什麼要從大到小更新 `sum`？

```java
for (int sum = target; sum >= num; sum--) {
    dp[sum] = dp[sum] || dp[sum - num];
}
```

這裡的 `sum` 代表「目前要判斷是否能組成的總和」，不是目前已經累加的總和。每次更新 `dp[sum]` 時，都是在判斷：

> 不使用 `num` 時，`dp[sum]` 是否已經成立；或是先組成 `sum - num`，再加入目前的 `num`。

必須使用 `sum--`，因為每個陣列元素只能使用一次。假設目前 `num = 2`、`target = 4`，且一開始只有 `dp[0] = true`。

如果從小到大更新：

```text
sum = 2：dp[2] = dp[2] || dp[0]  => dp[2] = true
sum = 4：dp[4] = dp[4] || dp[2]  => dp[4] = true
```

此時 `dp[2]` 是在同一輪才使用目前的 `2` 算出來的，接著又用它來計算 `dp[4]`，等於把同一個 `2` 使用了兩次，錯誤地得到 `2 + 2 = 4`。

從大到小更新時，順序會是 `sum = 4、3、2`。當計算 `dp[sum]` 時，來源 `dp[sum - num]` 位於較小的索引，而較小索引尚未在這一輪更新，因此它只能使用前一輪的狀態，不會重複使用目前的 `num`。

因此可以記住：

- `sum--`：每個數字最多使用一次，適合 0/1 背包。
- `sum++`：同一個數字可能被重複使用，適合完全背包。

```java
class Solution {
    public boolean canPartition(int[] nums) {
        int total = 0;
        for (int num : nums) {
            total += num;
        }

        // 總和為奇數時，不可能平分成兩個整數總和。
        if ((total & 1) == 1) {
            return false;
        }

        int target = total / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true;

        for (int num : nums) {
            // 倒序更新，避免同一個數字在同一輪被重複使用。
            for (int sum = target; sum >= num; sum--) {
                // 若 sum - num 可達，加入 num 後 sum 也可達。
                dp[sum] = dp[sum] || dp[sum - num];
            }
        }

        return dp[target];
    }
}
```

### 複雜度分析

- 時間複雜度：`O(n × target)`，其中 `n` 是陣列長度，`target` 是總和的一半。
- 空間複雜度：`O(target)`，使用一維 `dp` 陣列。
