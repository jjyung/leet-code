# 146. LRU Cache

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

Design a data structure that follows the constraints of a Least Recently Used (LRU) cache.

Implement the LRUCache class:

- `LRUCache(int capacity)` Initialize the LRU cache with positive size `capacity`.
- `int get(int key)` Return the value of the `key` if the key exists, otherwise return `-1`.
- `void put(int key, int value)` Update the value of the `key` if the `key` exists. Otherwise, add the `key-value` pair to the cache. If the number of keys exceeds the `capacity` from this operation, evict the least recently used key.

The functions get and put must each run in O(1) average time complexity.

### Example 1

```text
Input
["LRUCache", "put", "put", "get", "put", "get", "put", "get", "get", "get"]
[[2], [1, 1], [2, 2], [1], [3, 3], [2], [4, 4], [1], [3], [4]]
Output
[null, null, null, 1, null, -1, null, -1, 3, 4]

Explanation
LRUCache lRUCache = new LRUCache(2);
lRUCache.put(1, 1); // cache is {1=1}
lRUCache.put(2, 2); // cache is {1=1, 2=2}
lRUCache.get(1);    // return 1
lRUCache.put(3, 3); // LRU key was 2, evicts key 2, cache is {1=1, 3=3}
lRUCache.get(2);    // returns -1 (not found)
lRUCache.put(4, 4); // LRU key was 1, evicts key 1, cache is {4=4, 3=3}
lRUCache.get(1);    // return -1 (not found)
lRUCache.get(3);    // return 3
lRUCache.get(4);    // return 4
```

Constraints:

```text
1 <= capacity <= 3000
0 <= key <= 10^4
0 <= value <= 10^5
At most 2 * 10^5 calls will be made to get and put.
```

## Answer

### 解題思路

LRU cache 需要同時做到兩件事：用 `key` 在平均 O(1) 找到資料，以及在 O(1) 找到並移除最久未使用的資料。

使用 `HashMap<Integer, Node>` 儲存 `key` 對應的節點，讓查找可以平均 O(1)。再用雙向 linked list 維護使用順序：越靠近 head 代表越常被使用，越靠近 tail 代表越久沒被使用。

- `get(key)`：如果不存在回傳 `-1`；如果存在，將該節點移到最前面並回傳 value。
- `put(key, value)`：如果 key 已存在，更新 value 並移到最前面；如果不存在，建立新節點放到最前面。
- 當大小超過 `capacity` 時，移除 tail 前一個節點，因為它就是目前 least recently used 的資料。

```java
import java.util.HashMap;
import java.util.Map;

class LRUCache {
	private final int capacity;
	private final Map<Integer, Node> cache;
	private final Node head;
	private final Node tail;

	public LRUCache(int capacity) {
		this.capacity = capacity;
		this.cache = new HashMap<>();
		this.head = new Node(0, 0);
		this.tail = new Node(0, 0);

		// head 與 tail 是哨兵節點，讓插入與刪除不需要額外處理空串列邊界。
		head.next = tail;
		tail.prev = head;
	}

	public int get(int key) {
		Node node = cache.get(key);
		if (node == null) {
			return -1;
		}

		// 被讀取的 key 變成最近使用，移到 linked list 最前面。
		moveToFront(node);
		return node.value;
	}

	public void put(int key, int value) {
		Node node = cache.get(key);
		if (node != null) {
			node.value = value;
			moveToFront(node);
			return;
		}

		Node newNode = new Node(key, value);
		cache.put(key, newNode);
		addToFront(newNode);

		if (cache.size() > capacity) {
			// tail 前一個節點最久未使用，因此超過容量時移除它。
			Node leastRecentlyUsed = tail.prev;
			removeNode(leastRecentlyUsed);
			cache.remove(leastRecentlyUsed.key);
		}
	}

	private void moveToFront(Node node) {
		removeNode(node);
		addToFront(node);
	}

	private void addToFront(Node node) {
		Node firstUsedNode = head.next;
		node.prev = head;
		node.next = firstUsedNode;
		head.next = node;
		firstUsedNode.prev = node;
	}

	private void removeNode(Node node) {
		Node previousNode = node.prev;
		Node nextNode = node.next;
		previousNode.next = nextNode;
		nextNode.prev = previousNode;
	}

	private static class Node {
		int key;
		int value;
		Node prev;
		Node next;

		Node(int key, int value) {
			this.key = key;
			this.value = value;
		}
	}
}
```

### 說明

1. `HashMap` 負責從 `key` 找到節點，避免每次操作都掃描整個 cache。
2. 雙向 linked list 負責維護使用順序，`head.next` 永遠是最近使用的節點，`tail.prev` 永遠是最久未使用的節點。
3. `get` 與更新既有 key 的 `put` 都必須呼叫 `moveToFront`，因為讀取或更新都代表該 key 剛被使用。
4. 題目保證 `capacity >= 1`，因此超出容量時一定可以從 `tail.prev` 找到一個真實節點移除。
5. 設 `n` 為 cache 目前儲存的 key 數量。`get` 與 `put` 都只做固定次數的 HashMap 查找與 linked list 指標調整，時間複雜度為 O(1)；HashMap 與 linked list 最多存放 `capacity` 個節點，空間複雜度為 O(n)。
