# 948. Bag of Tokens

## Problem

<span style="color: #f59e0b;"><strong>Medium</strong></span>

You start with an initial power of `power`, an initial score of `0`, and a bag of tokens given as an integer array `tokens`, where each `tokens[i]` denotes the value of token `i`.

Your goal is to maximize the total score by strategically playing these tokens. In one move, you can play an unplayed token in one of the two ways (but not both for the same token):

- **Face-up**: If your current power is at least `tokens[i]`, you may play token `i`, losing `tokens[i]` power and gaining `1` score.
- **Face-down**: If your current score is at least `1`, you may play token `i`, gaining `tokens[i]` power and losing `1` score.

Return the maximum possible score you can achieve after playing any number of tokens.

### Example 1

```text
Input: tokens = [100], power = 50
Output: 0
Explanation: Since your score is 0 initially, you cannot play the token face-down. You also cannot play it face-up since your power (50) is less than tokens[0] (100).
```

### Example 2

```text
Input: tokens = [200,100], power = 150
Output: 1
Explanation: Play token1 (100) face-up, reducing your power to 50 and increasing your score to 1.

There is no need to play token0, since you cannot play it face-up to add to your score. The maximum score achievable is 1.
```

### Example 3

```text
Input: tokens = [100,200,300,400], power = 200
Output: 2
Explanation: Play the tokens in this order to get a score of 2:

Play token0 (100) face-up, reducing your power to 100 and increasing your score to 1.
Play token3 (400) face-down, increasing your power to 500 and reducing your score to 0.
Play token1 (200) face-up, reducing your power to 300 and increasing your score to 1.
Play token2 (300) face-up, reducing your power to 0 and increasing your score to 2.
The maximum score achievable is 2.
```

### Constraints

```text
0 <= tokens.length <= 1000
0 <= tokens[i], power < 104
```

## Answer

先將 `tokens` 由小到大排序，使用雙指標分別指向尚未使用的最小 token 與最大 token。

### Greedy + 雙指標

1. 若目前能量足以使用最小 token，便將它正面朝上使用，換取 `1` 分。使用最小 token 能以最低代價增加分數。
2. 若無法正面使用最小 token，且目前還有分數可消耗，就將最大 token 正面朝下使用，換取最多能量。
3. 每次增加分數後更新答案；若既不能正面使用，也沒有可用的分數換能量，就結束操作。

```java
import java.util.Arrays;

class Solution {
    public int bagOfTokensScore(int[] tokens, int power) {
        Arrays.sort(tokens);

        int left = 0;
        int right = tokens.length - 1;
        int score = 0;
        int answer = 0;

        while (left <= right) {
            if (power >= tokens[left]) {
                // 優先使用最小 token 正面朝上，以最低能量換取分數。
                power -= tokens[left];
                left++;
                score++;
                answer = Math.max(answer, score);
            } else if (score > 0 && left < right) {
                // 無法繼續得分時，使用最大 token 正面朝下換回最多能量。
                power += tokens[right];
                right--;
                score--;
            } else {
                // 沒有足夠能量，也沒有其他 token 可換回能量。
                break;
            }
        }

        return answer;
    }
}
```

### 說明

1. 將 token 分成「用最小值取得分數」與「用最大值換回能量」兩種操作，可以讓每次 Greedy 選擇保留最大的後續操作空間。
2. `left` 只會向右移動，`right` 只會向左移動，因此每個 token 最多被使用一次。
3. `answer` 記錄過程中的最高分數，因為後續正面朝下操作可能會暫時降低目前分數。
4. 時間複雜度：`O(n log n)`，主要花費在排序；雙指標掃描為 `O(n)`。
5. 空間複雜度：`O(log n)`，用於排序所需的額外堆疊空間（不計排序實作的差異）。
