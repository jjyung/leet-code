# 1833. Maximum Ice Cream Bars

## Question

<span style="color: #16a34a;"><strong>Easy</strong></span>

在炎熱的夏天，小男孩想購買冰淇淋。給定每支冰淇淋的價格 `costs`，以及可使用的硬幣數量 `coins`，請回傳最多可以購買的冰淇淋數量。

每支冰淇淋最多只能購買一次，且可以按照任意順序購買。

題目要求使用 Counting Sort 解題。

[LeetCode 題目連結](https://leetcode.com/problems/maximum-ice-cream-bars/)

## Answer

要購買最多數量，應該優先購買價格最低的冰淇淋。因為價格較高的冰淇淋可以被價格較低的冰淇淋取代，不會減少購買數量。

### Counting Sort + Greedy

先使用計數陣列統計每種價格出現的次數，再按照價格由低到高購買：

1. `count[price]` 記錄價格為 `price` 的冰淇淋數量。
2. 計算目前硬幣可以購買的數量 `coins / price`。
3. 實際購買數量取「該價格的數量」與「可負擔數量」的較小值。
4. 扣除花費並累加購買數量。

```java
class Solution {
    public int maxIceCream(int[] costs, int coins) {
        int maxCost = 0;

        // 找出最高價格，作為計數陣列的大小。
        for (int cost : costs) {
            maxCost = Math.max(maxCost, cost);
        }

        // 統計每種價格出現的次數。
        int[] count = new int[maxCost + 1];
        for (int cost : costs) {
            count[cost]++;
        }

        long remainingCoins = coins;
        int bars = 0;

        // 從最低價格開始購買，確保能買到最多數量。
        for (int price = 1; price <= maxCost; price++) {
            if (count[price] == 0) {
                continue;
            }

            // 實際購買數量不能超過庫存，也不能超過目前能負擔的數量。
            int affordable = (int) Math.min(
                    count[price],
                    remainingCoins / price
            );

            bars += affordable;
            remainingCoins -= (long) price * affordable;

            if (remainingCoins < price) {
                break;
            }
        }

        return bars;
    }
}
```

### 說明

1. 這是 Greedy，因為每次選擇目前最便宜的冰淇淋，一定能讓剩餘硬幣購買更多或相同數量的商品。
2. Counting Sort 以 `count[price]` 統計價格出現次數，不需要實際建立排序後的陣列。
3. `remainingCoins / price` 表示目前最多能購買幾支該價格的冰淇淋。
4. 使用 `long` 計算剩餘硬幣與花費，避免乘法計算時發生整數溢位。
5. 時間複雜度：`O(n + C)`，其中 `C` 是最高價格。
6. 空間複雜度：`O(C)`。
