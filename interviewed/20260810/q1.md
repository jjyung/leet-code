# Maximum Profit with Cost Limit

## Question

給定整數陣列 `cost` 與整數 `k`：

- `cost[i]` 表示選擇第 `i` 個項目的成本。
- 每個項目最多只能選擇一次。
- 所有已選項目的總成本不可超過 `k`。
- 選擇第 `i` 個項目的收益為 `2^i`。

請在成本限制內最大化總收益。

### Example

```text
cost = [4, 3, 5, 2]
k = 7
```

各項目的收益如下：

```text
index 0 -> 2^0 = 1
index 1 -> 2^1 = 2
index 2 -> 2^2 = 4
index 3 -> 2^3 = 8
```

最佳選擇為 index `3` 與 index `2`：

```text
總成本 = 2 + 5 = 7
總收益 = 8 + 4 = 12
```

## Answer

### 解題思路

收益 `2^i` 具有嚴格的位權關係：

```text
2^i > 2^0 + 2^1 + ... + 2^(i - 1)
```

因為：

```text
2^0 + 2^1 + ... + 2^(i - 1) = 2^i - 1
```

因此，只要目前剩餘成本足以選擇較高 index 的項目，就一定應該優先選擇它。即使放棄所有較低 index 的項目，收益仍然不會超過選擇這個較高 index 的項目。

所以可以使用 Greedy：從最高 index 往最低 index 掃描，若 `cost[i]` 不超過目前剩餘容量，就選擇該項目。

### Java Solution

```java
import java.util.List;

class Solution {
    public long maxProfit(List<Integer> cost, int k) {
        long profit = 0;

        for (int i = cost.size() - 1; i >= 0; i--) {
            if (cost.get(i) <= k) {
                k -= cost.get(i);
                profit += 1L << i;
            }
        }

        return profit;
    }
}
```

### 正確性說明

對於任意 index `i`，第 `i` 個項目的收益 `2^i` 大於所有較低 index 項目收益的總和 `2^i - 1`。

因此，在目前剩餘成本足以選擇 index `i` 時，選擇它必定比選擇任意較低 index 的組合更有利。從高 index 到低 index 依序處理，並在可負擔時選擇項目，就能得到字典序最大的二進位選擇結果，也就是最大總收益。

### 複雜度分析

令 `n = cost.size()`：

- 時間複雜度：`O(n)`
- 空間複雜度：`O(1)`

### Java 位移運算補充

Java 的 `^` 是 XOR，不是次方運算：

```java
2 ^ 3 // 1，不是 8
```

因為 `2^n` 是二進位中的單一位元，可以使用左移運算表示：

```java
1L << n
```

例如：

```text
1L << 0 = 1
1L << 1 = 2
1L << 2 = 4
1L << 3 = 8
```

使用 `1L` 可讓運算以 `long` 進行，避免使用 `int` 時過早溢位。此解法也假設收益可安全存放在 `long` 範圍內。
