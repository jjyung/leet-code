# Maximum Value with Cost Limit

## Problem

給定兩個長度相同的整數陣列 `cost`、`value`，以及整數 `k`：

- `cost[i]` 表示第 `i` 個項目的成本。
- `value[i]` 表示第 `i` 個項目的收益。
- 每個項目最多只能選擇一次。
- 所有已選項目的總成本不可超過 `k`。

請在成本限制內最大化總收益。

### Example

```text
cost  = [4, 3, 5, 2]
value = [5, 7, 6, 4]
k = 7
```

最佳選擇為 index `1` 與 index `3`：

```text
總成本 = 3 + 2 = 5
總收益 = 7 + 4 = 11
```

## Answer

### 解題思路

這是標準的 0/1 Knapsack 問題。由於每個項目的 `value[i]` 不再是 `2^i`，無法保證高 index 的項目一定比所有低 index 項目的組合更有價值，因此不能使用 Greedy。

令：

```text
dp[j] = 總成本不超過 j 時，可以得到的最大收益
```

處理第 `i` 個項目時，有兩種選擇：

1. 不選擇第 `i` 個項目：收益維持 `dp[j]`。
2. 選擇第 `i` 個項目：先使用 `cost[i]` 的容量，收益為 `dp[j - cost[i]] + value[i]`。

因此轉移公式為：

```text
dp[j] = max(dp[j], dp[j - cost[i]] + value[i])
```

### 為什麼容量必須倒序迭代？

這是 0/1 Knapsack 的一維 DP 寫法。對每個項目，`j` 必須從 `k` 倒序走到 `cost[i]`，才能確保同一個項目在本輪最多被使用一次。

若改成正序迭代，`dp[j - cost[i]]` 可能已經在本輪使用過第 `i` 個項目，導致同一個項目被重複選擇，變成 Unbounded Knapsack。

### Java Solution

```java
import java.util.List;

class Solution {
    public long maxValue(List<Integer> cost, List<Integer> value, int k) {
        long[] dp = new long[k + 1];

        for (int i = 0; i < cost.size(); i++) {
            int itemCost = cost.get(i);
            int itemValue = value.get(i);

            for (int capacity = k; capacity >= itemCost; capacity--) {
                dp[capacity] = Math.max(
                        dp[capacity],
                        dp[capacity - itemCost] + itemValue
                );
            }
        }

        return dp[k];
    }
}
```

### 正確性說明

在處理第 `i` 個項目時，`dp[capacity]` 保留不選擇該項目的結果；而 `dp[capacity - itemCost] + itemValue` 則代表選擇該項目後的結果。取兩者最大值，就能得到使用前 `i + 1` 個項目、且成本不超過 `capacity` 時的最佳收益。

容量倒序迭代可確保轉移所使用的 `dp[capacity - itemCost]` 仍來自前一輪，因而每個項目最多被選擇一次。處理完所有項目後，`dp[k]` 即為成本不超過 `k` 的最大收益。

### 複雜度分析

令 `n = cost.size()`：

- 時間複雜度：`O(nk)`
- 空間複雜度：`O(k)`

### 與 q1 的差異

`q1.md` 中的收益固定為 `2^i`，高 index 的收益一定大於所有低 index 收益總和，因此可以使用 Greedy。

本題的 `value[i]` 是任意陣列值，收益之間沒有這種位權關係。例如：

```text
cost  = [4, 3]
value = [5, 100]
k = 3
```

此時只能選擇 index `1`。一般情況下，成本與收益的組合可能非常複雜，必須透過 DP 比較每個項目的「選擇」與「不選擇」結果。
