# Count Distinct Palindromic Substrings

## Question

給定一個字串 `s`，請計算其中所有「不同」回文子字串的數量。

子字串必須是原字串中連續的一段；如果相同內容的回文子字串出現多次，只能計算一次。

### Example 1

```text
Input: s = "ababa"
Output: 5
```

不同的回文子字串為 `"a"`、`"b"`、`"aba"`、`"bab"`、`"ababa"`。

### Example 2

```text
Input: s = "aaa"
Output: 3
```

不同的回文子字串為 `"a"`、`"aa"`、`"aaa"`。

## Answer

### 解題思路

直接列舉每個子字串，再用 stack 或雙指標判斷是否為回文，最壞會產生 `O(n^2)` 個子字串；若每次判斷又需要 `O(n)`，總複雜度會達到 `O(n^3)`。即使使用 `HashSet` 去除重複，也可能因為產生大量子字串而超時。

這題可以使用「回文樹」（Palindromic Tree，也稱 Eertree）：

1. 每個節點代表一種不同的回文子字串，因此節點數量就是答案。
2. `len` 儲存該回文的長度。
3. `link` 指向該回文的最長回文後綴。
4. 依序加入字元時，只需要尋找目前最長回文後綴能否向左右延伸。
5. 如果延伸後的回文尚未建立，新增一個節點；若已存在則沿用原節點，自然不會重複計數。

```java
import java.util.ArrayList;
import java.util.HashMap;
import java.util.List;
import java.util.Map;

class Solution {
    private static class Node {
        int length;
        int suffixLink;
        Map<Character, Integer> next = new HashMap<>();

        Node(int length) {
            this.length = length;
        }
    }

    public int countDistinctPalindromicSubstrings(String s) {
        List<Node> tree = new ArrayList<>();

        // 兩個虛擬根節點：長度 -1 與長度 0。
        tree.add(new Node(-1));
        tree.add(new Node(0));
        tree.get(0).suffixLink = 0;
        tree.get(1).suffixLink = 0;

        int longestSuffix = 1;

        for (int i = 0; i < s.length(); i++) {
            char currentChar = s.charAt(i);
            int candidate = longestSuffix;

            // 找到可以在左右兩側加入 currentChar 的最長回文。
            while (i - 1 - tree.get(candidate).length < 0
                    || s.charAt(i - 1 - tree.get(candidate).length) != currentChar) {
                candidate = tree.get(candidate).suffixLink;
            }

            Integer nextNode = tree.get(candidate).next.get(currentChar);
            if (nextNode == null) {
                Node palindrome = new Node(tree.get(candidate).length + 2);
                tree.add(palindrome);
                nextNode = tree.size() - 1;
                tree.get(candidate).next.put(currentChar, nextNode);

                if (palindrome.length == 1) {
                    palindrome.suffixLink = 1;
                } else {
                    int suffixCandidate = tree.get(candidate).suffixLink;
                    while (i - 1 - tree.get(suffixCandidate).length < 0
                            || s.charAt(i - 1 - tree.get(suffixCandidate).length) != currentChar) {
                        suffixCandidate = tree.get(suffixCandidate).suffixLink;
                    }
                    palindrome.suffixLink = tree.get(suffixCandidate).next.get(currentChar);
                }
            }

            longestSuffix = nextNode;
        }

        // 排除兩個虛擬根節點。
        return tree.size() - 2;
    }
}
```

### 說明

1. 每個一般節點只在某一種回文第一次出現時建立，所以不需要額外使用 `HashSet`。
2. 例如 `"aaa"` 會依序建立 `"a"`、`"aa"`、`"aaa"` 三個節點。
3. 時間複雜度：`O(n)`（`HashMap` 操作為平均 `O(1)`）。
4. 空間複雜度：`O(n)`，最多建立 `n` 個不同回文節點。
