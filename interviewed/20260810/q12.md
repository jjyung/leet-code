# Maximum Value with Unlimited Items

## Question

給定兩個長度相同的整數陣列 `cost`、`value`，以及整數 `k`：

- `cost[i]` 表示第 `i` 種物品的成本。
- `value[i]` 表示第 `i` 種物品的收益。
- 每種物品可以被選擇任意次數，包含零次。
- 所有已選物品的總成本不可超過 `k`。

請在成本限制內最大化總收益。

每種物品的成本必須大於 `0`，否則若該物品有正收益，就可以無限次選擇而沒有增加成本。

### Example

```text
cost  = [4, 3, 5, 2]
value = [5, 7, 6, 4]
k = 7
```

因為物品可以重複選擇，選擇兩次 index `1` 的物品：

```text
總成本 = 3 + 3 = 6
總收益 = 7 + 7 = 14
```

因此最大收益為 `14`。

## Answer

### 解題思路

這是 Unbounded Knapsack，也就是可以無限次選擇同一種物品的背包問題。

令：

```text
dp[j] = 總成本不超過 j 時，可以得到的最大收益
```

對每一種物品 `i`，若目前容量足以放入它，就可以選擇它，轉移公式為：

```text
dp[j] = max(dp[j], dp[j - cost[i]] + value[i])
```

關鍵在於容量 `j` 必須由小到大迭代。如此一來，`dp[j - cost[i]]` 可能已經在本輪使用過同一種物品，便能表示重複選擇該物品。

### 為什麼容量必須正序迭代？

以某個物品的成本為 `cost[i]` 為例：

```text
dp[cost[i]]
```

先計算選擇一次該物品的結果後，後續計算更大容量時，便可以使用這個更新過的狀態：

```text
dp[2 * cost[i]]
dp[3 * cost[i]]
...
```

因此同一種物品可以被重複使用。

若容量改成倒序迭代，`dp[j - cost[i]]` 仍是本輪更新前的值，同一種物品就只能被使用一次，會變成 `q11.md` 的 0/1 Knapsack。

### Java Solution

```java
import java.util.List;

class Solution {
    public long maxValue(List<Integer> cost, List<Integer> value, int k) {
        long[] dp = new long[k + 1];

        for (int i = 0; i < cost.size(); i++) {
            int itemCost = cost.get(i);
            int itemValue = value.get(i);

            for (int capacity = itemCost; capacity <= k; capacity++) {
                dp[capacity] = Math.max(
                        dp[capacity],
                        dp[capacity - itemCost] + itemValue
                );
            }
        }

        return dp[k];
    }
}
```

### 正確性說明

處理第 `i` 種物品時，`dp[capacity]` 代表不選擇該物品的結果；`dp[capacity - itemCost] + itemValue` 則代表至少再選擇一次該物品的結果。

由於容量是正序迭代，`dp[capacity - itemCost]` 可能已經包含同一種物品，因此每次轉移都能延續前一次選擇，涵蓋選擇該物品任意次的情況。

對每個物品與每個容量取最大值後，`dp[k]` 就是總成本不超過 `k` 時的最大收益。

### 複雜度分析

令 `n = cost.size()`：

- 時間複雜度：`O(nk)`
- 空間複雜度：`O(k)`

### 與 q11 的差異

| 題目 | 每種物品可選次數 | 容量迭代方向 |
| --- | --- | --- |
| q11 | 最多一次 | 由大到小 |
| q12 | 任意次 | 由小到大 |

兩者的轉移公式相同，差別只在一維 DP 的迭代方向：

```java
// 0/1 Knapsack：每種物品最多一次
for (int capacity = k; capacity >= itemCost; capacity--) {
    // ...
}

// Unbounded Knapsack：每種物品可以重複使用
for (int capacity = itemCost; capacity <= k; capacity++) {
    // ...
}
```
